## Що таке тричленні рівняння

Тричленні рівняння — це особливий вид [многочленних рівнянь](<../polynomial-equations/>), що складаються з трьох доданків зі сталими та [степенями](<../powers>) змінної.

\[ax^{2n} + bx^{n} + c = 0 \]

Цей вигляд особливо корисний, бо дає змогу застосовувати стратегії підстановки, наприклад \(x^n = y\), щоб перетворити рівняння на стандартне квадратне.

  * \( a \), \( b \) і \( c \) — числові коефіцієнти.
  * \( x \) — невідома змінна.


Варто зазначити, що коли \( n = 1 \), рівняння стає [квадратним рівнянням](<../quadratic-equations>), яке часто записують у вигляді:

\[ax^2 + bx + c = 0 \]

## Як розв’язувати тричленні рівняння

Для розв’язування тричленного рівняння вигляду \( ax^{2n} + bx^n + c = 0 \) можна виконати загальну послідовність кроків. Перший крок — зробити підстановку, що перетворює рівняння на квадратне відносно \( y \), яке розв’язати легше. Наприклад, покладемо:

\[x^n = y \]

і отримаємо:

\[ay^2 + by + c = 0 \]

Щоб розв’язати отримане квадратне рівняння відносно \( y \), можна застосувати такі прийоми, як [розклад на множники](<../factoring-quadratic-equations>), [виділення повного квадрата](<../completing-the-square>) або [формула коренів квадратного рівняння](<../quadratic-formula>). Знайшовши розв’язки для \( y \), підставляємо їх назад, користуючись початковою заміною \( y = x^n \), щоб визначити відповідні значення \( x \). Коротко:

  * Нехай \( y = x^n \), тож рівняння набуває вигляду \( ay^2 + by + c = 0 \).

  * Розв’яжіть квадратне рівняння відносно \( y \).

  * Для кожного розв’язку \( y_i \) розв’яжіть \( x^n = y_i \), щоб знайти відповідні значення \( x \).

  * Перевірте всі розв’язки в початковому рівнянні, щоб переконатися, що вони правильні.


##### Важливо перевірити кожен розв’язок, підставивши його в початкове рівняння, щоб переконатися в його правильності. Процес може здатися складним, але насправді він практичний і простий у виконанні.

Коли рівняння розв’язують підстановкою, іноді можуть з’явитися зайві розв’язки, які називають сторонніми. Вони можуть задовольняти перетворене рівняння, але не початкове. Підставляючи кожен розв’язок назад у початкове рівняння, ми переконуємося, що він справді підходить і не порушує жодних неявних умов.

## Приклад

Розв’яжіть рівняння \(3x^4-7x^2 + 2 = 0\).

Зробімо підстановку \(y = x^2\), щоб перетворити рівняння на квадратне:

\[3y^2-7y + 2 = 0\]


Для знаходження \(y\) можна скористатися [формулою коренів квадратного рівняння](<../quadratic-formula>). Отримуємо:

\begin{align*} y &= \frac{{-(-7) \pm \sqrt{{(-7)^2-4 \cdot 3 \cdot 2}}}}{{2 \cdot 3}} \\\\[0.6em] &= \frac{{7 \pm \sqrt{{49-24}}}}{6} \\\\[0.6em] &= \frac{{7 \pm \sqrt{25}}}{6} \\\\[0.6em] &= \frac{{7 \pm 5}}{6} \end{align*}

Отже, ми знайшли:

\[y_1 = \frac{12}{6} = 2\] \[y_2 = \frac{2}{6} = \frac{1}{3}\]


Коли розв’язки для \(y\) знайдено, їх можна підставити назад у початкове рівняння із \(x^2 = y\), щоб знайти відповідні значення \(x\).

Для \(y = 2\) маємо: \[x^2 = 2 \quad \rightarrow \quad x = \pm \sqrt{2} \]

Для \(y = \frac{1}{3}\) маємо \[x^2 = \frac{1}{3} \quad \rightarrow \quad \pm \sqrt{\frac{1}{3}} \]


Необхідно перевірити, що розв’язки правильні, підставивши їх назад у початкове рівняння, щоб упевнитися в точності. Щоб перевірити, чи задані значення є розв’язками рівняння \(3x^4-7x^2 + 2 = 0\), потрібно підставити їх у рівняння й перевірити, чи вони його задовольняють.

Для \( x = \sqrt{2} \):

\[3(\sqrt{2})^4-7(\sqrt{2})^2 + 2 = 3 \cdot 2^2-7 \cdot 2 + 2 \] \[= 12 - 14 + 2 = 0 \]


Для \( x = -\sqrt{2} \): \[3(-\sqrt{2})^4-7(-\sqrt{2})^2 + 2 = 3 \cdot 2^2-7 \cdot 2 + 2 \] \[= 12 - 14 + 2 = 0 \]


Для \( x = \sqrt{\dfrac{1}{3}} \): \[3\left(\sqrt{\frac{1}{3}}\right)^4-7\left(\sqrt{\frac{1}{3}}\right)^2 + 2 = 3 \cdot \left(\frac{1}{3}\right)^2 - 7 \cdot \frac{1}{3} + 2 \] \[= \frac{3}{9}-\frac{7}{3} + 2 = 0 \]


Для \( x = -\sqrt{\dfrac{1}{3}} \): \[3\left(-\sqrt{\frac{1}{3}}\right)^4-7\left(-\sqrt{\frac{1}{3}}\right)^2 + 2 = 3 \cdot \left(\frac{1}{3}\right)^2-7 \cdot \frac{1}{3} + 2 \] \[= \frac{3}{9}- \frac{7}{3} + 2 = 0 \]

Усі розв’язки задовольняють початкове рівняння.

Розв’язок рівняння: \[x = \pm \sqrt{2} \quad \text{і} \quad \pm \sqrt{\frac{1}{3}}\]
