## Що таке однорідні тригонометричні рівняння

Однорідні тригонометричні рівняння — це [рівняння](<../equations>), у яких усі доданки містять тригонометричні функції, наприклад [синус і косинус](<../sine-and-cosine>), [піднесені](<../powers>) до того самого степеня. Однорідне тригонометричне рівняння першого степеня зазвичай має вигляд:

\[a \sin x + b \cos x = 0 \]

Кожен доданок рівняння має степінь 1, а \( a \) і \( b \) — [дійсні коефіцієнти](<../types-of-numbers>). Загальний вигляд тригонометричного рівняння першого степеня:

\[a \sin x + b \cos x + c = 0 \]

Це рівняння вважають однорідним, коли вільний член \( c = 0 \). Подібні міркування стосуються однорідних тригонометричних рівнянь другого степеня, які містять лише доданки другого степеня. Такі рівняння зазвичай записують у вигляді:

\[a \sin^2 x + b \sin x \cos x + c \cos^2 x = 0 \]

##### Означення можна узагальнити на рівняння третього, четвертого, п’ятого й вищих степенів. У цих випадках усі доданки мають містити тригонометричні [функції](<../functions>), піднесені до того самого степеня, і тоді рівняння лишається однорідним.

Однорідні рівняння степеня \( n \) можна розв’язати, поділивши кожен доданок рівняння на \( \cos^n x \) і тим самим перетворивши рівняння на таке, що виражене через \( \tan x \).

## Приклад 1

Розв’яжімо однорідне тригонометричне рівняння першого степеня: \[\sin x - \sqrt{3} \cos x = 0 \]


Поділивши рівняння на \( \cos x \), отримуємо:

\[\frac{\sin x}{\cos x} - \sqrt{3} = 0\]

Оскільки відношення синуса до косинуса дорівнює [тангенсу](<../tangent-and-cotangent>), рівняння можна переписати через \( \tan x. \)

\[\tan x = \sqrt{3}\]

Розв’язавши рівняння, отримуємо значення:

\[x = \arctan(\sqrt{3}) = \frac{\pi}{3} \]

Оскільки функція тангенса періодична з періодом \( \pi \), загальний розв’язок такий:

\[x = \frac{\pi}{3} + k\pi, \quad k \in \mathbb{Z} \]

Щоразу, коли [тригонометричні тотожності](<../trigonometric-identities/>) дають змогу переписати тригонометричне рівняння в однорідному вигляді, зазвичай варто це зробити, адже так можна спростити обчислення й полегшити процес розв’язування.

## Приклад 2

Розглянемо тепер тригонометричне рівняння другого степеня:

\[\sin^2 x + \sin 2x - \cos^2 x = 0 \]

На перший погляд, це рівняння не однорідне, бо не всі доданки мають однаковий степінь. Зокрема, \( \sin 2x \) — доданок першого степеня, тоді як \( \sin^2 x \) і \( \cos^2 x \) — вирази другого степеня. У такому рівнянні ми не можемо поділити всі доданки на \( \cos^2 x \), бо доданок першого степеня не перетворюється на вираз, корисний для розв’язування рівняння. Справді, цей метод працює лише тоді, коли всі доданки мають однаковий степінь, як в однорідних рівняннях.


Проте, скориставшись [тригонометричними тотожностями](<../trigonometric-identities/>), а саме формулою подвійного кута, можна переписати \( \sin(2x) \) як \( 2\sin(x)\cos(x) \). Тоді рівняння набуває вигляду:

\[\sin^2 x + 2\sin x \cos x - \cos^2 x = 0 \]

Так ми перетворили початкове рівняння на однорідне тригонометричне рівняння другого степеня, яке тепер можна розв’язати, поділивши всі доданки на \( \cos^2 x \). Рівняння набуває вигляду:

\[\frac{\sin^2 x}{\cos^2 x} + \frac{2\sin x \cos x}{\cos^2 x} - \frac{\cos^2 x}{\cos^2 x} = 0 \]


Спростивши кожен доданок, отримуємо:

\[\tan^2 x + 2\tan x - 1 = 0 \]

Це [квадратне рівняння](<../quadratic-equations>) відносно \( \tan x \), і тепер його можна розв’язати за [формулою коренів квадратного рівняння](<../quadratic-formula>). Зробімо заміну \( t = \tan x \). Рівняння набуває вигляду:

\[t^2 + 2t - 1 = 0 \]

За формулою коренів квадратного рівняння маємо:

\[t = \frac{-2 \pm \sqrt{4 + 4}}{2} = \frac{-2 \pm 2\sqrt{2}}{2} = -1 \pm \sqrt{2} \]

Два розв’язки:

\[t_1 = -1 + \sqrt{2}, \quad t_2 = -1 - \sqrt{2} \]


Повернувшись до \( t = \tan x \), отримуємо розв’язки:

\[\tan x = -1 + \sqrt{2} \quad \text{і} \quad \tan x = -1 - \sqrt{2} \]

Загальні розв’язки:

\[x_1 = \arctan(-1 + \sqrt{2}) + k\pi \quad k \in \mathbb{Z} \] \[x_2 = \arctan(-1 - \sqrt{2}) + k\pi \quad k \in \mathbb{Z} \]
