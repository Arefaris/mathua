# Неповні квадратні рівняння


## Означення

Квадратне рівняння вважають неповним, коли в стандартному вигляді \(ax^2 + bx + c = 0\) відсутній один або обидва доданки \(bx\) і \(c\), за умови, що доданок \(ax^2\) присутній. Такі рівняння мають прямі методи розв’язування, які не потребують ні формули коренів квадратного рівняння, ні розкладу на множники. 


Коли \(b\) і \(c\) обидва дорівнюють нулю, рівняння зводиться до такого:

\[ax^2 = 0, \quad a \neq 0\]

Поділивши обидві частини на \(a\), яке за припущенням ненульове, отримуємо \(x^2 = 0\), і єдиний дійсний розв’язок — \(x = 0\) для кожного допустимого значення \(a\).

> Графічно рівняння задає параболу з вершиною на початку координат \((0, 0)\), симетричну відносно осі y. Вітки графіка напрямлені вгору, якщо \(a > 0\), і вниз, якщо \(a < 0\); модуль \(a\) визначає ширину параболи. Хоча рівняння має єдиний розв’язок, функція має подвійний корінь у точці \(x = 0\): вісь x дотикається до параболи на початку координат.

## Випадок b = 0

Коли \(b = 0\), рівняння має вигляд:

\[ax^2 + c = 0, \quad a \neq 0,\\, c \neq 0\]

Виразивши \(x^2\), отримуємо:

\[x^2 = -\frac{c}{a}\]

Рівняння задає параболу, симетричну відносно осі y. Коли \(a\) і \(c\) мають протилежні знаки, величина \(-c/a\) додатна, і рівняння має два різні дійсні розв’язки:

\[x_{1,2} = \pm\sqrt{-\frac{c}{a}}\]

Парабола перетинає вісь x у двох точках, симетричних відносно початку координат. Коли \(a\) і \(c\) мають однакові знаки, величина \(-c/a\) від’ємна, і рівняння не має дійсних розв’язків:

\[-\frac{c}{a} < 0 \implies x \notin \mathbb{R}\]

Парабола лежить повністю над віссю x або під нею й не перетинає її.

## Випадок c = 0

Коли \(c = 0\), рівняння має вигляд:

\[ax^2 + bx = 0, \quad a \neq 0,\\, b \neq 0\]

Винісши \(x\) за дужки, отримуємо \(x(ax + b) = 0\). За властивістю нульового добутку або \(x = 0\), або \(ax + b = 0\), і рівняння має два різні дійсні розв’язки:

\[x_1 = 0 \qquad x_2 = -\frac{b}{a}\]

## Приклади

Розглянемо рівняння \(3x^2 = 0\). Оскільки \(b\) і \(c\) обидва нульові, єдиний розв’язок — \(x = 0\).


Розглянемо рівняння \(2x^2 - 8 = 0\). Воно має вигляд \(ax^2 + c = 0\), де \(a = 2\) і \(c = -8\). Оскільки \(a\) і \(c\) мають протилежні знаки, існують два дійсні розв’язки. Виразивши \(x^2\), отримуємо:

\[x^2 = \frac{8}{2} = 4\]

Добувши квадратний корінь з обох частин, отримуємо два розв’язки:

\[x_{1,2} = \pm\sqrt{4} = \pm 2\]


Розглянемо рівняння \(x^2 + 5 = 0\). Тут \(a = 1\) і \(c = 5\) мають однакові знаки, тож \(-c/a = -5 < 0\). Рівняння не має дійсних розв’язків.


Розглянемо рівняння \(3x^2 - 6x = 0\). Воно має вигляд \(ax^2 + bx = 0\), де \(a = 3\) і \(b = -6\). Винісши \(x\) за дужки, отримуємо \(x(3x - 6) = 0\), і два розв’язки такі:

\[x_1 = 0 \qquad x_2 = \frac{6}{3} = 2\]

## Поширена помилка, якої слід уникати

Для рівнянь вигляду \(ax^2 + bx = 0\) часта помилка полягає в діленні обох частин на \(x\), коли рівняння записано так:

\[ax^2 = bx\]

Ділити на \(x\) тут не можна, бо \(x = 0\) сам є розв’язком, а ділення на нуль не визначене. Через таку дію втрачається корінь \(x = 0\), а рівняння зводиться до лінійного, що дає лише розв’язок \(x = -b/a\). Правильний підхід — винести \(x\) за дужки як спільний множник, як показано вище.
