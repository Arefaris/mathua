# Квадратні рівняння

![Графік квадратного рівняння](svg/quadratic-equations.svg)

## Вступ

Квадратне рівняння — це алгебраїчне рівняння другого степеня
з однією змінною. Його стандартний вигляд такий:

\[ ax^2 + bx + c = 0 \]

де \(a\), \(b\) і \(c\) — дійсні коефіцієнти, \(x\) — невідома, а \(a \neq 0\).

- Коефіцієнти \(a\), \(b\) і \(c\) — сталі.
- \(x\) позначає змінну.
- \(a\) — коефіцієнт при квадратному доданку \(x^2\), \(b\) — коефіцієнт при лінійному доданку \(x\), а \(c\) — вільний член.
- Коли \(a = 0\), рівняння зводиться до лінійного рівняння \(bx + c = 0\). Якщо ще й \(b = 0\), рівняння перетворюється на числову рівність і може не мати розв’язку або мати нескінченно багато розв’язків, залежно від того, чи \(c \neq 0\), чи \(c = 0\).

Квадратні рівняння — найпростіший випадок тричленного рівняння, яке має загальний вигляд:

\[ ax^{2n} + bx^{n} + c = 0 \]

Поклавши \(n = 1\), отримуємо стандартний квадратний вигляд \(ax^2 + bx + c = 0.\) Для \(n \geq 2\) рівняння можна звести до квадратного відносно допоміжної змінної \(y = x^n\) і розв’язати тими самими методами.

## Геометричне тлумачення

Рівняння \(y = ax^2 + bx + c\), де \(a \neq 0\), задає параболу на площині зі змінними \(x\) і \(y\).

![Мал. 1](quadratic-equations.svg)

Коли коефіцієнт \(a > 0\), вітки параболи напрямлені вгору, а вершина є мінімумом функції. Коли \(a < 0\), вітки напрямлені вниз, а вершина є максимумом.

Дійсні розв’язки рівняння \(ax^2 + bx + c = 0\) відповідають точкам, у яких парабола перетинає вісь \(x\). Цю конфігурацію визначає знак дискримінанта \(\Delta = b^2 - 4ac\):

+ За \(\Delta > 0\) парабола перетинає вісь у двох різних точках.
+ За \(\Delta = 0\) вона дотикається до осі.
+ За \(\Delta < 0\) вона не перетинає вісь, і рівняння не має дійсних розв’язків.

> Умова \(a \neq 0\) гарантує, що рівняння описує параболічну криву, а не лінійне рівняння.

## Методи розв’язування

Квадратне рівняння неповне, коли
коефіцієнт \(b\) або \(c\) дорівнює нулю. У цьому випадку рівняння має простіший вигляд і його можна розв’язати безпосередньо, не застосовуючи загальної формули. Перший крок розв’язування квадратного рівняння — переписати його в стандартному вигляді:

\[ax^2 + bx + c = 0\]

Такий вигляд дає змогу визначити коефіцієнти й обчислити дискримінант \(\Delta = b^2 - 4ac\). Дискримінант визначає характер розв’язків:

+ Два різні дійсні корені, коли \(\Delta > 0\).
+ Один дійсний корінь кратності два, коли \(\Delta = 0\).
+ Пара спряжених комплексних коренів, коли \(\Delta < 0\).

Найзагальніший метод розв’язування — формула коренів квадратного рівняння.
Проте в деяких випадках розклад на множники або виділення повного квадрата може бути прямішим шляхом до розв’язку.

Основна теорема алгебри гарантує, що квадратне рівняння має рівно два корені в \(\mathbb{C}\) з урахуванням кратності. Обидва корені дійсні, коли \(\Delta \geq 0\), і утворюють пару спряжених комплексних чисел, коли \(\Delta < 0\).

## Формула коренів квадратного рівняння

 Для квадратного рівняння в стандартному вигляді \(ax^2+bx+c = 0\) формула коренів така:

\[ x_{1,2} = \frac{{-b \pm \sqrt{{b^2 - 4ac}}}}{{2a}} \]

+ \(a\), \(b\), \(c\) — дійсні коефіцієнти, і \(a \neq 0\).
+ Символ \(\pm\) відображає існування двох розв’язків, що відповідають двом знакам.
+ Квадратне рівняння має рівно два корені в \(\mathbb{C}\) з урахуванням кратності.
+ За формулами Вієта корені задовольняють \(x_1 + x_2 = -b/a\) і \(x_1 \cdot x_2 = c/a\).

Ще одна властивість дискримінанта така:

\[ \Delta = a^2(x_1 - x_2)^2 \]

Ця тотожність безпосередньо показує, що \(\Delta \geq 0\), коли корені дійсні, і що
\(\Delta = 0\) тоді й лише тоді, коли два корені збігаються.

>Коли дискримінант від’ємний, розв’язки комплексні. Цей випадок повністю розглянуто в окремій статті про квадратні рівняння з комплексними розв’язками.

## Розклад на множники

Квадратне рівняння можна розкласти на множники до такого вигляду:

\[ ax^2 + bx + c = 0 \quad \Longleftrightarrow \quad a(x - x_1)(x - x_2) = 0 \]

де \(x_1\) і \(x_2\) — корені рівняння. За формулами Вієта корені задовольняють такі співвідношення:

\[ x_1 + x_2 = -\frac{b}{a}\]
\[ x_1 \cdot x_2 = \frac{c}{a} \]

Цей метод ефективний, коли корені можна визначити підбором або простою
перевіркою, але стає непрактичним для рівнянь з ірраціональними чи комплексними коренями, де
краще скористатися формулою коренів квадратного рівняння.

## Як розв’язати квадратне рівняння

+ Перепишіть рівняння в стандартному вигляді: \( ax^2 + bx + c = 0 \).  
+ Обчисліть дискримінант: \( \Delta = b^2 - 4ac \).  
+ Скористайтеся формулою коренів квадратного рівняння:  
   \[
   x = \frac{-b \pm \sqrt{\Delta}}{2a}
   \]  
+ Спростіть результат.  
+ Якщо \( \Delta \geq 0 \), розв’язки дійсні; якщо \( \Delta < 0 \), розв’язки — спряжені комплексні числа.

> Формула коренів квадратного рівняння — універсальний метод, але не завжди найефективніший. Коли рівняння неповне або допускає очевидний розклад на множники, корені нерідко можна отримати швидше безпосереднім підбором.

## Квадратні рівняння з параметрами

Природне розширення вивчення квадратних рівнянь — розглянути випадок, коли коефіцієнти не фіксовані числа, а залежать від зовнішнього параметра. У цьому контексті говорять про квадратні рівняння з параметром,
які також називають буквеними квадратними рівняннями; вони мають вигляд:

\[ a(k)\\,x^2 + b(k)\\,x + c(k) = 0, \quad a(k) \neq 0 \]

Зміна параметра \(k\) змінює рівняння й, отже, характер його розв’язків. Аналіз спирається на дискримінант:

\[ \Delta(k) = b(k)^2 - 4\\,a(k)\\,c(k) \]

який, так само як у класичному випадку, визначає, чи має рівняння два
різні дійсні розв’язки, кратний розв’язок чи пару спряжених комплексних розв’язків.

## Блок-схема

- `Quadratic equation to solve`
  - **IF** \( a = 0 \)
    - _звести до лінійного рівняння_
      старший коефіцієнт перетворюється на нуль, тож рівняння більше не квадратне: \( bx + c = 0 \)
    - _розв’язати безпосередньо_
      \[x = -\frac{c}{b}\]
  - `ELSE IF` \( b = 0 \) і \( c = 0 \)
    - _рівняння зводиться до \( ax^2 = 0 \)_
      лінійний і вільний доданки обидва зникають, лишаючи повний квадрат
    - _висновок_ \( x = 0 \) — подвійний корінь
  - `ELSE IF` \( b = 0 \) і \( c \neq 0 \)
    - _рівняння зводиться до \( ax^2 + c = 0 \)_
      лінійний доданок зникає; рівняння є чистим квадратним відносно \( x^2 \)
    - _розв’язати відносно \( x^2 \)_
      \[x^2 = -\frac{c}{a}\]
    - **IF** \( -c/a < 0 \)
      - _дійсних розв’язків немає_
        права частина від’ємна, тому жодне дійсне число не задовольняє рівняння
    - `ELSE`
      - _два дійсні розв’язки_
        \[x = \pm\sqrt{-\frac{c}{a}}\]
  - `ELSE IF` \( c = 0 \)
    - _винести \( x \) за дужки_
      вільний член зникає, тож \( x \) — очевидний спільний множник: \( x(ax + b) = 0 \)
    - _два розв’язки_
      \[x = 0 \qquad x = -\frac{b}{a}\]
  - `ELSE IF` рівняння легко розкладається на множники
    - _шукати два числа \( p \) і \( q \), для яких_
      \[p + q = b \qquad p \cdot q = ac\]
    - _переписати та розкласти на множники_
      якщо такі числа існують, тричлен одразу розкладається на множники: \( ax^2 + bx + c = a(x - r_1)(x - r_2) \)
    - _зчитати корені_ \( x = r_1 \) і \( x = r_2 \)
  - `ELSE`
    - _обчислити дискримінант_
      коли жоден спрощений спосіб не підходить, загальний метод — формула коренів квадратного рівняння: \( \Delta = b^2 - 4ac \)
    - **IF** \( \Delta < 0 \)
      - _дійсних розв’язків немає_
        квадратний корінь із від’ємного числа не є дійсним; рівняння має два спряжені комплексні корені
    - **IF** \( \Delta = 0 \)
      - _один дійсний розв’язок_ (подвійний корінь)
        два корені збігаються; парабола дотикається до осі \( x \)
        \[x = -\frac{b}{2a}\]
    - **IF** \( \Delta > 0 \)
      - _два різні дійсні розв’язки_
        парабола перетинає вісь \( x \) у двох різних точках
        \[x = \frac{-b \pm \sqrt{\Delta}}{2a}\]
