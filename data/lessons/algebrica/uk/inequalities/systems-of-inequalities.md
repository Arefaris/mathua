## Лінійні системи нерівностей з однією змінною

Система нерівностей — це набір із двох чи більше нерівностей, що містять одну або кілька змінних і розглядаються одночасно. Мета — визначити множину всіх значень змінних, що задовольняють кожну нерівність системи водночас. Іншими словами, розв’язок задає спільна область (або перетин) окремих множин розв’язків, пов’язаних з кожною нерівністю.

У цьому розділі ми зосередимося на лінійних системах з однією дійсною змінною \( x \). Такі системи зазвичай складаються з нерівностей першого степеня й можуть бути записані в загальному вигляді:

\[\begin{cases} f_1(x) \geq 0 \\\\[0.6em] f_2(x) \geq 0 \\\\[0.6em] \quad \quad \quad \vdots \\\\[0.6em] f_k(x) \geq 0 \end{cases} \]

де \( f_i(x) \) — функції або вирази зі змінною \( x \), а співвідношенням може бути будь-який знак нерівності: \( <, \leq, >, \geq \). Систему, що не має розв’язків, називають несумісною. Якщо навіть одна нерівність системи не має розв’язку, уся система вважається несумісною.

У розділі про [лінійні нерівності](<../linear-inequalities>) ми бачили приклади розв’язування нерівностей з [функцією модуля](<../absolute-value-function>). У таких випадках для знаходження розв’язку необхідно скористатися системою нерівностей. Розгляньмо ще один приклад розв’язування системи лінійних нерівностей.

## Приклад 1

Розглянемо таку систему лінійних нерівностей:

\[\begin{cases} 3x + 6 > 0 \\\\[0.6em] x - 3 \geq 0 \\\\[0.6em] 9 - x > 0 \end{cases} \]

Нам потрібно знайти значення \( x \), що одночасно задовольняють усі три нерівності. Розв’язавши окремі нерівності, отримуємо:

\[\begin{cases} 3x + > -6 \rightarrow x > -2\\\\[0.6em] x \geq 3 \\\\[0.6em] -x > -9 \rightarrow x < 9 \end{cases} \]

Отже, маємо три проміжки: \(x > -2\), \(x \geq 3\), \(x<9\). Як зазначено, розв’язок системи — той, що задовольняє всі три нерівності одночасно. Зобразимо значення на числовій прямій і визначимо спільний проміжок, що відповідає вимогам.

| \[-2\]| \[3\]| \[9\]|   
---|---|---|---|---  
| | | |   
| | | |   
| | | |   
| | | |   
| | | |   
  
Розв’язок системи: \[x \in [3, 9)\]

##### Цей проміжок включає 3 і виключає 9. Щоб докладніше дізнатися про будову та тлумачення проміжків, зверніться до [окремої статті](<../determining-the-domain-of-a-function/>).

## Загальна стратегія розв’язування систем нерівностей

Те, що ми розглянули, — дуже проста система з трьох лінійних нерівностей зі змінною \( x \). Системи нерівностей можуть бути значно складнішими й містити дробово-раціональні функції, [корені](<../radicals>), [степені](<../powers/>), [логарифми](<../logarithms>), показникові та [тригонометричні функції](<../sine-and-cosine>).

Хоча конкретна процедура розв’язування залежить від вигляду та властивостей наявних функцій, загальний принцип лишається тим самим: допустимі значення — це ті, що задовольняють усі нерівності системи одночасно, тобто перетин їхніх окремих множин розв’язків.

Загалом розв’язування системи нерівностей виконують за чітко визначеною послідовністю кроків. Типова процедура така:

  * Розв’яжіть кожну нерівність окремо й визначте відповідну їй множину розв’язків.
  * За потреби зобразіть множини розв’язків на числовій прямій, щоб наочно побачити отримані проміжки.
  * Знайдіть перетин усіх множин розв’язків, бо систему задовольняють лише значення, спільні для кожної нерівності.
  * Запишіть остаточний розв’язок у відповідному записі проміжків, подбавши про правильне позначення включень і виключень на кінцях.


##### Цей структурований підхід дає надійну основу, яку можна пристосувати до найрізноманітніших задач. Зі зростанням складності наявних функцій аналіз спрямовують ті самі принципи, і кожен крок лишається логічно обґрунтованим і методологічно послідовним.

## Приклад 2

Розглянемо таку систему лінійних нерівностей:

\[\begin{cases} \log_2(2x+4) > \log_2(x) \\\\[0.9em] x - 2 > 0 \end{cases} \]

Щоб розв’язати цю нерівність, спершу потрібно визначити [область визначення](<../determining-the-domain-of-a-function/>) логарифма. Логарифм визначений лише тоді, коли його аргумент більший за нуль. Тому в цьому випадку маємо:

\[\begin{align} &2x + 4 > 0 \rightarrow x > -2 \\\\[0.6em] &x > 0 \rightarrow x > 0 \end{align} \]

Перетин цих двох умов дає \( x > 0 \). На цьому етапі переходимо до першої нерівності. Оскільки логарифми \( \log_2(2x + 4) \) і \( \log_2(x) \) мають однакову основу, нерівність можна аналізувати, безпосередньо порівнявши аргументи двох логарифмічних виразів.

\[2x+4 > x \rightarrow x > -2\]

Тепер, перетнувши цей розв’язок з областю визначення логарифма, отримуємо \( x > 0 \). Розглянувши другу нерівність, отримуємо \( x > 2 \). Тепер перевіримо, де обидва розв’язки виконуються одночасно:

| \[0\]| \[2\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Розв’язок системи: \[x> 2\]

## Системи нерівностей з кількома змінними

Існують і складніші системи нерівностей, що складаються з \( k \) нерівностей з \( m \) змінними й мають загальний вигляд:

\[\begin{cases} f_1(x_1, x_2, \ldots x_m) \geq 0 \\\\[0.6em] f_2(x_1, x_2, \ldots x_m) \geq 0 \\\\[0.6em] \quad \quad \quad \vdots \\\\[0.6em] f_k(x_1, x_2, \ldots x_m) \geq 0 \end{cases} \]

Ці системи потребують складніших методів розв’язування, таких як графічні методи, метод інтервалів, лінійне програмування та різні чисельні прийоми. Тому їх буде докладніше розглянуто в інших розділах.
