## Вступ

[Модуль](<../absolute-value/>) дійсного числа \(x\) означають так:

\[|x| = \begin{cases} +x & \text{якщо } x \geq 0 \\\\[6pt] -x & \text{якщо } x < 0 \end{cases} \, \forall \, x \in \mathbb{R} \]

Геометрично \(|x|\) — це відстань від \(x\) до початку координат на числовій прямій, а загальніше \(|x - a|\) — відстань між \(x\) і точкою \(a\). Це геометричне тлумачення нерідко найприродніше для розуміння нерівностей з модулем, і саме на нього спирається інтуїція, що стоїть за методами розв’язування, розглянутими нижче.


Властивості, на яких ґрунтується розв’язування таких нерівностей, такі. Для кожного [дійсного числа](<../properties-of-real-numbers/>) \(k > 0\) і кожного дійсного виразу \(f(x)\) виконуються такі рівносильності:

  * \( |f(x)| \leq k \quad \) якщо \( -k \leq f(x) \leq k.\)

  * \(|f(x)| \geq k \quad \) якщо \(f(x) \leq -k \, \) або \( \, f(x) \geq k.\)


Ті самі рівносильності природно поширюються на випадки строгих нерівностей, якщо замінити \(\leq\) на \(<\), а \(\geq\) на \(>\). Коли \(k = 0\), нерівність \(|f(x)| \leq 0\) виконується лише тоді, коли \(f(x) = 0\), бо модуль завжди невід’ємний. Для \(k < 0\) нерівність \(|f(x)| \leq k\) не має розв’язків для жодного \(x\).

Альтернативний метод, застосовний щоразу, коли вираз під модулем [лінійний](<../linear-inequalities/>), полягає в аналізі знака аргумента за допомогою його кускового означення. Знаходять точку, у якій аргумент перетворюється на нуль, ділять числову пряму на два відповідні промені й переписують нерівність окремо на кожному з них, прибравши модуль. Тоді часткові розв’язки збирають об’єднанням.

###### Розв’язування нерівності з модулем ґрунтується на тому самому принципі, що й розв’язування [рівняння з модулем](<../absolute-value-equations/>): застосовують означальні властивості функції модуля, щоб алгебраїчно його усунути, зводячи задачу до набору звичайних нерівностей, які треба розв’язати й об’єднати.

## Нерівність трикутника

Фундаментальний результат, тісно пов’язаний з нерівностями з модулем, — нерівність трикутника. Для будь-яких двох дійсних чисел \(a\) і \(b\) виконується таке співвідношення:

\[|a + b| \leq |a| + |b| \]

Ця нерівність стверджує, що модуль суми ніколи не перевищує суми модулів. Її доведення та докладне обговорення наслідків наведено в статті про [модуль](<../absolute-value/>).

###### Цей результат варто пам’ятати, працюючи з виразами, що містять суми модулів, бо він одразу дає верхню межу, яка може спростити оцінки без повного розгляду випадків.

## Приклад 1

Розглянемо таку просту нерівність:

\[|x - 3| \leq 5 \]

Застосувавши основну властивість для випадку \(\leq\), отримуємо [систему](<../systems-of-inequalities/>) із двох одночасних нерівностей:

\[-5 \leq x - 3 \leq 5 \]

Щоб виразити \(x\), додаємо 3 до всіх трьох частин складеної нерівності. Ця дія припустима, бо додавання однієї й тієї самої величини до обох частин нерівності не змінює її напрямку.

\[-5 + 3 \leq x \leq 5 + 3 \]

\[-2 \leq x \leq 8 \]

Зобразивши отримані значення на числовій прямій, маємо таку картину:

| \[-2\]| \[8\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Виділений рядок показує перетин двох умов: розв’язок — це множина значень \(x\), за яких обидві нерівності виконуються одночасно. Отже, розв’язок — замкнений проміжок \([-2,\, 8]\).

Отже, розв’язок — замкнений проміжок \([-2,\, 8]\).

## Приклад 2

Розглянемо таку нерівність:

\[|2x + 1| > 3 \]

Застосувавши основну властивість для випадку \(>\), розбиваємо нерівність на дві альтернативні умови, кожна з яких має виконуватися незалежно.

\[2x + 1 < -3 \] \[2x + 1 > 3\]

Розв’язуючи першу умову, віднімаємо 1 від обох частин і отримуємо \(2x < -4\), а поділивши на 2, отримуємо \(x < -2\). Оскільки дільник додатний, напрямок нерівності зберігається.

Розв’язуючи другу умову так само й віднімаючи 1, отримуємо \(2x > 2\), а поділивши на 2, отримуємо \(x > 1\).

Зобразивши отримані значення на числовій прямій, маємо таку картину:

| \[-2\]| \[1\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Як і в розглянутому раніше випадку, виділений рядок показує об’єднання двох умов: розв’язок — це множина значень \(x\), за яких виконується принаймні одна з двох нерівностей.

Отже, розв’язок — об’єднання відкритих проміжків \((-\infty,\, -2) \cup (1,\, +\infty)\).

## Приклад 3

Розглянемо таку нерівність, у якій з’являються два різні модулі:

\[|x + 1| + |x - 2| > 4 \]

Коли нерівність містить більше ніж один модуль, найсистематичніший підхід — розбити числову пряму за нулями аргументів. Вирази \(x + 1\) і \(x - 2\) перетворюються на нуль за \(x = -1\) і \(x = 2\) відповідно, що дає три області, які слід проаналізувати окремо.


Випадок \(x < -1\). У цій області \(x + 1 < 0\) і \(x - 2 < 0\), тож обидва аргументи від’ємні, і модуль змінює їхній знак. Нерівність набуває такого вигляду:

\[-(x + 1) + (-(x - 2)) > 4 \]

\[-x - 1 - x + 2 > 4 \]

\[-2x + 1 > 4 \]

Віднявши 1 від обох частин, отримуємо \(-2x > 3\). Поділивши на \(-2\) і змінивши напрямок нерівності, бо дільник від’ємний, отримуємо таке:

\[x < -\frac{3}{2} \]

Ця умова має виконуватися в області \(x < -1\). Оскільки \(-\frac{3}{2} < -1\), умова \(x < -\frac{3}{2}\) жорсткіша з двох, і перетин із \(x < -1\) зводиться до \(x < -\frac{3}{2}\). Отже, внесок цього випадку — \(\left(-\infty,\, -\frac{3}{2}\right)\).


Випадок \(-1 \leq x < 2\). У цій області \(x + 1 \geq 0\) і \(x - 2 < 0\). Нерівність набуває такого вигляду:

\[(x + 1) + (-(x - 2)) > 4 \]

\[x + 1 - x + 2 > 4 \]

\[3 > 4 \]

Це суперечність, яка не виконується за жодного значення \(x\). Тому випадок II розв’язків не дає.


Випадок \(x \geq 2\). У цій області \(x + 1 > 0\) і \(x - 2 \geq 0\), тож обидва аргументи невід’ємні, і модуль залишає їх без змін. Нерівність набуває такого вигляду:

\[(x + 1) + (x - 2) > 4 \]

\[2x - 1 > 4 \]

Додавши 1 до обох частин, отримуємо \(2x > 5\), а поділивши на 2, отримуємо таке:

\[x > \frac{5}{2} \]

Перетинаючи із \(x \geq 2\): оскільки \(\frac{5}{2} > 2\), визначальною є умова \(x > \frac{5}{2}\). Отже, внесок цього випадку — \(\left(\frac{5}{2},\, +\infty\right)\).


Зібравши внески з усіх трьох випадків, часткові розв’язки, отримані на кожній області числової прямої, зображено нижче.

| \[-\frac{3}{2}\]| \[\frac{5}{2}\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Об’єднання двох відкритих променів дає повну множину розв’язків.

Отже, розв’язок нерівності:

\[\left(-\infty,\, -\frac{3}{2}\right) \cup \left(\frac{5}{2},\, +\infty\right) \]

## Приклад 4

Розглянемо тепер складніший випадок, у якому права частина нерівності — не фіксоване число, а [дійсний параметр](<../equations-with-parameters/>) \(k\). Будова множини розв’язків залежить від значення \(k\), і повний розгляд потребує окремого опрацювання кількох випадків. Розглянемо таку нерівність:

\[|x - 1| > k \]

Поведінка розв’язку суттєво змінюється залежно від того, від’ємне \(k\), нульове чи додатне, і саме це ми збираємося визначити.


Випадок \(k < 0\). Оскільки модуль завжди невід’ємний, ліва частина задовольняє \(|x - 1| \geq 0 > k\) для кожного дійсного \(x\). Отже, нерівність виконується для всіх дійсних чисел, і розв’язок — \(\mathbb{R}\).


Випадок \(k = 0\). Нерівність зводиться до \(|x - 1| > 0\), що виконується для кожного \(x\), крім точки, де модуль перетворюється на нуль. Оскільки \(|x - 1| = 0\) тоді й лише тоді, коли \(x = 1\), розв’язок — \(\mathbb{R} \setminus {1}\).


Випадок \(k > 0\). Застосувавши основну властивість для випадку \(>\), розбиваємо нерівність на дві альтернативні умови:

\[x - 1 < -k \] \[x - 1 > k\]

Додавши 1 до обох частин кожної умови, отримуємо таке:

\[x < 1 - k \qquad \text{або} \qquad x > 1 + k \]


Зобразивши розв’язок на числовій прямій, маємо таку картину:

| \[1-k\]| \[1+k\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Зауважте, що коли \(k \to 0^+\), дві межові точки \(1 - k\) і \(1 + k\) наближаються до 1 з протилежних боків, а множина розв’язків наближається до \(\mathbb{R} \setminus \\{1\\}\), що узгоджується з випадком \(k = 0\).

Отже, розв’язок — об’єднання двох відкритих проміжків: \[\left(-\infty,\, 1-k\right) \cup \left(1+k,\, +\infty\right)\]

## Нерівності зі змінною правою частиною

Наведені вище рівносильності припускають, що права частина — додатна стала \(k\). Коли права частина сама є функцією від \(x\), скажімо \(g(x)\), ситуація потребує додаткової уважності. Розглянемо таку нерівність.

\[|f(x)| \leq g(x) \]

Застосувавши ті самі міркування, що й раніше, отримуємо, що вона рівносильна такій складеній нерівності.

\[-g(x) \leq f(x) \leq g(x) \]

Проте це зведення правильне лише тоді, коли \(g(x) > 0\). Якщо \(g(x) \leq 0\) у якійсь точці, нерівність \(|f(x)| \leq g(x)\) там виконуватися не може, бо ліва частина завжди невід’ємна. Тому правильний підхід — накласти \(g(x) > 0\) як необхідну умову й перетнути її з розв’язком складеної нерівності. Як конкретний приклад розглянемо таку.

\[|x - 1| \leq 2x - 3 \]

Права частина \(g(x) = 2x - 3\) додатна лише тоді, коли \(x > \frac{3}{2}\). Поза цією областю нерівність не має розв’язків незалежно від значення \(|x - 1|\). В області \(x > \frac{3}{2}\) нерівність рівносильна такій системі.

\[-(2x - 3) \leq x - 1 \leq 2x - 3 \]

Ліва нерівність \(-(2x - 3) \leq x - 1\) спрощується до \(-2x + 3 \leq x - 1\), тобто \(4 \leq 3x\), звідки \(x \geq \frac{4}{3}\). Права нерівність \(x - 1 \leq 2x - 3\) спрощується до \(2 \leq x\), звідки \(x \geq 2\). Оскільки \(\frac{4}{3} < \frac{3}{2} < 2\), умова \(x \geq \frac{4}{3}\) уже випливає з вимоги \(x > \frac{3}{2}\), а визначальне обмеження з-поміж усіх трьох — \(x \geq 2\). Зобразивши розв’язок на числовій прямій, маємо таку картину.

| \[\frac{4}{3}\]| \[\frac{3}{2}\]| \[2\]|   
---|---|---|---|---  
| | | |   
| | | |   
| | | |   
| | | |   
| | | |   
  
Три критичні значення на графіку відображають три незалежні умови, виведені під час розв’язування: поріг \(\frac{4}{3}\) з лівої нерівності, поріг \(\frac{3}{2}\) із вимоги додатності \(g(x)\) і поріг 2 з правої нерівності. Оскільки кожна умова жорсткіша за попередню, остаточний розв’язок цілком визначається найправішою межею.

Отже, розв’язок — проміжок \([2, +\infty)\).
