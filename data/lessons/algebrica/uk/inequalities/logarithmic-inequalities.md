## Вступ

Логарифмічні нерівності — це нерівності, що містять один чи кілька [логарифмічних](<../logarithms>) виразів, у яких невідома \(x\) стоїть або в аргументі логарифма, або, в окремих випадках, в самій основі. Перш ніж братися за логарифмічні нерівності, необхідно добре розуміти логарифми, їхні основні властивості та стандартні методи розв’язування [логарифмічних рівнянь](<../logarithmic-inequalities/>), бо ці інструменти вирішальні для правильного підходу до таких нерівностей і їх розв’язування.


Логарифмічні нерівності можуть мати загальний вигляд:

\[\log_af(x) \lesseqgtr \log_ag(x) \]

  * \(a\) — основа логарифма, де (a > 0) і \(a \neq 1.\)
  * \(f(x)\) і \(g(x)\) — алгебраїчні вирази, що залежать від змінної \(x.\)
  * Символ \(\lesseqgtr\) позначає одне зі співвідношень \(\le\), \(=\) або \(\ge.\)


Крім того, щоб нерівність була коректно визначена, мають виконуватися такі умови:

\[\begin{cases} f(x) > 0\\\\[0.6em] g(x) > 0\\\\[0.6em] \end{cases} \]


Нерівність, що містить логарифмічний вираз, у якому невідома змінна не входить ні в аргумент, ні в основу логарифма, не є логарифмічною нерівністю. Іншими словами, нерівність на кшталт: \[\log_3(9) - 3x > 0 \] не є логарифмічною нерівністю, бо логарифмічний доданок — стала. Натомість  
\[\log_3(9x) - 3x > 0 \] є логарифмічною нерівністю, бо змінна \(x\) стоїть у аргументі логарифма й безпосередньо впливає на його область визначення та поведінку.

## Як розв’язувати логарифмічні нерівності

Процес розв’язування логарифмічних нерівностей загальний, проте для зручності пояснення розглянемо таку нерівність: \[\log_a f(x) \ge \log_a g(x) \]

Процедуру можна структурувати в чотири основні кроки:

  * Визначте [область визначення](<../determining-the-domain-of-a-function/>) нерівності, накладаючи умови допустимості. Аргументи всіх логарифмічних виразів мають бути строго додатними, а основа має задовольняти: \[\begin{cases} f(x) > 0 \\\\[0.6em] g(x) > 0 \\\\[0.6em] \end{cases} \]

  * Основа має задовольняти: \[\begin{cases} a > 0 \\\\[0.6em] a \neq 1 \\\\[0.6em] \end{cases} \]

  * Якщо \(a > 1\), логарифмічна функція [зростає](<../increasing-and-decreasing-functions/>), і нерівність зберігає свій напрямок, коли логарифми прибирають.

  * Якщо \(0 < a < 1\), логарифмічна функція спадає, і напрямок нерівності слід змінити на протилежний, коли усувають логарифми.

  * Скористайтеся монотонністю логарифмічної функції, щоб усунути логарифми й звести задачу до рівносильної алгебраїчної нерівності з \(f(x)\) і \(g(x)\).

  * Розв’яжіть отриману алгебраїчну нерівність і перетніть множину розв’язків із визначеною раніше областю визначення, відкинувши всі значення, що не задовольняють початкові логарифмічні умови.


Щоб пояснити роль основи логарифма, пригадаймо поведінку [логарифмічної функції](<../logarithmic-function/>), коли \(0 < a < 1\). З її графіка бачимо, що функція строго спадає на всій області визначення з вертикальною асимптотою вздовж осі \(y\):

![Графік логарифмічної функції з основою між нулем і одиницею.](/diagrams/algebrica/logharithm-5-1.png)

##### Пунктирна крива зображує логарифмічну функцію з основою \(a > 1\). У цьому випадку функція строго зростає. В обох випадках, коли \(x = 1\), значення логарифмічної функції дорівнює 0, і графіки перетинаються в точці \((1,0)\).

## Приклад 1

Розглянемо логарифмічну нерівність: \[\log_{\frac{1}{2}}(x + 3) \ge \log_{\frac{1}{2}}(2x - 1) \]

Почнімо з визначення області визначення нерівності. Аргументи логарифмів мають бути строго додатними: \[\begin{cases} x + 3 > 0 \\\\[0.6em] 2x - 1 > 0 \end{cases} \]

Використавши графічне зображення й розглянувши проміжки розв’язків [лінійних нерівностей](<../linear-inequalities/>) у попередній системі, бачимо, що їхній перетин, який визначає область визначення логарифмічної нерівності, дорівнює саме \(x > 1/2\).

| \[-3\]| \[\frac{1}{2}\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Отже, область визначення \(D\) початкової нерівності — такий проміжок: \[\left(-\frac{1}{2}, +\infty\right) \]


Далі проаналізуємо основу логарифма. Оскільки основа задовольняє \[0 < \frac{1}{2} < 1 \] логарифмічна функція строго спадає. Як наслідок, коли логарифми усувають, напрямок нерівності слід змінити на протилежний. Тому задана нерівність: \[\log_{\frac{1}{2}}(x + 3) \ge \log_{\frac{1}{2}}(2x - 1) \] рівносильна: \[x + 3 \le 2x - 1 \]


Тепер розв’яжемо отриману алгебраїчну нерівність: \[x + 3 \le 2x - 1 \quad \rightarrow \quad x \ge 4 \]

Нарешті, перетнемо цей результат із визначеною раніше областю визначення. Оскільки область визначення вимагає \(x > \frac{1}{2}\), умова \(x \ge 4\) допустима.

Отже, множина розв’язків логарифмічної нерівності: \[x \ge 4 \]

## Приклад 2

Розглянемо логарифмічну нерівність:

\[\log_{\frac{1}{2}}(x+1) > \log_2(2-x) \]

Почнімо з визначення [області визначення](<../determining-the-domain-of-a-function/>). Аргументи логарифмів мають бути строго додатними, отже:

\[\begin{cases} x+1 > 0 \\\\[0.6em] 2-x > 0 \\\\[0.6em] \end{cases} \]

Використавши графічне зображення й розглянувши проміжки розв’язків лінійних нерівностей у попередній системі, бачимо, що їхній перетин — \( -1 < x < 2\).

| \[-1\]| \[2\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Отже, область визначення \(D\) початкової нерівності — такий проміжок: \[(-1, 2) \]


Далі перепишемо логарифм з основою \(\tfrac{1}{2}\) через основу 2. Оскільки \(\tfrac{1}{2} = 2^{-1}\), маємо \[\log_{\frac{1}{2}}(x+1) = \frac{\log_2(x+1)}{\log_2(\frac{1}{2})} = -\log_2(x+1) \]

Підставивши в початкову нерівність, отримуємо:

\[\log_2(x+1) < -\log_2(2-x) \]

Перенісши всі логарифмічні доданки в одну частину й застосувавши властивості логарифмів, отримуємо: \[\log_2(x+1) + \log_2(2-x) < 0 \]

що за властивістю суми логарифмів, згідно з якою [сума двох логарифмів](<../logarithms>) дорівнює логарифму їхнього добутку, дає змогу переписати вираз так:

\[\log_2!\bigl((x+1)(2-x)\bigr) < 0 \]

Оскільки логарифмічна функція з основою \(2>1\) строго зростає, ця нерівність рівносильна \[0 < (x+1)(2-x) < 1 \]

В області визначення \((-1,2)\) добуток \((x+1)(2-x)\) завжди додатний, тож достатньо розв’язати:

\[(x+1)(2-x) < 1 \]

Розкривши дужки й спростивши, отримуємо \[x^2 - x - 1 > 0 \]

Пов’язане [квадратне рівняння](<../quadratic-equations>) має корені: \[x = \frac{1 \pm \sqrt{5}}{2} \]

Нерівність виконується поза проміжком, який визначають ці корені. Перетнувши цей результат з областю визначення \((-1,2)\), нарешті отримуємо множину розв’язків: \[-1 < x < \frac{1-\sqrt{5}}{2}\]
