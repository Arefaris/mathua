# Неполные квадратные уравнения


## Определение

Квадратное уравнение называется неполным, если в стандартном виде \(ax^2 + bx + c = 0\) отсутствует одно или оба слагаемых \(bx\) и \(c\), при условии что слагаемое \(ax^2\) присутствует. Такие уравнения допускают прямые методы решения, не требующие ни формулы корней квадратного уравнения, ни разложения на множители. 


Когда \(b\) и \(c\) оба равны нулю, уравнение сводится к:

\[ax^2 = 0, \quad a \neq 0\]

Разделив обе части на \(a\), которое по условию отлично от нуля, получаем \(x^2 = 0\), и единственное действительное решение — \(x = 0\) при любом допустимом значении \(a\).

> Графически уравнению соответствует парабола с вершиной в начале координат \((0, 0)\), симметричная относительно оси y. График раскрыт вверх при \(a > 0\) и вниз при \(a < 0\); величина \(a\) определяет ширину параболы. Хотя у уравнения единственное решение, у функции двойной корень в точке \(x = 0\): ось x касается параболы в начале координат.

## Случай b = 0

Когда \(b = 0\), уравнение принимает вид:

\[ax^2 + c = 0, \quad a \neq 0,\\, c \neq 0\]

Выразив \(x^2\), получаем:

\[x^2 = -\frac{c}{a}\]

Уравнение задаёт параболу, симметричную относительно оси y. Когда \(a\) и \(c\) имеют противоположные знаки, величина \(-c/a\) положительна и у уравнения два различных действительных решения:

\[x_{1,2} = \pm\sqrt{-\frac{c}{a}}\]

Парабола пересекает ось x в двух точках, симметричных относительно начала координат. Когда \(a\) и \(c\) имеют одинаковые знаки, величина \(-c/a\) отрицательна и у уравнения нет действительных решений:

\[-\frac{c}{a} < 0 \implies x \notin \mathbb{R}\]

Парабола целиком лежит выше или ниже оси x и не пересекает её.

## Случай c = 0

Когда \(c = 0\), уравнение принимает вид:

\[ax^2 + bx = 0, \quad a \neq 0,\\, b \neq 0\]

Вынесение \(x\) за скобки приводит к \(x(ax + b) = 0\). По свойству нулевого произведения либо \(x = 0\), либо \(ax + b = 0\), и у уравнения два различных действительных решения:

\[x_1 = 0 \qquad x_2 = -\frac{b}{a}\]

## Примеры

Рассмотрим уравнение \(3x^2 = 0\). Поскольку \(b\) и \(c\) оба равны нулю, единственное решение — \(x = 0\).


Рассмотрим уравнение \(2x^2 - 8 = 0\). Оно имеет вид \(ax^2 + c = 0\), где \(a = 2\) и \(c = -8\). Поскольку \(a\) и \(c\) имеют противоположные знаки, существуют два действительных решения. Выразив \(x^2\), получаем:

\[x^2 = \frac{8}{2} = 4\]

Извлекая квадратный корень из обеих частей, получаем два решения:

\[x_{1,2} = \pm\sqrt{4} = \pm 2\]


Рассмотрим уравнение \(x^2 + 5 = 0\). Здесь \(a = 1\) и \(c = 5\) имеют одинаковые знаки, так что \(-c/a = -5 < 0\). У уравнения нет действительных решений.


Рассмотрим уравнение \(3x^2 - 6x = 0\). Оно имеет вид \(ax^2 + bx = 0\), где \(a = 3\) и \(b = -6\). Вынесение \(x\) за скобки приводит к \(x(3x - 6) = 0\), и два решения:

\[x_1 = 0 \qquad x_2 = \frac{6}{3} = 2\]

## Типичная ошибка, которой нужно избегать

Для уравнений вида \(ax^2 + bx = 0\) частая ошибка состоит в делении обеих частей на \(x\), когда уравнение записано в виде:

\[ax^2 = bx\]

Деление на \(x\) здесь недопустимо, так как \(x = 0\) само является решением, а деление на нуль не определено. Это преобразование теряет корень \(x = 0\) и сводит уравнение к линейному, оставляя только решение \(x = -b/a\). Правильный подход — вынести \(x\) за скобки как общий множитель, как показано выше.
