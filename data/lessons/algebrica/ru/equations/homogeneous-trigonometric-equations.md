## Что такое однородные тригонометрические уравнения

Однородные тригонометрические уравнения — это [уравнения](<../equations>), в которых все слагаемые содержат тригонометрические функции, например [синус и косинус](<../sine-and-cosine>), [возведённые](<../powers>) в одну и ту же степень. Однородное тригонометрическое уравнение первой степени обычно записывается в виде:

\[a \sin x + b \cos x = 0 \]

Каждое слагаемое уравнения имеет степень 1, а \( a \) и \( b \) — [действительные коэффициенты](<../types-of-numbers>). Общий вид тригонометрического уравнения первой степени:

\[a \sin x + b \cos x + c = 0 \]

Это уравнение считается однородным, когда свободный член \( c = 0 \). Аналогичные соображения применимы к однородным тригонометрическим уравнениям второй степени, которые включают только слагаемые второй степени. Такие уравнения обычно записывают в виде:

\[a \sin^2 x + b \sin x \cos x + c \cos^2 x = 0 \]

##### Определение можно обобщить на уравнения третьей, четвёртой, пятой степени и так далее. В этих случаях все слагаемые должны содержать тригонометрические [функции](<../functions>) в одной и той же степени, что сохраняет однородность уравнения.

Однородные уравнения степени \( n \) можно решить, разделив каждое слагаемое уравнения на \( \cos^n x \) и тем самым преобразовав уравнение в выраженное через \( \tan x \).

## Пример 1

Решим однородное тригонометрическое уравнение первой степени: \[\sin x - \sqrt{3} \cos x = 0 \]


Разделив уравнение на \( \cos x \), получаем:

\[\frac{\sin x}{\cos x} - \sqrt{3} = 0\]

Так как отношение синуса к косинусу равно [тангенсу](<../tangent-and-cotangent>), уравнение можно переписать через \( \tan x. \)

\[\tan x = \sqrt{3}\]

Решая уравнение, получаем значение:

\[x = \arctan(\sqrt{3}) = \frac{\pi}{3} \]

Так как тангенс периодичен с периодом \( \pi \), общее решение таково:

\[x = \frac{\pi}{3} + k\pi, \quad k \in \mathbb{Z} \]

Всякий раз, когда [тригонометрические тождества](<../trigonometric-identities/>) позволяют переписать тригонометрическое уравнение в однородном виде, это, как правило, предпочтительно, так как может упростить вычисления и сделать процесс решения более управляемым.

## Пример 2

Рассмотрим теперь тригонометрическое уравнение второй степени:

\[\sin^2 x + \sin 2x - \cos^2 x = 0 \]

На первый взгляд это не однородное уравнение, потому что не все слагаемые имеют одну степень. В частности, \( \sin 2x \) — слагаемое первой степени, тогда как \( \sin^2 x \) и \( \cos^2 x \) содержат выражения второй степени. В таком уравнении нельзя разделить все слагаемые на \( \cos^2 x \), потому что слагаемое первой степени не превращается в выражение, полезное для решения уравнения. В самом деле, этот метод работает только когда все слагаемые имеют одну и ту же степень, как в однородных уравнениях.


Однако с помощью [тригонометрических тождеств](<../trigonometric-identities/>), а именно формулы двойного угла, мы можем переписать \( \sin(2x) \) как \( 2\sin(x)\cos(x) \). Тогда уравнение принимает вид:

\[\sin^2 x + 2\sin x \cos x - \cos^2 x = 0 \]

Так мы преобразовали исходное уравнение в однородное тригонометрическое уравнение второй степени, которое теперь можно решить, разделив все слагаемые на \( \cos^2 x \). Уравнение принимает вид:

\[\frac{\sin^2 x}{\cos^2 x} + \frac{2\sin x \cos x}{\cos^2 x} - \frac{\cos^2 x}{\cos^2 x} = 0 \]


Упростив каждое слагаемое, получаем:

\[\tan^2 x + 2\tan x - 1 = 0 \]

Это [квадратное уравнение](<../quadratic-equations>) относительно \( \tan x \), и теперь его можно решить по [формуле корней квадратного уравнения](<../quadratic-formula>). Сделаем замену \( t = \tan x \). Уравнение принимает вид:

\[t^2 + 2t - 1 = 0 \]

По формуле корней квадратного уравнения имеем:

\[t = \frac{-2 \pm \sqrt{4 + 4}}{2} = \frac{-2 \pm 2\sqrt{2}}{2} = -1 \pm \sqrt{2} \]

Два решения таковы:

\[t_1 = -1 + \sqrt{2}, \quad t_2 = -1 - \sqrt{2} \]


Вернувшись к \( t = \tan x \), получаем решения:

\[\tan x = -1 + \sqrt{2} \quad \text{и} \quad \tan x = -1 - \sqrt{2} \]

Общие решения таковы:

\[x_1 = \arctan(-1 + \sqrt{2}) + k\pi \quad k \in \mathbb{Z} \] \[x_2 = \arctan(-1 - \sqrt{2}) + k\pi \quad k \in \mathbb{Z} \]
