## Что такое трёхчленные уравнения

Трёхчленные уравнения — особый вид [алгебраическых уравнений](<../polynomial-equations/>), состоящих из трёх членов, содержащих константы и [степени](<../powers>) переменной.

\[ax^{2n} + bx^{n} + c = 0 \]

Эта форма особенно полезна, потому что допускает приёмы подстановки, например \(x^n = y\), превращающие уравнение в стандартное квадратное.

  * \( a \), \( b \) и \( c \) — числовые коэффициенты.
  * \( x \) — неизвестная переменная.


Стоит отметить, что при \( n = 1 \) уравнение становится [квадратным уравнением](<../quadratic-equations>), часто записываемым в виде:

\[ax^2 + bx + c = 0 \]

## Как решать трёхчленные уравнения

Для решения трёхчленного уравнения вида \( ax^{2n} + bx^n + c = 0 \) можно следовать общему набору шагов. Первый шаг — сделать подстановку, превращающую уравнение в квадратное относительно \( y \), которое решить проще. Например, положим:

\[x^n = y \]

и получим:

\[ay^2 + by + c = 0 \]

Для решения получившегося квадратного уравнения относительно \( y \) можно использовать такие приёмы, как [разложение на множители](<../factoring-quadratic-equations>), [выделение полного квадрата](<../completing-the-square>) или [формула корней квадратного уравнения](<../quadratic-formula>). Найдя решения для \( y \), подставляем их обратно по исходной подстановке \( y = x^n \), чтобы определить соответствующие значения \( x \). Кратко:

  * Пусть \( y = x^n \), тогда уравнение принимает вид \( ay^2 + by + c = 0 \).

  * Решите квадратное уравнение относительно \( y \).

  * Для каждого решения \( y_i \) решите \( x^n = y_i \), чтобы найти соответствующие значения \( x \).

  * Проверьте все решения в исходном уравнении, чтобы убедиться, что они допустимы.


##### Важно проверять каждое решение подстановкой в исходное уравнение, чтобы убедиться в его допустимости. Процесс может показаться сложным, но на самом деле он практичен и прост в применении.

При решении уравнений подстановкой иногда могут появляться лишние решения, называемые посторонними. Они могут удовлетворять преобразованному уравнению, но не исходному. Подставляя каждое решение обратно в исходное уравнение, мы убеждаемся, что оно действительно подходит и не нарушает никаких неявных условий.

## Пример

Решите уравнение \(3x^4-7x^2 + 2 = 0\).

Сделаем подстановку \(y = x^2\), чтобы превратить уравнение в квадратное:

\[3y^2-7y + 2 = 0\]


Для нахождения значения \(y\) воспользуемся [формулой корней квадратного уравнения](<../quadratic-formula>). Получаем:

\begin{align*} y &= \frac{{-(-7) \pm \sqrt{{(-7)^2-4 \cdot 3 \cdot 2}}}}{{2 \cdot 3}} \\\\[0.6em] &= \frac{{7 \pm \sqrt{{49-24}}}}{6} \\\\[0.6em] &= \frac{{7 \pm \sqrt{25}}}{6} \\\\[0.6em] &= \frac{{7 \pm 5}}{6} \end{align*}

Итак, мы нашли:

\[y_1 = \frac{12}{6} = 2\] \[y_2 = \frac{2}{6} = \frac{1}{3}\]


После того как решения для \(y\) найдены, их можно подставить обратно в исходное уравнение при \(x^2 = y\), чтобы найти соответствующие значения \(x\).

При \(y = 2\) имеем: \[x^2 = 2 \quad \rightarrow \quad x = \pm \sqrt{2} \]

При \(y = \frac{1}{3}\) имеем \[x^2 = \frac{1}{3} \quad \rightarrow \quad \pm \sqrt{\frac{1}{3}} \]


Важно убедиться в правильности решений, подставив их обратно в исходное уравнение. Чтобы проверить, являются ли данные значения решениями уравнения \(3x^4-7x^2 + 2 = 0\), нужно подставить их в уравнение и проверить, выполняются ли они.

При \( x = \sqrt{2} \):

\[3(\sqrt{2})^4-7(\sqrt{2})^2 + 2 = 3 \cdot 2^2-7 \cdot 2 + 2 \] \[= 12 - 14 + 2 = 0 \]


При \( x = -\sqrt{2} \): \[3(-\sqrt{2})^4-7(-\sqrt{2})^2 + 2 = 3 \cdot 2^2-7 \cdot 2 + 2 \] \[= 12 - 14 + 2 = 0 \]


При \( x = \sqrt{\dfrac{1}{3}} \): \[3\left(\sqrt{\frac{1}{3}}\right)^4-7\left(\sqrt{\frac{1}{3}}\right)^2 + 2 = 3 \cdot \left(\frac{1}{3}\right)^2 - 7 \cdot \frac{1}{3} + 2 \] \[= \frac{3}{9}-\frac{7}{3} + 2 = 0 \]


При \( x = -\sqrt{\dfrac{1}{3}} \): \[3\left(-\sqrt{\frac{1}{3}}\right)^4-7\left(-\sqrt{\frac{1}{3}}\right)^2 + 2 = 3 \cdot \left(\frac{1}{3}\right)^2-7 \cdot \frac{1}{3} + 2 \] \[= \frac{3}{9}- \frac{7}{3} + 2 = 0 \]

Все решения удовлетворяют исходному уравнению.

Решение уравнения: \[x = \pm \sqrt{2} \quad \text{и} \quad \pm \sqrt{\frac{1}{3}}\]
