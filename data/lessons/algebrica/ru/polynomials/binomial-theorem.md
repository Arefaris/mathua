## Бином Ньютона

![Треугольник Паскаля](svg/pascals-triangle.svg)

## Формулировка

Бином Ньютона утверждает, что для любого натурального числа \(n\) выражение \((a+b)^n\) можно разложить в конечную сумму \(n+1\) слагаемых. Каждое слагаемое состоит из биномиального коэффициента, умноженного на степень \(a\) и степень \(b\):

\[
(a + b)^n = \binom{n}{0} a^n b^0 + \binom{n}{1} a^{n-1} b^1 + \ldots + \binom{n}{n-1} a^1 b^{n-1} + \binom{n}{n} a^0 b^n
\]

+ Показатель \(n\) — натуральное число, то есть \(n \in \mathbb{N}^+\).
+ Основание \(a\) возводится в убывающую степень, от \(n\) до 0
+ Основание \(b\) возводится в возрастающую степень, от 0 до \(n\).
+ Множитель \(\dbinom{n}{k}\) — биномиальный коэффициент, где индекс \(k\) принимает целые значения от 0 до \(n\).

> Коэффициенты \(\binom{n}{k}\), входящие в разложение, в точности соответствуют элементам \(n\)-й строки треугольника Паскаля. Симметрия \(\binom{n}{k} = \binom{n}{n-k}\) отражает тот факт, что выбрать \(k\) элементов из множества из \(n\) равносильно тому, чтобы оставить в стороне остальные \(n-k\).

В компактной форме бином Ньютона можно записать как сумму \(n+1\) слагаемых:

\[
(a + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^k
\]

## Биномиальный коэффициент

Биномиальный коэффициент выражает число способов выбрать \(k\) предметов из множества из \(n\) элементов без учёта порядка выбора. В комбинаторике его обычно читают как «из n по k» и обозначают так:

\[
\binom{n}{k} = \begin{cases}
\displaystyle \frac{n!}{k!\,(n-k)!} & 0 \leq k \leq n \\\\[6pt]
0 & n < k
\end{cases}
\]

- \(n, k \in \mathbb{N}\).
- \(n\) — общее число элементов множества.
- \(k\) — число выбираемых предметов.
- \(n!\) и \((n-k)!\) — факториалы натуральных чисел \(n\) и \(n-k\) соответственно.

## Доказательство

Есть два стандартных доказательства теоремы. Первое основано на комбинаторном рассуждении. Разложение \((a+b)^n\) можно рассматривать как произведение \(n\) одинаковых множителей:

\[
(a+b)^n = \underbrace{(a+b)(a+b)\cdots(a+b)}_{n \text{ множителей}}
\]

Каждое слагаемое раскрытого произведения получается выбором \(a\) или \(b\) из каждого множителя. Слагаемое вида \(a^{n-k} b^k\) возникает, когда \(b\) выбирается ровно из \(k\) из \(n\) множителей, а \(a\) — из остальных \(n-k\). Число таких выборов равно \(\binom{n}{k}\) — оно перечисляет \(k\)-элементные подмножества из \(n\) множителей. Суммирование по всем возможным значениям \(k\) от 0 до \(n\) доказывает теорему.

Второе доказательство использует математическую индукцию по \(n\). При \(n = 1\) тождество принимает вид \((a+b)^1 = a + b\), что, очевидно, верно. Предположим, что теорема верна для некоторого целого числа \(n \geq 1\). Умножив обе части предположения индукции на \((a+b)\), получаем:

\[
\begin{align}
(a+b)^{n+1} &= (a+b) \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^k \\\\[6pt]
&= \sum_{k=0}^{n} \binom{n}{k} a^{n-k+1} b^k + \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^{k+1}
\end{align}
\]

Если сдвинуть индекс во второй сумме, положив \(j = k+1\), и выделить крайние слагаемые, получим:

\[
(a+b)^{n+1} = a^{n+1} + \sum_{k=1}^{n} \left[\binom{n}{k} + \binom{n}{k-1}\right] a^{n+1-k} b^{k} + b^{n+1}
\]

Применив тождество Паскаля \(\binom{n}{k} + \binom{n}{k-1} = \binom{n+1}{k}\) к внутренним коэффициентам, получаем:

\[
(a+b)^{n+1} = \sum_{k=0}^{n+1} \binom{n+1}{k} a^{n+1-k} b^k
\]

Это утверждение бинома Ньютона для \(n+1\), что завершает индукцию.

## Свойства биномиального разложения

Из бинома Ньютона вытекает несколько тождеств, непосредственно следующих из конкретных значений \(a\) и \(b\) или из структурных особенностей самих коэффициентов.

Сумма всех биномиальных коэффициентов порядка \(n\) получается при \(a = b = 1\) в разложении. Левая часть становится равной \(2^n\), поэтому:

\[
\sum_{k=0}^{n} \binom{n}{k} = 2^n
\]

Это тождество допускает комбинаторное истолкование: общее число подмножеств множества из \(n\) элементов равно \(2^n\), и каждое подмножество соответствует выбору некоторых \(k\) элементов из \(n\) при некотором значении \(k\) от 0 до \(n\). При \(a = 1\) и \(b = -1\) получаем тождество для знакочередующейся суммы:

\[
\sum_{k=0}^{n} (-1)^k \binom{n}{k} = 0 \qquad \text{при } n \geq 1
\]

Соотношение утверждает, что для любого натурального \(n\) число подмножеств с чётным числом элементов равно числу подмножеств с нечётным числом элементов. Коэффициенты разложения удовлетворяют соотношению симметрии:

\[
\binom{n}{k} = \binom{n}{n-k}
\]

Как следствие, разложение \((a+b)^n\) симметрично: коэффициент при \(a^{n-k} b^k\) совпадает с коэффициентом при \(a^k b^{n-k}\). Если выписать их по порядку, последовательность коэффициентов читается одинаково слева направо и справа налево.

Общий член разложения, часто обозначаемый \(T_{k+1}\), таков:

\[
T_{k+1} = \binom{n}{k} a^{n-k} b^k
\]

Индекс \(k+1\) отражает положение члена в разложении, так как \(k\) пробегает значения от 0 до \(n\), а первому члену соответствует \(k = 0\). Такая запись удобна, когда нужен конкретный член разложения без вычисления всей суммы.

## Частные случаи

Несколько классических тождеств возникают как частные случаи бинома Ньютона, и их стоит выписать явно ввиду частого использования в алгебраических преобразованиях.

Случай \(n = 2\) воспроизводит хорошо известное тождество для квадрата двучлена:

\[
(a + b)^2 = a^2 + 2ab + b^2
\]

Три коэффициента \(1, 2, 1\) соответствуют второй строке треугольника Паскаля, а в разложении есть перекрёстное слагаемое \(2ab\), возникающее из двух способов выбрать один множитель \(a\) и один множитель \(b\).

Случай \(n = 3\) даёт куб двучлена:

\[
(a + b)^3 = a^3 + 3a^2 b + 3a b^2 + b^3
\]

Коэффициенты \(1, 3, 3, 1\) образуют третью строку треугольника Паскаля. Два внутренних коэффициента равны, в согласии с соотношением симметрии \(\binom{3}{1} = \binom{3}{2}\). Когда одно из двух слагаемых равно 1, теорема сводится к разложению \((1 + x)^n\):

\[
(1 + x)^n = \sum_{k=0}^{n} \binom{n}{k} x^k
\]

Эта форма особенно важна, так как выражает \((1+x)^n\) как многочлен от \(x\), коэффициенты которого — в точности биномиальные коэффициенты порядка \(n\). Она служит также отправной точкой для обобщения на вещественные и комплексные показатели, известного как биномиальный ряд.

Положив \(x = 1\) в предыдущем тождестве, получаем уже рассмотренную сумму биномиальных коэффициентов, а положив \(x = -1\) — знакочередующуюся сумму. Эти два вычисления показывают, как частный случай \((1+x)^n\) кодирует в одном выражении структурные тождества, которым удовлетворяют биномиальные коэффициенты.

## Пример 1

Рассмотрим разложение \((x + 2)^4\) по биному Ньютона при \(a = x\), \(b = 2\) и \(n = 4\). Применяя формулу:

\[
(x + 2)^4 = \sum_{k=0}^{4} \binom{4}{k} x^{4-k} \cdot 2^k
\]

Вычисляя каждое слагаемое суммы:

\[
\begin{align}
k = 0 &\quad \binom{4}{0} x^4 \cdot 2^0 = x^4 \\\\[6pt]
k = 1 &\quad \binom{4}{1} x^3 \cdot 2^1 = 8x^3 \\\\[6pt]
k = 2 &\quad \binom{4}{2} x^2 \cdot 2^2 = 24x^2 \\\\[6pt]
k = 3 &\quad \binom{4}{3} x^1 \cdot 2^3 = 32x \\\\[6pt]
k = 4 &\quad \binom{4}{4} x^0 \cdot 2^4 = 16
\end{align}
\]

Сложив все слагаемые, получаем разложение:

\[(x+2)^4 = x^4 + 8x^3 + 24x^2 + 32x + 16\]

## Пример 2

Для двучлена с вычитанием бином Ньютона применяется с заменой \(b\) на отрицательное значение. Знаки в разложении чередуются, потому что \((-1)^k\) принимает положительное значение при чётном \(k\) и отрицательное при нечётном \(k\). Рассмотрим разложение \((x - 1)^5\), где \(a = x\), \(b = -1\) и \(n = 5\):

\[
(x - 1)^5 = \sum_{k=0}^{5} \binom{5}{k} x^{5-k} \cdot (-1)^k
\]

Каждое слагаемое суммы вычисляется так:

\[
\begin{align}
k = 0 &\quad \binom{5}{0} x^5 \cdot (-1)^0 = x^5 \\\\[6pt]
k = 1 &\quad \binom{5}{1} x^4 \cdot (-1)^1 = -5x^4 \\\\[6pt]
k = 2 &\quad \binom{5}{2} x^3 \cdot (-1)^2 = 10x^3 \\\\[6pt]
k = 3 &\quad \binom{5}{3} x^2 \cdot (-1)^3 = -10x^2 \\\\[6pt]
k = 4 &\quad \binom{5}{4} x^1 \cdot (-1)^4 = 5x \\\\[6pt]
k = 5 &\quad \binom{5}{5} x^0 \cdot (-1)^5 = -1
\end{align}
\]

Сложив все слагаемые, получаем разложение:

\[
(x - 1)^5 = x^5 - 5x^4 + 10x^3 - 10x^2 + 5x - 1
\]
