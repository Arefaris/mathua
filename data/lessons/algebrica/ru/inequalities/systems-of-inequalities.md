## Линейные системы неравенств с одной переменной

Система неравенств — это набор из двух или более неравенств, содержащих одну или несколько переменных и рассматриваемых одновременно. Цель — определить множество всех значений переменных, удовлетворяющих каждому неравенству системы одновременно. Иными словами, решение задаётся общей областью (или пересечением) отдельных множеств решений, соответствующих каждому неравенству.

В этом разделе мы сосредоточимся на линейных системах с одной действительной переменной \( x \). Такие системы обычно состоят из неравенств первой степени и могут быть записаны в общем виде:

\[\begin{cases} f_1(x) \geq 0 \\\\[0.6em] f_2(x) \geq 0 \\\\[0.6em] \quad \quad \quad \vdots \\\\[0.6em] f_k(x) \geq 0 \end{cases} \]

где \( f_i(x) \) — функции или выражения, содержащие переменную \( x \), а отношением может быть любой знак неравенства: \( <, \leq, >, \geq \). Система без решений называется несовместной. Если хотя бы одно неравенство системы не имеет решений, вся система считается несовместной.

В разделе о [линейных неравенствах](<../linear-inequalities>) мы видели примеры того, как решать неравенства, содержащие [функцию модуля](<../absolute-value-function>). В таких случаях для нахождения решения необходимо использовать систему неравенств. Рассмотрим ещё один пример решения системы линейных неравенств.

## Пример 1

Рассмотрим следующую систему линейных неравенств:

\[\begin{cases} 3x + 6 > 0 \\\\[0.6em] x - 3 \geq 0 \\\\[0.6em] 9 - x > 0 \end{cases} \]

Нужно найти значения \( x \), одновременно удовлетворяющие всем трём неравенствам. Решив отдельные неравенства, получаем:

\[\begin{cases} 3x + > -6 \rightarrow x > -2\\\\[0.6em] x \geq 3 \\\\[0.6em] -x > -9 \rightarrow x < 9 \end{cases} \]

Итак, у нас три промежутка: \(x > -2\), \(x \geq 3\), \(x<9\). Как уже сказано, решение системы — то, которое удовлетворяет всем трём неравенствам одновременно. Мы изобразим значения на числовой прямой и определим общий промежуток, отвечающий требованиям.

| \[-2\]| \[3\]| \[9\]|   
---|---|---|---|---  
| | | |   
| | | |   
| | | |   
| | | |   
| | | |   
  
Решение системы: \[x \in [3, 9)\]

##### Этот промежуток включает 3 и исключает 9. Подробнее о структуре и интерпретации промежутков см. в [специальной статье](<../determining-the-domain-of-a-function/>).

## Общая стратегия решения систем неравенств

То, что мы видели, — очень простая система из трёх линейных неравенств с переменной \( x \). Системы неравенств могут быть гораздо сложнее и могут включать рациональные функции, [корни](<../radicals>), [степени](<../powers/>), [логарифмы](<../logarithms>), показательные и [тригонометрические функции](<../sine-and-cosine>).

Хотя конкретная процедура решения зависит от вида и свойств входящих функций, главный принцип остаётся прежним: допустимые значения — те, что удовлетворяют всем неравенствам системы одновременно, то есть пересечение их отдельных множеств решений.

В общем случае решение системы неравенств следует чётко определённой последовательности шагов. Типичная процедура такова:

  * Решите каждое неравенство по отдельности и определите соответствующее множество решений.
  * Когда уместно, изобразите множества решений на числовой прямой, чтобы увидеть получающиеся промежутки.
  * Найдите пересечение всех множеств решений, поскольку системе удовлетворяют только значения, общие для каждого неравенства.
  * Запишите окончательное решение в подходящей записи промежутков, следя за тем, чтобы включение и исключение концов были указаны правильно.


##### Такой структурированный подход предоставляет надёжную основу, которую можно приспособить к самым разным задачам. По мере усложнения входящих функций анализ направляют те же принципы, гарантируя, что каждый шаг остаётся логически обоснованным и методологически последовательным.

## Пример 2

Рассмотрим следующую систему линейных неравенств:

\[\begin{cases} \log_2(2x+4) > \log_2(x) \\\\[0.9em] x - 2 > 0 \end{cases} \]

Чтобы решить это неравенство, сначала нужно определить [область определения](<../determining-the-domain-of-a-function/>) логарифма. Логарифм определён только тогда, когда его аргумент больше нуля. Поэтому в данном случае имеем:

\[\begin{align} &2x + 4 > 0 \rightarrow x > -2 \\\\[0.6em] &x > 0 \rightarrow x > 0 \end{align} \]

Пересечение этих двух условий даёт \( x > 0 \). На этом этапе обратимся к первому неравенству. Поскольку логарифмы \( \log_2(2x + 4) \) и \( \log_2(x) \) имеют одно основание, неравенство можно анализировать прямым сравнением аргументов двух логарифмических выражений.

\[2x+4 > x \rightarrow x > -2\]

Теперь, пересекая это решение с областью определения логарифма, получаем \( x > 0 \). Рассматривая второе неравенство, получаем \( x > 2 \). Теперь проверим, где оба решения выполняются одновременно:

| \[0\]| \[2\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Решение системы: \[x> 2\]

## Системы неравенств со многими переменными

Бывают и более сложные системы неравенств, состоящие из \( k \) неравенств с \( m \) переменными и имеющие общий вид:

\[\begin{cases} f_1(x_1, x_2, \ldots x_m) \geq 0 \\\\[0.6em] f_2(x_1, x_2, \ldots x_m) \geq 0 \\\\[0.6em] \quad \quad \quad \vdots \\\\[0.6em] f_k(x_1, x_2, \ldots x_m) \geq 0 \end{cases} \]

Эти системы требуют более сложных методов решения, таких как графические методы, метод интервалов, линейное программирование и различные численные методы. Поэтому они будут рассмотрены подробнее в других разделах.
