## Что такое метод интервалов

Метод интервалов для неравенств — способ определения промежутков, на которых данное выражение положительно, отрицательно или равно нулю. Этот подход особенно ценен для решения [многочленных](<../polynomials>) и [рациональных неравенств](https://algebrica.org/rational-inequalities/) и для анализа поведения функций в заданных[областях определения](<../determining-the-domain-of-a-function/>).


Знак произведения определяется тем, чётно или нечётно число отрицательных множителей. Произведение положительно, если число отрицательных множителей чётно, и отрицательно, если оно нечётно. Имеем:

\[\begin{align} +\times + &\quad = + \\\ +\times - &\quad = - \\\ -\times - &\quad = + \\\ -\times + &\quad = - \end{align} \]

## Пример 1

Рассмотрим простое [квадратное неравенство](<../quadratic-inequalities/>):

\[x^2 + x - 2 > 0 \]

Нужно определить диапазон значений x, удовлетворяющих неравенству. Сначала можно [разложить многочлен на множители](<../factoring-ac-method/>) в виде:

\[(x - 1)(x + 2) > 0 \]

По правилу знаков произведения этот многочлен, разложенный в произведение двух множителей, положителен при выполнении следующего условия:

\[\begin{align} &x - 1 > 0 \to x > 1 \\\\[6pt] &x + 2 > 0 \to x > -2 \end{align} \]

Значения \(x = 1\) и \(x = -2\) разбивают числовую прямую на непересекающиеся промежутки. Поскольку выражение [непрерывно](<../continuous-functions/>) и может менять знак только в своих нулях, его знак остаётся постоянным внутри каждого промежутка. Затем эти значения отмечаются на числовой прямой, а \(+\) и \(-\) указывают знак на каждом промежутке.

| | \[-2 \]| \[1 \]  
---|---|---|---  
\( x - 1 > 0 \)| \( \boldsymbol{-} \)| \( \boldsymbol{-} \)| \( \boldsymbol{+} \)  
\( x +2 > 0 \)| \( \boldsymbol{-} \)| \( \boldsymbol{+} \)| \( \boldsymbol{+} \)  
\( (x - 1)(x+2) > 0 \)| \( \boldsymbol{+} \)| \( \boldsymbol{-} \)| \( \boldsymbol{+} \)  
  

В последней строке записываем результат произведения знаков из строки 1 и строки 2 для каждого промежутка. Промежутки, удовлетворяющие нашему исходному неравенству \( (x - 1)(x + 2) > 0 \):

\[x < -2 \quad \text{и} \quad x > 1 \]

В записи промежутков множество решений:

\((-\infty, -2) \cup (1, +\infty) \)

###### Если неравенство нестрогое, нули выражения принадлежат решению. Для неравенства: \(x^2 + x - 2 \geq 0\) процедура та же, но поскольку неравенство выполняется и при \(f(x) = 0\), нули \(x = -2\) и \(x = 1\) входят в множество решений \((-\infty, -2] \cup [1, +\infty)\).

## Систематический порядок действий в методе интервалов

В общем случае метод интервалов для неравенств следует систематической процедуре, которая единообразно применяется к любому многочленному или рациональному выражению.

  * Перепишите неравенство в виде \(f(x) > 0\) (или \(< 0\), \(\geq 0\), \(\leq 0\)), с нулём в правой части.
  * Разложите \(f(x)\) в произведение или частное линейных или неприводимых множителей. Для рациональных неравенств анализируйте числитель и знаменатель независимо.
  * Найдите нули каждого множителя. Нули знаменателя никогда не принадлежат решению и должны быть отмечены на числовой прямой пустым кружком.
  * Расположите нули в порядке возрастания вдоль числовой прямой, тем самым разбив \(\mathbb{R}\) на непересекающиеся промежутки. Для каждого промежутка определите знак каждого множителя.
  * Объедините знаки для каждого промежутка по правилу произведения: общий знак положителен, если число отрицательных множителей чётно, и отрицателен, если нечётно. Множители чётной кратности не вызывают смены знака в соответствующем нуле.
  * Определите промежутки, на которых общий знак удовлетворяет исходному неравенству. Для строгих неравенств исключайте нули из решения; для нестрогих — включайте. Нули знаменателя всегда исключайте.
  * Запишите решение в виде множеств, объединяя непересекающиеся промежутки знаком \(\cup\).
