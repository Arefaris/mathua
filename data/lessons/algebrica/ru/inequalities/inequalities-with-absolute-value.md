## Введение

[Модуль](<../absolute-value/>) действительного числа \(x\) определяется следующим образом:

\[|x| = \begin{cases} +x & \text{если } x \geq 0 \\\\[6pt] -x & \text{если } x < 0 \end{cases} \, \forall \, x \in \mathbb{R} \]

Геометрически \(|x|\) представляет расстояние от \(x\) до начала координат на числовой прямой, а в более общем виде \(|x - a|\) представляет расстояние между \(x\) и точкой \(a\). Эта геометрическая интерпретация часто — самый естественный способ понять неравенства с модулем, и она направит интуицию, стоящую за обсуждаемыми ниже методами решения.


Свойства, лежащие в основе решения таких неравенств, таковы. Для каждого [действительного числа](<../properties-of-real-numbers/>) \(k > 0\) и каждого действительного выражения \(f(x)\) выполняются следующие равносильности:

  * \( |f(x)| \leq k \quad \) если \( -k \leq f(x) \leq k.\)

  * \(|f(x)| \geq k \quad \) если \(f(x) \leq -k \, \) или \( \, f(x) \geq k.\)


Те же равносильности естественно переносятся на случаи строгих неравенств с заменой \(\leq\) на \(<\) и \(\geq\) на \(>\). Когда \(k = 0\), неравенство \(|f(x)| \leq 0\) выполняется только при \(f(x) = 0\), так как модуль всегда неотрицателен. При \(k < 0\) неравенство \(|f(x)| \leq k\) не имеет решений ни при каком \(x\).

Альтернативный метод, применимый всякий раз, когда выражение под модулем [линейно](<../linear-inequalities/>), состоит в анализе знака аргумента с помощью его определения по частям. Находят точку, в которой аргумент обращается в нуль, делят числовую прямую на две соответствующие полупрямые и переписывают неравенство отдельно на каждой из них, убирая модуль. Частные решения затем объединяются.

###### Решение неравенства с модулем следует тому же принципу, что и решение [уравнения с модулем](<../absolute-value-equations/>): определяющие свойства функции модуля применяют, чтобы убрать модуль алгебраически, сводя задачу к набору обычных неравенств, которые нужно решить и объединить.

## Неравенство треугольника

Фундаментальный результат, тесно связанный с неравенствами с модулем, — неравенство треугольника. Для любых двух действительных чисел \(a\) и \(b\) выполняется соотношение:

\[|a + b| \leq |a| + |b| \]

Это неравенство утверждает, что модуль суммы никогда не превосходит суммы модулей. Его доказательство и подробное обсуждение следствий приведены в статье о [модуле](<../absolute-value/>).

###### Этот результат стоит помнить при работе с выражениями, содержащими суммы модулей, так как он сразу даёт верхнюю оценку, которая может упростить оценки без полного разбора случаев.

## Пример 1

Рассмотрим следующее простое неравенство:

\[|x - 3| \leq 5 \]

Применяя основное свойство для случая \(\leq\), получаем [систему](<../systems-of-inequalities/>) из двух одновременных неравенств:

\[-5 \leq x - 3 \leq 5 \]

Чтобы выразить \(x\), прибавим 3 ко всем трём частям составного неравенства. Эта операция допустима, потому что прибавление одной и той же величины к обеим частям неравенства не меняет его направления.

\[-5 + 3 \leq x \leq 5 + 3 \]

\[-2 \leq x \leq 8 \]

Изобразив полученные значения на числовой прямой, получаем следующую картину:

| \[-2\]| \[8\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Выделенная строка представляет пересечение двух условий: решение — множество значений \(x\), при которых оба неравенства выполняются одновременно. Следовательно, решение — замкнутый промежуток \([-2,\, 8]\).

Следовательно, решение — замкнутый промежуток \([-2,\, 8]\).

## Пример 2

Рассмотрим следующее неравенство:

\[|2x + 1| > 3 \]

Применяя основное свойство для случая \(>\), неравенство распадается на два альтернативных условия, каждое из которых должно выполняться независимо.

\[2x + 1 < -3 \] \[2x + 1 > 3\]

Решая первое условие, вычитанием 1 из обеих частей получаем \(2x < -4\), а делением на 2 — \(x < -2\). Так как делитель положителен, направление неравенства сохраняется.

Решая второе условие тем же способом и вычитая 1, получаем \(2x > 2\), а делением на 2 — \(x > 1\).

Изобразив полученные значения на числовой прямой, получаем следующую картину:

| \[-2\]| \[1\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Как и в рассмотренном ранее случае, выделенная строка представляет объединение двух условий: решение — множество значений \(x\), при которых выполняется хотя бы одно из двух неравенств.

Следовательно, решение — объединение открытых промежутков \((-\infty,\, -2) \cup (1,\, +\infty)\).

## Пример 3

Рассмотрим следующее неравенство, в котором встречаются два различных модуля:

\[|x + 1| + |x - 2| > 4 \]

Когда неравенство содержит более одного модуля, наиболее систематический подход — разбить числовую прямую по нулям аргументов. Выражения \(x + 1\) и \(x - 2\) обращаются в нуль соответственно при \(x = -1\) и \(x = 2\), что даёт три области, которые нужно анализировать отдельно.


Случай \(x < -1\). В этой области \(x + 1 < 0\) и \(x - 2 < 0\), поэтому оба аргумента отрицательны, и модуль меняет их знак. Неравенство принимает вид:

\[-(x + 1) + (-(x - 2)) > 4 \]

\[-x - 1 - x + 2 > 4 \]

\[-2x + 1 > 4 \]

Вычитание 1 из обеих частей даёт \(-2x > 3\). Деление на \(-2\) с изменением направления неравенства, так как делитель отрицателен, приводит к следующему:

\[x < -\frac{3}{2} \]

Это условие должно выполняться внутри области \(x < -1\). Так как \(-\frac{3}{2} < -1\), условие \(x < -\frac{3}{2}\) — более строгое из двух, и пересечение с \(x < -1\) сводится к \(x < -\frac{3}{2}\). Вклад этого случая поэтому равен \(\left(-\infty,\, -\frac{3}{2}\right)\).


Случай \(-1 \leq x < 2\). В этой области \(x + 1 \geq 0\) и \(x - 2 < 0\). Неравенство принимает вид:

\[(x + 1) + (-(x - 2)) > 4 \]

\[x + 1 - x + 2 > 4 \]

\[3 > 4 \]

Это противоречие, которое не выполняется ни при каком значении \(x\). Случай II поэтому не даёт решений.


Случай \(x \geq 2\). В этой области \(x + 1 > 0\) и \(x - 2 \geq 0\), поэтому оба аргумента неотрицательны, и модуль оставляет их без изменений. Неравенство принимает вид:

\[(x + 1) + (x - 2) > 4 \]

\[2x - 1 > 4 \]

Прибавление 1 к обеим частям даёт \(2x > 5\), а деление на 2 приводит к следующему:

\[x > \frac{5}{2} \]

Пересекая с \(x \geq 2\): так как \(\frac{5}{2} > 2\), действующее условие — \(x > \frac{5}{2}\). Вклад этого случая поэтому равен \(\left(\frac{5}{2},\, +\infty\right)\).


Собрав вклады всех трёх случаев, ниже изображены частные решения, полученные на каждой области числовой прямой.

| \[-\frac{3}{2}\]| \[\frac{5}{2}\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Объединение двух открытых полупрямых даёт полное множество решений.

Решение неравенства поэтому:

\[\left(-\infty,\, -\frac{3}{2}\right) \cup \left(\frac{5}{2},\, +\infty\right) \]

## Пример 4

Рассмотрим теперь более сложный случай, в котором правая часть неравенства — не фиксированное число, а [действительный параметр](<../equations-with-parameters/>) \(k\). Структура множества решений зависит от значения \(k\), и для полного обсуждения нужно рассматривать несколько случаев отдельно. Рассмотрим следующее неравенство:

\[|x - 1| > k \]

Поведение решения существенно меняется в зависимости от того, отрицательно \(k\), равно нулю или положительно, и это нам и предстоит определить.


Случай \(k < 0\). Так как модуль всегда неотрицателен, левая часть удовлетворяет \(|x - 1| \geq 0 > k\) при любом действительном \(x\). Поэтому неравенство выполняется для всех действительных чисел, и решение — \(\mathbb{R}\).


Случай \(k = 0\). Неравенство сводится к \(|x - 1| > 0\), которое выполняется при любом \(x\), кроме точки, где модуль обращается в нуль. Так как \(|x - 1| = 0\) тогда и только тогда, когда \(x = 1\), решение — \(\mathbb{R} \setminus {1}\).


Случай \(k > 0\). Применяя основное свойство для случая \(>\), неравенство распадается на два альтернативных условия:

\[x - 1 < -k \] \[x - 1 > k\]

Прибавление 1 к обеим частям каждого условия приводит к следующему:

\[x < 1 - k \qquad \text{или} \qquad x > 1 + k \]


Изобразив решение на числовой прямой, получаем следующую картину:

| \[1-k\]| \[1+k\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Заметим, что при \(k \to 0^+\) две граничные точки \(1 - k\) и \(1 + k\) приближаются к 1 с противоположных сторон, и множество решений приближается к \(\mathbb{R} \setminus \\{1\\}\), что согласуется со случаем \(k = 0\).

Следовательно, решение — объединение двух открытых промежутков: \[\left(-\infty,\, 1-k\right) \cup \left(1+k,\, +\infty\right)\]

## Неравенства с непостоянной правой частью

Приведённые выше равносильности предполагают, что правая часть — положительная константа \(k\). Когда правая часть сама является функцией от \(x\), скажем \(g(x)\), ситуация требует дополнительной осторожности. Рассмотрим следующее неравенство.

\[|f(x)| \leq g(x) \]

Применяя те же рассуждения, что и ранее, получаем, что оно равносильно следующему составному неравенству.

\[-g(x) \leq f(x) \leq g(x) \]

Однако это сведение верно только при \(g(x) > 0\). Если \(g(x) \leq 0\) в некоторой точке, неравенство \(|f(x)| \leq g(x)\) там выполняться не может, так как левая часть всегда неотрицательна. Правильный подход поэтому — наложить \(g(x) > 0\) как необходимое условие и пересечь его с решением составного неравенства. В качестве конкретного примера рассмотрим следующее.

\[|x - 1| \leq 2x - 3 \]

Правая часть \(g(x) = 2x - 3\) положительна только при \(x > \frac{3}{2}\). Вне этой области неравенство не имеет решений независимо от значения \(|x - 1|\). Внутри области \(x > \frac{3}{2}\) неравенство равносильно следующей системе.

\[-(2x - 3) \leq x - 1 \leq 2x - 3 \]

Левое неравенство \(-(2x - 3) \leq x - 1\) упрощается до \(-2x + 3 \leq x - 1\), то есть \(4 \leq 3x\), откуда \(x \geq \frac{4}{3}\). Правое неравенство \(x - 1 \leq 2x - 3\) упрощается до \(2 \leq x\), откуда \(x \geq 2\). Так как \(\frac{4}{3} < \frac{3}{2} < 2\), условие \(x \geq \frac{4}{3}\) уже следует из требования \(x > \frac{3}{2}\), а определяющее ограничение среди всех трёх — \(x \geq 2\). Изобразив решение на числовой прямой, получаем следующую картину.

| \[\frac{4}{3}\]| \[\frac{3}{2}\]| \[2\]|   
---|---|---|---|---  
| | | |   
| | | |   
| | | |   
| | | |   
| | | |   
  
Три критических значения на графике отражают три независимых условия, полученные в ходе решения: порог \(\frac{4}{3}\) из левого неравенства, порог \(\frac{3}{2}\) из требования положительности \(g(x)\) и порог 2 из правого неравенства. Так как каждое условие строже предыдущего, действующее решение полностью определяется крайней правой границей.

Решение — промежуток \([2, +\infty)\).
