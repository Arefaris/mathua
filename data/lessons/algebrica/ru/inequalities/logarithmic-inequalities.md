## Введение

Логарифмические неравенства — это неравенства, содержащие одно или несколько [логарифмических](<../logarithms>) выражений, в которых неизвестное \(x\) стоит либо в аргументе логарифма, либо, в некоторых случаях, в самом основании. Прежде чем браться за логарифмические неравенства, необходимо хорошо понимать логарифмы, их основные свойства и стандартные методы решения [логарифмических уравнений](<../logarithmic-inequalities/>), так как эти инструменты нужны для правильного подхода к таким неравенствам и их решению.


Логарифмические неравенства могут иметь общий вид:

\[\log_af(x) \lesseqgtr \log_ag(x) \]

  * \(a\) — основание логарифма, причём (a > 0) и \(a \neq 1.\)
  * \(f(x)\) и \(g(x)\) — алгебраические выражения, зависящие от переменной \(x.\)
  * Символ \(\lesseqgtr\) обозначает одно из отношений \(\le\), \(=\) или \(\ge.\)


Кроме того, чтобы неравенство было корректно определено, должны выполняться следующие условия:

\[\begin{cases} f(x) > 0\\\\[0.6em] g(x) > 0\\\\[0.6em] \end{cases} \]


Неравенство, содержащее логарифмическое выражение, в котором неизвестная переменная не входит ни в аргумент, ни в основание логарифма, не является логарифмическим неравенством. Иными словами, неравенство вида: \[\log_3(9) - 3x > 0 \] не является логарифмическим неравенством, так как логарифмическое слагаемое — константа. Напротив,  
\[\log_3(9x) - 3x > 0 \] является логарифмическим неравенством, потому что переменная \(x\) входит в аргумент логарифма и напрямую влияет на его область определения и поведение.

## Как решать логарифмические неравенства

Процесс решения логарифмических неравенств общий, однако для удобства объяснения рассмотрим следующее неравенство: \[\log_a f(x) \ge \log_a g(x) \]

Процедуру можно разбить на четыре основных шага:

  * Определите [область определения](<../determining-the-domain-of-a-function/>) неравенства, наложив условия допустимости. Аргументы всех логарифмических выражений должны быть строго положительными, а основание должно удовлетворять: \[\begin{cases} f(x) > 0 \\\\[0.6em] g(x) > 0 \\\\[0.6em] \end{cases} \]

  * Основание должно удовлетворять: \[\begin{cases} a > 0 \\\\[0.6em] a \neq 1 \\\\[0.6em] \end{cases} \]

  * Если \(a > 1\), логарифмическая функция [возрастает](<../increasing-and-decreasing-functions/>), и неравенство сохраняет направление при снятии логарифмов.

  * Если \(0 < a < 1\), логарифмическая функция убывает, и направление неравенства нужно изменить на противоположное при устранении логарифмов.

  * Используйте монотонность логарифмической функции, чтобы убрать логарифмы и свести задачу к равносильному алгебраическому неравенству относительно \(f(x)\) и \(g(x)\).

  * Решите получившееся алгебраическое неравенство и пересеките множество решений с ранее найденной областью определения, отбросив значения, не удовлетворяющие исходным логарифмическим условиям.


Чтобы объяснить роль основания логарифма, напомним поведение [логарифмической функции](<../logarithmic-function/>) при \(0 < a < 1\). По её графику видим, что функция строго убывает на всей области определения и имеет вертикальную асимптоту вдоль оси \(y\):

![График логарифмической функции с основанием между нулём и единицей.](/diagrams/algebrica/logharithm-5-1.png)

##### Пунктирная кривая — логарифмическая функция с основанием \(a > 1\). В этом случае функция строго возрастает. В обоих случаях при \(x = 1\) значение логарифмической функции равно 0, и графики пересекаются в точке \((1,0)\).

## Пример 1

Рассмотрим логарифмическое неравенство: \[\log_{\frac{1}{2}}(x + 3) \ge \log_{\frac{1}{2}}(2x - 1) \]

Начнём с определения области определения неравенства. Аргументы логарифмов должны быть строго положительными: \[\begin{cases} x + 3 > 0 \\\\[0.6em] 2x - 1 > 0 \end{cases} \]

Используя графическое представление и рассматривая промежутки решений [линейных неравенств](<../linear-inequalities/>) в предыдущей системе, находим, что их пересечение, определяющее область определения логарифмического неравенства, как раз задаётся условием \(x > 1/2\).

| \[-3\]| \[\frac{1}{2}\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Следовательно, область определения \(D\) исходного неравенства задаётся следующим промежутком: \[\left(-\frac{1}{2}, +\infty\right) \]


Далее проанализируем основание логарифма. Так как основание удовлетворяет \[0 < \frac{1}{2} < 1 \] логарифмическая функция строго убывает. Как следствие, при снятии логарифмов направление неравенства нужно изменить на противоположное. Поэтому данное неравенство: \[\log_{\frac{1}{2}}(x + 3) \ge \log_{\frac{1}{2}}(2x - 1) \] равносильно: \[x + 3 \le 2x - 1 \]


Теперь решим получившееся алгебраическое неравенство: \[x + 3 \le 2x - 1 \quad \rightarrow \quad x \ge 4 \]

Наконец, пересечём этот результат с ранее найденной областью определения. Так как область определения требует \(x > \frac{1}{2}\), условие \(x \ge 4\) допустимо.

Следовательно, множество решений логарифмического неравенства: \[x \ge 4 \]

## Пример 2

Рассмотрим логарифмическое неравенство:

\[\log_{\frac{1}{2}}(x+1) > \log_2(2-x) \]

Начнём с определения [области определения](<../determining-the-domain-of-a-function/>). Аргументы логарифмов должны быть строго положительными, следовательно:

\[\begin{cases} x+1 > 0 \\\\[0.6em] 2-x > 0 \\\\[0.6em] \end{cases} \]

Используя графическое представление и рассматривая промежутки решений линейных неравенств в предыдущей системе, находим, что их пересечение задаётся условием \( -1 < x < 2\).

| \[-1\]| \[2\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Следовательно, область определения \(D\) исходного неравенства задаётся следующим промежутком: \[(-1, 2) \]


Далее перепишем логарифм с основанием \(\tfrac{1}{2}\) через основание 2. Так как \(\tfrac{1}{2} = 2^{-1}\), имеем \[\log_{\frac{1}{2}}(x+1) = \frac{\log_2(x+1)}{\log_2(\frac{1}{2})} = -\log_2(x+1) \]

Подставив в исходное неравенство, получаем:

\[\log_2(x+1) < -\log_2(2-x) \]

Перенеся все логарифмические слагаемые в одну часть и применив свойства логарифмов, получаем: \[\log_2(x+1) + \log_2(2-x) < 0 \]

что по свойству суммы логарифмов, согласно которому [сумма двух логарифмов](<../logarithms>) равна логарифму их произведения, позволяет переписать выражение следующим образом:

\[\log_2!\bigl((x+1)(2-x)\bigr) < 0 \]

Так как логарифмическая функция с основанием \(2>1\) строго возрастает, это неравенство равносильно \[0 < (x+1)(2-x) < 1 \]

В области определения \((-1,2)\) произведение \((x+1)(2-x)\) всегда положительно, поэтому достаточно решить:

\[(x+1)(2-x) < 1 \]

Раскрыв скобки и упростив, получаем \[x^2 - x - 1 > 0 \]

Соответствующее [квадратное уравнение](<../quadratic-equations>) имеет корни: \[x = \frac{1 \pm \sqrt{5}}{2} \]

Неравенство выполняется вне промежутка, определяемого этими корнями. Пересекая этот результат с областью определения \((-1,2)\), окончательно получаем множество решений: \[-1 < x < \frac{1-\sqrt{5}}{2}\]
