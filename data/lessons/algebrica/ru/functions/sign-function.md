## Введение

Функция знака сопоставляет каждому действительному числу его знак, не учитывая его величину. Функция определяется так:

\[\operatorname{sgn}(x) = \begin{cases} -1 & \text{если } x < 0 \\\\[6pt] 0 & \text{если } x = 0 \\\\[6pt] 1 & \text{если } x > 0 \end{cases} \quad \forall \, x \in \mathbb{R} \]

А именно, \(\operatorname{sgn}(x)\) возвращает \(-1\) для отрицательных значений, 0 при \(x = 0\) и 1 для положительных значений. Функция не измеряет величину \(x\), а лишь указывает положение \(x\) относительно нуля. Например, по определению имеем:

\[\operatorname{sgn}(-7) = -1 \qquad \operatorname{sgn}(0) = 0 \qquad \operatorname{sgn}(4) = 1 \]


График \(y = \operatorname{sgn}(x)\) состоит из двух горизонтальных лучей и одной изолированной точки. Луч на \(y = -1\) тянется по всем \(x < 0\), луч на \(y = 1\) — по всем \(x > 0\), а изолированная точка в начале координат \((0, 0)\) лежит на \(y = 0\). Два луча приближаются к оси y, но не пересекают её.

![Функция знака.](/diagrams/algebrica/sign-function-1.png)

Функция знака относится к [нечётным функциям](<../even-and-odd-functions/>), так как удовлетворяет тождеству:

\[\operatorname{sgn}(-x) = -\operatorname{sgn}(x) \quad \forall \, x \in \mathbb{R} \]

## Свойства

  * [Область определения](<../determining-the-domain-of-a-function/>): \(\mathbb{R}\).
  * Множество значений: \({-1,\, 0,\, 1}\).
  * Функция [нечётная](<../even-and-odd-functions/>), так как \(\operatorname{sgn}(-x) = -\operatorname{sgn}(x)\).
  * У функции ровно один корень \(x = 0\), так как \(\operatorname{sgn}(x) = 0\) только при \(x = 0\).
  * Функция постоянна на \((-\infty, 0)\) и на \((0, +\infty)\), следовательно, [возрастает](<../increasing-and-decreasing-functions/>) в том смысле, что она не убывает на \(\mathbb{R}\).
  * У функции [разрыв скачком](<../discontinuities-of-real-functions/>) в точке \(x = 0\); во всех остальных точках она [непрерывна](<../continuous-functions/>).
  * Функция не дифференцируема в точке \(x = 0\). Во всех остальных точках она дифференцируема, с нулевой [производной](<../derivatives/>).
  * Пределы при приближении к \(x = 0\) с каждой стороны: \[\begin{align} \lim_{x \to 0^-} \operatorname{sgn}(x) &= -1 \\\\[0.5em] \lim_{x \to 0^+} \operatorname{sgn}(x) &= 1 \end{align} \]


Так как два односторонних предела различны, следующий двусторонний предел не существует: \[\lim_{x \to 0} \operatorname{sgn}(x)\]

## Пределы на бесконечности

Когда \(x\) удаляется от начала координат в любом направлении, функция знака стабилизируется на постоянном значении:

\[\begin{align} \lim_{x \to -\infty} \operatorname{sgn}(x) &= -1 \\\\[6pt] \lim_{x \to +\infty} \operatorname{sgn}(x) &= 1 \end{align} \]

Это просто следствие того, что \(\operatorname{sgn}(x) = -1\) при всех \(x < 0\) и \(\operatorname{sgn}(x) = 1\) при всех \(x > 0\), поэтому значение функции не меняется по мере удаления \(x\) от нуля.

## Производная и интеграл

На каждой из двух открытых полупрямых, где функция знака постоянна, её [производная](<../derivatives/>) равна нулю:

\[\frac{d}{dx} \operatorname{sgn}(x) = 0 \quad \text{при } x \neq 0 \]

При \(x = 0\) производная не существует, потому что функция там разрывна. В смысле обобщённых функций, однако, производная функции знака равна:

\[\frac{d}{dx} \operatorname{sgn}(x) = 2\delta(x) \]

\(\delta(x)\) — дельта-функция Дирака, обобщённая функция, равная нулю всюду, кроме начала координат, интеграл которой по всей числовой прямой равен единице. Это тождество в смысле обобщённых функций показывает, что функция знака имеет в начале координат разрыв амплитудой 2, так как:

\[\lim_{x \to 0^-} \operatorname{sgn}(x) = -1 \] \[\lim_{x \to 0^+} \operatorname{sgn}(x) = 1 \]

Эта амплитуда объясняет наличие множителя 2 перед дельта-функцией Дирака.


[Неопределённый интеграл](<../indefinite-integrals/>) функции знака, вычисленный вдали от начала координат, возвращает [модуль](<../absolute-value-function/>):

\[\int \operatorname{sgn}(x) \, dx = |x| + c \]

Это согласуется с тем, что производная \(|x|\) равна \(\operatorname{sgn}(x)\) везде, где первая дифференцируема.

## Связь с функцией модуля

Между функцией знака и [модулем](<../absolute-value-function/>) существует прямая алгебраическая связь. Для любого \(x \neq 0\) выполняется следующее тождество:

\[\operatorname{sgn}(x) = \frac{x}{|x|} \]

Этот результат согласуется с определением: при \(x > 0\) отношение \(x / |x| = x/x = 1\). При \(x < 0\) отношение \(x / |x| = x/(-x) = -1\). Формула не определена при \(x = 0\), поэтому значение \(\operatorname{sgn}(0) = 0\) назначается отдельно по соглашению.

И наоборот, модуль можно выразить через функцию знака с помощью следующего тождества:

\[|x| = x \cdot \operatorname{sgn}(x) \]

Это тождество верно при всех \(x \in \mathbb{R}\), включая \(x = 0\), где обе части равны нулю. Вместе эти два тождества показывают, что \(|x|\) и \(\operatorname{sgn}(x)\) дополняют друг друга: модуль сохраняет величину и опускает знак, тогда как функция знака сохраняет знак и опускает величину.


Из связи между функцией знака и модулем возникают ещё два тождества. Первое таково:

\[x = |x| \cdot \operatorname{sgn}(x) \]

Это тождество выражает любое действительное число как произведение его величины и знака. Второе тождество использует равенство \(|x| = \sqrt{x^2}\), верное при всех \(x \in \mathbb{R}\), и даёт альтернативное представление функции знака при \(x \neq 0\):

\[\operatorname{sgn}(x) = \frac{x}{\sqrt{x^2}} \]

## Связь со ступенчатой функцией Хевисайда

[Ступенчатая функция Хевисайда](<../heaviside-function/>) \(H(x)\) определяется так:

\[H(x) = \begin{cases} 0 & \text{если } x < 0 \\\\[6pt] \dfrac{1}{2} & \text{если } x = 0 \\\\[8pt] 1 & \text{если } x > 0 \end{cases} \]

![Ступенчатая функция Хевисайда.](/diagrams/algebrica/Heaviside-function-1.png)

Функция знака и ступенчатая функция Хевисайда связаны простым линейным преобразованием. А именно:

\[\operatorname{sgn}(x) = 2H(x) - 1 \]

Равносильно:

\[H(x) = \frac{1 + \operatorname{sgn}(x)}{2} \]

Это соотношение часто используется, так как переход между этими представлениями может упростить вычисления. Функция Хевисайда отображает \((-\infty, 0)\) в 0, а \((0, +\infty)\) в 1 и потому может трактоваться как сдвинутая и масштабированная форма функции знака.
