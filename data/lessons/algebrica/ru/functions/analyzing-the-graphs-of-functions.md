## Введение

Анализ графика [функции](<../functions>) \(y=f(x)\) позволяет изучить её поведение и ключевые характеристики и даёт ценное представление о её математических свойствах. Это упорядоченный процесс, который можно эффективно проводить по чёткой схеме анализа, состоящей из следующих шагов.

  * Определите [область определения](<../determining-the-domain-of-a-function/>), найдя множество действительных чисел, на котором функция определена.
  * Проверьте симметрию: [чётная или нечётная](<../even-and-odd-functions/>) ли функция.
  * Найдите точки пересечения с осями: точки, в которых график пересекает ось \(x\) и ось \(y\).
  * Проанализируйте знак функции, чтобы определить, где она положительна, а где отрицательна.
  * Найдите [асимптоты](<../asymptotes>), включая горизонтальные, вертикальные или наклонные границы.
  * С помощью первой производной найдите промежутки возрастания и убывания.
  * С помощью второй производной изучите выпуклость и найдите [точки перегиба](<../https://algebrica.org/maximum-minimum-and-inflection-points/>).
  * Постройте качественное изображение графика функции.


## Область определения

Первый шаг анализа функции — определить её [область определения](<../determining-the-domain-of-a-function/>), то есть множество всех действительных чисел, при которых функция корректно определена. Область определения зависит от типа анализируемой функции. Нахождение области определения имеет решающее значение, потому что она задаёт входные значения, для которых функцию можно вычислять и строить её график. Чтобы найти область определения, мы рассматриваем выражение функции и выявляем математические ограничения, которые могут исключать некоторые значения \( x \).

Рассмотрим в качестве примера функцию \( y = x^3 - 2x \). Это многочленная функция вида: \[y = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0\] где \( a_n, a_{n-1}, \dots, a_0 \) — действительные коэффициенты, а \( n \) — степень [многочлена](<../polynomials>).

Поскольку многочленные функции определены на всех действительных числах, область определения этой функции — \( \mathbb{R} \).

## Симметрия

Следующий шаг — определить, обладает ли функция [симметрией](<../even-and-odd-functions/>) относительно оси \( y \) или начала координат.

  * Функция \(y=f(x)\) называется [чётной](<../even-and-odd-functions/>), если выполняется условие \(f(-x) = f(x) \quad \forall x \in D.\) Это означает, что график симметричен относительно оси \( y \).

  * Функция \(y=f(x)\) называется [нечётной](<../even-and-odd-functions/>), если выполняется условие \(f(-x) = -f(x) \quad \forall x \in D.\) Это означает, что график симметричен относительно начала координат.


Чтобы определить, чётна или нечётна функция \(f(x) = x^3 - 2x\), вычислим \( f(-x) \). Подставив ( -x ) вместо ( x ), получаем: \[\begin{align} f(-x) &= (-x)^3 - 2(-x) \\\\[0.5em] &= -x^3 + 2x \end{align} \]


Вычисляя \( -f(x) \), получаем:  
\[\begin{align} -f(x) &= -(x^3 - 2x) \\\\[0.5em] &= -x^3 + 2x \end{align} \]

Так как \( f(-x) = -f(x) \), функция нечётная, то есть симметрична относительно начала координат.

## Пересечения с осями координат

Изучив симметрию, следующим шагом определяем точки пересечения функции с декартовыми осями. Это:

  * точки пересечения с осью \( x \), получаемые решением \( f(x) = 0 \).
  * точка пересечения с осью \( y \), равная \( f(0) \), если функция определена при \( x = 0 \).


Чтобы найти точки пересечения с осью \( y \), положим \( x = 0 \) в функции \( f(x) \). Имеем: \[f(0) = 0^3 - 2(0) = 0\]

Следовательно, функция пересекает ось \( y \) в точке: \[(0, 0)\]


Далее, чтобы найти точки пересечения с осью \( x \), положим \( f(x) = 0 \):

\[x^3 - 2x = 0\] \[x(x^2 - 2) = 0\]

Решая относительно \( x \), имеем: \[x = 0 \quad \text{или} \quad x^2 - 2 = 0\]

Из \( x^2 - 2 = 0 \) получаем:  
\[x = \pm \sqrt{2}\]

Следовательно, функция пересекает ось \( x \) в точках:

\[(0,0), \quad (\sqrt{2},0), \quad (-\sqrt{2},0)\]

Итак, пересечения с декартовыми осями:

ось \( y \): \( (0,0)\)  
ось \( x \): \( (0,0) \), \( (\sqrt{2},0) \), \( (-\sqrt{2},0) \)

## Метод интервалов

Далее анализируем знак функции, определяя промежутки, на которых она положительна и отрицательна. Для этого решаем неравенство \(f(x) > 0\), определяющее, где функция принимает положительные значения. Остальные промежутки, на которых \( f(x) < 0 \), показывают, где функция отрицательна.

##### В этом контексте, поскольку речь пойдёт о неравенствах, полезно напомнить, как применять [метод интервалов](<../sign-analysis-in-inequalities/>) в неравенствах.

Чтобы проанализировать знак функции, определим, где \( f(x) \) положительна, отрицательна или равна нулю, решив неравенство:  
\[x^3 - 2x \gt 0\]


Разложив выражение на множители, имеем: \[x(x^2 - 2) \gt 0\]

Из первого множителя получаем: \[x \gt 0\]

Из второго множителя получаем: \[x^2-2 \gt 0 \Rightarrow x \gt \sqrt{2} \quad x \lt -\sqrt{2}\]


Перемножив знаки первого и второго множителей, получаем (чёрным цветом) промежутки, на которых функция положительна.

| \[-\sqrt{2}\]| \[0\]| \[+\sqrt{2}\]|   
---|---|---|---|---  
| | | |   
| | | |   
| | | |   
| | | |   
  
Следовательно, функция \( x(x^2 - 2) \) положительна при:

\[x \in (-\sqrt{2},0) \cup (+\sqrt{2},+\infty)\]

##### Для полноты напомним, что анализ знака функции, как в данном примере, требует изучения знаков её отдельных множителей и определения общего знака на каждом промежутке вычислением произведения этих знаков.


Затем изобразим на декартовой плоскости промежутки, в которых должна находиться функция, исключив серые.

## Асимптоты

Ещё один важный шаг анализа функции — исследование её поведения на границах области определения. Для этого вычисляются [пределы](<../limits/>), чтобы определить, как ведёт себя функция, когда \( x \) приближается к концам области определения или уходит в бесконечность. Вычислив эти пределы, можно обнаружить наличие асимптот.

  * Функция \( f(x) \) имеет горизонтальную асимптоту, если: \[\lim\limits_{x \to \pm\infty} f(x) = L\] где \( L \) — конечное действительное число. В этом случае прямая \( y = L \) — асимптота, описывающая поведение функции на бесконечности.

  * Функция \( f(x) \) имеет вертикальную асимптоту \( x = x_0 \), если  
\[\lim\limits_{x \to x_0^\pm} f(x) = \pm\infty\] В этом случае прямая \( x = a \) — асимптота, показывающая, что вблизи \( x = a \) функция неограниченно растёт.

  * Функция \( f(x) \) имеет наклонную асимптоту вида \( y = mx + q \), если существуют и конечны следующие пределы:  
\[m = \lim\limits_{x \to \pm\infty} \frac{f(x)}{x}\] \[q = \lim\limits_{x \to \pm\infty} \left[ f(x) - mx \right]\]


Чтобы определить, существуют ли горизонтальные асимптоты, проверим, существует ли и конечен ли следующий предел: \[\lim\limits_{x \to \pm\infty} f(x)\]

Имеем:  
\[\lim\limits_{x \to \pm\infty} (x^3 - 2x) = \pm\infty\]

Функция стремится к бесконечности в обоих направлениях, поэтому горизонтальных асимптот нет.


Вертикальные асимптоты возникают в точках, где функция не определена и её значения неограниченно растут. Данная функция \(y = x^3 - 2x\) — многочлен, определённый при всех \( x \in \mathbb{R} \). Поскольку у многочленов нет точек разрыва и бесконечных пределов при конечных значениях \( x \), делаем вывод, что вертикальных асимптот нет.


Чтобы определить существование наклонных асимптот, вычислим угловой коэффициент \(m\) с помощью следующего предела:

\[m = \lim\limits_{x \to \pm\infty} \frac{x^3 - 2x}{x} = +\infty\]

Так как предел не конечен, наклонных асимптот не существует.

Следовательно, нет ни горизонтальных, ни вертикальных, ни наклонных асимптот.

## Точки максимума и минимума

Теперь, анализируя первую производную, сначала определим её область определения и нули, найдя, где \( f^{\prime}(x) = 0 \). Изучив её знак, установим промежутки, на которых функция возрастает \( f^{\prime}(x) > 0 \), и, соответственно, убывает \( f^{\prime}(x) < 0 \).

Затем найдём возможные [локальные максимумы и минимумы](<../maximum-minimum-and-inflection-points/>), исследовав критические точки \( f(x) \). Кроме того, проверим функцию на точки перегиба, где меняется выпуклость, и на точки, где \( f(x) \) [не дифференцируема](<../points-of-non-differentiability/>).

Вычислим первую производную \( f(x) \) и проанализируем её знак. \[f^{\prime}(x) = 3x^2 - 2\]

Для \[3x^2 - 2 > 0 \Rightarrow x < -\sqrt{\frac{2}{3}} \quad x > \sqrt{\frac{2}{3}} \]


Отсюда следует, что \(f(x)\) возрастает при:

\[x < -\sqrt{\frac{2}{3}} \quad \text{или} \quad x > \sqrt{\frac{2}{3}}\]

и убывает при:

\[-\sqrt{\frac{2}{3}} < x < \sqrt{\frac{2}{3}}\]


Из анализа знака следует, что в точке \( \sqrt{\frac{2}{3}} \) локальный минимум. Теперь вычислим значение функции в этой точке:

\[\begin{align} f\left(\sqrt{\frac{2}{3}}\right) &= \left(\sqrt{\frac{2}{3}}\right)^3 - 2\left(\sqrt{\frac{2}{3}}\right) \\\\[0.5em] &= \frac{2\sqrt{2}}{3\sqrt{3}} - 2\sqrt{\frac{2}{3}} \\\\[0.5em] &= \frac{2\sqrt{6}}{9} - \frac{6\sqrt{6}}{9} \\\\[0.5em] &= \frac{-4\sqrt{6}}{9} \end{align} \]


Из анализа знака следует также, что в точке \( -\sqrt{\\frac{2}{3}} \) локальный максимум. Теперь вычислим значение функции в этой точке:

\[\begin{align} f\left(-\sqrt{\frac{2}{3}}\right) &= \left(-\sqrt{\frac{2}{3}}\right)^3 - 2\left(-\sqrt{\frac{2}{3}}\right) \\\\[0.5em] &= -\frac{2\sqrt{2}}{3\sqrt{3}} + 2\sqrt{\frac{2}{3}} \\\\[0.5em] &= -\frac{2\sqrt{6}}{9} + \frac{6\sqrt{6}}{9} \\\\[0.5em] &= \frac{4\sqrt{6}}{9} \end{align} \]

У функции есть:

  * Локальный максимум в точке:  
\[x = -\sqrt{\frac{2}{3}}, \quad y = \frac{4\sqrt{6}}{9}\]

  * Локальный минимум в точке:  
\[x = \sqrt{\frac{2}{3}}, \quad y = \frac{-4\sqrt{6}}{9} \]


## Точки перегиба

Наконец, анализируя вторую производную \( f^{\prime\prime}(x) \), определим промежутки, на которых график выпуклый вниз \( f^{\prime\prime}(x) > 0 \) или выпуклый вверх \( f^{\prime\prime}(x) < 0 \).

Теперь найдём [точки перегиба](<../maximum-minimum-and-inflection-points/>), проанализировав знак второй производной. Вторая производная f(x) равна:

\[f^{\prime\prime}(x) = 6x\]

Положив \( f''(x) = 0 \), находим точку перегиба при \(x = 0\). Вычислив \( f(0) \), получаем \( y = 0 \).

Итак, точка перегиба: \[(0,0)\]
