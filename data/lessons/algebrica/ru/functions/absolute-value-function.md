## Введение

[Модуль](<../absolute-value>) числа определяется следующим образом:

\[|x| = \begin{cases} +x & \text{если } x \geq 0 \\\\[0.5em] -x & \text{если } x < 0 \end{cases} \quad \forall \, x \in \mathbb{R} \]

Функция модуля сопоставляет каждому действительному числу его расстояние до нуля на числовой прямой. Это значит, что отрицательные числа переходят в соответствующие им положительные, а положительные остаются без изменений, поскольку расстояние всегда неотрицательно.

![Геометрически модуль числа x, записываемый |x|, — это расстояние между x и 0 на числовой прямой.](/diagrams/algebrica/absolute-value-1.png)

В более общем виде выражение с модулем \(|x - a|\) можно истолковать как расстояние между точкой \(x\) и точкой \(a\) на числовой прямой. Имеем:

\[|x-a| = |a-x| \]

В самом деле, можно заметить, что \( a - x \) — это просто число, противоположное \( x - a \); иначе говоря, \(a - x = -(x - a)\). Отсюда \(|a - x| = |- (x - a)| = |x - a|\). Это показывает, что у двух выражений одинаковый модуль, хотя слагаемые в скобках стоят в обратном порядке.

## График и симметрия функции модуля

Функция модуля имеет вид:

\[y = |x| = \begin{cases} +x & \text{если } x \geq 0 \\\\[0.5em] -x & \text{если } x < 0 \end{cases} \]

График \(y= |x|\) выглядит так:

![График функции модуля симметричен относительно оси y. Эта симметрия означает, что функция чётная.](/diagrams/algebrica/absolute-value-6.png)


График функции модуля \( |x| \) симметричен относительно оси y. Эта симметрия означает, что функция [чётная](<../even-and-odd-functions/>), то есть удовлетворяет тождеству:

\[|{-x}| = |x| \quad \text{для всех } x \in \mathbb{R}\]

## Свойства

  * [Область определения](<../determining-the-domain-of-a-function/>): \( \mathbb{R} \).
  * Множество значений: \( \mathbb{R}^+_0 \).
  * Функция [убывает](<../increasing-and-decreasing-functions/>) на \( (-\infty, 0] \) и возрастает на \( [0, +\infty) \).
  * Функция [чётная](<../even-and-odd-functions/>), так как \( |{-x}| = |x| \).
  * Функция [непрерывна](<../continuous-functions/>) на всей числовой прямой \( \mathbb{R} \).
  * Функция дифференцируема всюду, кроме точки \( x = 0 \), где у неё [угловая точка](<../points-of-non-differentiability/>).
  * У функции есть [абсолютный минимум](<../maximum-minimum-and-inflection-points/>) в точке \( x = 0 \), где \( |x| = 0 \), а максимума у неё нет.
  * Пределы при стремлении \( x \) к концам области определения: \[\begin{align} \lim_{x \to -\infty} |x| &= +\infty \\\\[0.5em] \lim_{x \to +\infty} |x| &= +\infty \end{align} \]


## Как построить график модуля функции: отразить отрицательную часть

Рассмотрим [параболу](<../parabola>), заданную уравнением

\[y = x^2 - 1 \]

Этот график содержит часть кривой, лежащую ниже оси x, а именно на промежутке, где функция принимает отрицательные значения.

![](/diagrams/algebrica/absolute-value-3.png)

Чтобы найти этот промежуток, решим:

\[x^2 - 1 < 0 \rightarrow -1 < x < 1\. \]

Итак, функция \( y = x^2 - 1 \) отрицательна на открытом промежутке \( (-1, 1) \), и на этом участке график опускается ниже оси x.


Чтобы построить график функции \( f(x) = |x^2 - 1| \), начнём с графика \( y = x^2 - 1 \). Части графика, лежащие на оси x или выше неё, оставим без изменений, а все части, которые были ниже оси, отразим относительно оси x. Получаем:

![](/diagrams/algebrica/absolute-value-4.png)

Это преобразование гарантирует, что все значения функции становятся неотрицательными, как того требует модуль.

## Пределы, производные и интегралы функции модуля

Основной [предел](<../limits>), связанный с функцией модуля: \[\lim_{x \to 0} \frac{|x|}{x} \] Этот предел не существует, потому что левосторонний и правосторонний пределы различны: \[\lim_{x \to 0^-} \frac{|x|}{x} = -1 \quad \text{и} \quad \lim_{x \to 0^+} \frac{|x|}{x} = 1 \] Это поведение подчёркивает недифференцируемость \( |x| \) в точке \( x = 0 \).


[Производная](<../derivatives>) функции модуля задаётся по частям: \[\frac{d}{dx} |x| = \begin{cases} 1 & \text{если } x > 0 \\\\[0.5em] -1 & \text{если } x < 0 \end{cases} \] Производная не существует в точке \( x = 0 \), потому что в этой точке у функции [острый излом](<../points-of-non-differentiability/>).


[Неопределённый интеграл](<../indefinite-integrals>) функции модуля равен: \[\int |x| \, dx = \frac{x^2 \cdot \operatorname{sgn}(x)}{2} + c \] где \( \operatorname{sgn}(x) \) — [функция знака](<../sign-function/>), определяемая так: \[\operatorname{sgn}(x) = \begin{cases} -1 & \text{если } x < 0 \\\\[0.5em] 0 & \text{если } x = 0 \\\\[0.5em] 1 & \text{если } x > 0 \end{cases} \]
