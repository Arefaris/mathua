## Систематический метод нахождения области определения функции

Во введении к [функциям](<../functions>) мы обсуждали понятие области определения функции, то есть множества входных значений, для которых выражение математически осмысленно. Мы также рассматривали, как находить область определения основных семейств функций, таких как [многочлены](<../polynomials/>), [радикалы](<../radicals/>), [логарифмы](<../logarithms/>) и [тригонометрические](<../sine-and-cosine/>) выражения.

Однако на практике нам часто встречаются более сложные выражения, объединяющие в одной формуле несколько типов функций. В таких ситуациях найти область определения не всегда сразу просто, потому что каждый внутренний компонент может вносить собственные ограничения. В таких случаях наиболее эффективную стратегию можно свести к следующим шагам:

  * Начните с рассмотрения внутренних компонентов выражения и определите область определения, необходимую для каждого из них.
  * Двигайтесь наружу, слой за слоем, передавая ограничения, накладываемые каждой новой операцией или функцией.
  * Объедините все получившиеся условия, взяв их пересечение, поскольку общая область определения состоит только из значений, удовлетворяющих всем ограничениям одновременно.


Чтобы понять, как эта процедура работает на практике, полезно сразу перейти к конкретному примеру и применить каждый шаг к реальным выражениям.

## Виды промежутков

Изучая область определения функции, полезно вспомнить, как определяются действительные промежутки, поскольку область определения всегда выражается как объединение таких множеств. Промежутки описывают непрерывные участки числовой прямой и дают компактный способ указать, какие значения \(x\) допустимы. Первый тип — открытый интервал, содержащий все точки строго между двумя концами и не содержащий самих концов. В описательной форме он записывается  
\[\lbrace\,x : a < x < b\,\rbrace \] а в записи промежутков он выглядит так: \[(a,\,b) \] Эта запись особенно удобна, когда значения \(a\) и \(b\) соответствуют точкам, где функция не определена или где происходит разрыв. Графически иллюстрации на Algebrica будут следовать этому соглашению. Концы \(a\) и \(b\) показаны пустыми кружками, чтобы указать, что они не входят в промежуток, а отрезок между ними представляет все значения строго между \(a\) и \(b\). Такое графическое обозначение делает открытый интервал сразу узнаваемым и ясно подчёркивает, что его концы исключены.

| \[a\]| \[b\]|   
---|---|---|---  
| | |   
| | |   
  
Второй тип — замкнутый отрезок, включающий оба конца. В описательной форме он записывается: \[\lbrace\,x : a \le x \le b\,\rbrace \] а соответствующая запись промежутком —  
\[[\,a,\,b\,] \] Такое представление типично, когда функция определена и непрерывна даже в граничных точках \(a\) и \(b\). В том же духе, что и на иллюстрации выше, замкнутый отрезок изображается графически закрашиванием концов \(a\) и \(b\). Закрашенные точки показывают, что оба граничных значения включены, а отрезок между ними изображает все точки от \(a\) до \(b\). Это соглашение делает структуру замкнутого отрезка сразу понятной и подчёркивает, что его концы входят в множество.

| \[a\]| \[b\]|   
---|---|---|---  
| | |   
| | |   
  
Естественно, нетрудно увидеть, что возможны и другие сочетания открытых и закрытых концов. Например, может быть полуоткрытый промежуток вида \([a, +\infty)\) или, в более общем случае, промежутки, смешивающие включение и исключение на концах, такие как \((a, b]\). Эти формы показаны на рисунке ниже и обычно используются при описании областей определения, уходящих в бесконечность или начинающихся с определённого граничного значения.

| \[a\]| \[b\]|   
---|---|---|---  
| | |   
| | |   
| | |   
  
Введённое выше графическое обозначение особенно полезно, потому что позволяет сразу увидеть область определения функции. Когда из разных компонентов выражения возникает несколько условий существования, каждое из них можно изобразить на отдельной диаграмме промежутков. Общая область определения тогда получается **пересечением этих условий**: иначе говоря, множество допустимых значений \(x\) образуют только те промежутки, которые одновременно присутствуют на всех линиях диаграммы. Такой наглядный подход делает структуру области определения ясной и помогает избежать ошибок при объединении нескольких ограничений.

## Область определения элементарных функций

В качестве дополнительного замечания полезно подытожить ограничения области определения, порождаемые самыми распространёнными выражениями:

  * **Многочлены:** всегда определены на \(\mathbb{R}.\)
  * **Рациональные функции:** знаменатель \(\neq 0.\)
  * **Корни чётной степени:** подкоренное выражение \(\gt 0.\)
  * **Корни нечётной степени:** всегда определены на \(\mathbb{R}.\)
  * **Логарифмы:** аргумент \(> 0\), основание \(> 0\), основание \(\neq 1.\)
  * **Модули:** всегда определены на \(\mathbb{R}.\)
  * **Тригонометрические функции:** всегда определены на \(\mathbb{R}.\)
  * **Обратные тригонометрические функции:** аргумент в определённых границах


## Пример 1

Чтобы показать, как применяется графический метод, рассмотрим функцию:

\[f(x) = \log(x - 1) + \sqrt{x + 4} \]

Чтобы определить её область определения, нужно рассмотреть каждую составляющую отдельно, потому что функция определена только при тех значениях \(x\), которые одновременно удовлетворяют всем лежащим в основе условиям.


Логарифмическое слагаемое \(\log(x - 1)\) требует, чтобы его аргумент был строго положительным. Это приводит к условию: \[x - 1 > 0 \]

то есть допустимы только значения больше 1. Любое значение, меньшее или равное 1, сразу нарушает определение логарифма. Графически это условие можно изобразить так:

| \[1\]|   
---|---|---  
| |   
| |   
  
Слагаемое с квадратным корнем \(\sqrt{x + 4}\) требует, чтобы его аргумент был неотрицательным. Это условие выражается так: \[x + 4 \ge 0 \] поэтому допустимы значения \(x \ge -4\). По сравнению с логарифмическим ограничением это требование менее строгое, поскольку любое значение больше 1 автоматически больше \(-4\). Добавив этот результат к предыдущей диаграмме, получаем:

| \[-4\]| \[1\]|   
---|---|---|---  
| | |   
| | |   
| | |   
| | |   
  
Объединяя всё вместе, область определения функции получается пересечением двух условий \(x > 1\) и \(x \ge -4\). Поскольку \(x > 1\) уже влечёт \(x \ge -4\), пересечение сводится к простому неравенству \(x > 1)\).

Следовательно, область определения функции изображается выделенным чёрным отрезком, который соответствует промежутку: \[(1, +\infty) \]

## Пример 2

Рассмотрим относительно простой пример, в котором уже сочетаются квадратный корень, логарифм и тригонометрическая функция. Функция задана формулой:

\[f(x) = \sqrt{\frac{\log(2 + \sin x)}{\sinh(x)}} \]

На первый взгляд найти область определения этой функции не совсем просто. Одно начальное наблюдение, однако, можно сделать: присутствие тригонометрического слагаемого говорит о том, что получаемые условия, скорее всего, будут периодически повторяться. Теперь применим описанный выше метод, шаг за шагом рассматривая ограничения области определения, которые вносит каждая отдельная составляющая выражения, начиная с самых внутренних элементов.


Первый встречающийся нам элемент — [логарифм](<../logarithms>): \[\log(2 + \sin x)\]

Поскольку логарифм определён только для строго положительных значений, требуем:

\[2 + \sin x > 0\]

Так как \(\sin x\) принимает значения между \(-1\) и 1, наименьшее значение этого выражения равно \(2 - 1 = 1\), то есть уже положительно. Это значит, что логарифм не вносит никакого ограничения на область определения, так как его аргумент положителен при любом действительном \(x\).


Сделав шаг наружу, видим, что сам логарифм стоит в числителе дроби, знаменатель которой — \(\sinh(x)\). Знаменатель не может быть нулём, потому что деление на нуль не определено на [действительных числах](<../types-of-numbers>), поэтому нужно исключить значения \(x\), при которых \(\sinh(x) = 0\). Гиперболический синус обращается в нуль только при \(x = 0\), поэтому эту точку нужно удалить из области определения.


Наконец, вся дробь стоит под квадратным корнем, который требует неотрицательности аргумента.

  * Числитель \(\log(2 + \sin x)\) всегда неотрицателен и обращается в нуль ровно тогда, когда \(\sin x = -1\), то есть в точках \(x = -\frac{\pi}{2} + 2k\pi\). В этих точках дробь равна нулю и потому допустима, при условии что знаменатель отличен от нуля, а это всегда так, кроме точки \(x = 0\), уже исключённой.

  * При всех остальных значениях \(\log(2 + \sin x)\) строго положителен, поэтому знак всей дроби зависит только от знака \(\sinh(x)\). Гиперболический синус положителен при \(x > 0\) и отрицателен при \(x < 0\). Поскольку подкоренное выражение должно быть неотрицательным, дробь допустима в точности при \(x > 0\) или когда числитель равен нулю.


Объединяя эти наблюдения, получаем, что область определения состоит из всех \(x\), больших нуля, вместе с изолированными точками, где \(\sin x = -1\). Следовательно, область определения:

\[(0, +\infty) \;\cup\; \left\\{ -\frac{\pi}{2} + 2k\pi \,\middle|\, k \in \mathbb{Z} \right\\} \]

## Пример 3

Рассмотрим ещё один пример и найдём область определения функции:

\[f(x) = \sqrt{\cos^{2}(3x - 1) - \log\\!\bigl(5 - |2x|\bigr)} \]

Мы находим область определения, рассматривая выражение изнутри наружу, выявляя ограничения, которые вносит каждая составляющая, и объединяя их в конце. Первый элемент, налагающий ограничение, — логарифм. Поскольку натуральный логарифм принимает только строго положительные аргументы, нужно потребовать

\[5 - |2x| > 0 \]

Решая это [неравенство](<../linear-inequalities/>), содержащее [модуль](<../absolute-value/>), получаем:

\[|2x| < 5 \quad \rightarrow \quad -\frac{5}{2} < x < \frac{5}{2} \]


Тригонометрическая часть \(\cos^{2}(3x - 1)\) не вносит дополнительных ограничений, потому что [функция косинуса](<../cosine-function/>) и её квадрат определены при всех действительных значениях \(x\).


Теперь поднимемся на уровень выше и рассмотрим всё выражение под квадратным корнем. Квадратный корень определён только тогда, когда его аргумент неотрицателен, поэтому нужно потребовать

\[\cos^{2}(3x - 1) - \log(5 - |2x|) \ge 0 \]

Это неравенство связывает два слагаемых с совершенно разным поведением. Квадрат косинуса колеблется между 0 и 1, а логарифм изменяется на промежутке \((-5/2,\; 5/2)\) и становится сколь угодно большим, когда \(|2x|\) приближается к 5 снизу. Поэтому неравенство выполняется только для тех значений \(x\), при которых логарифмическое слагаемое не превосходит квадрат косинуса. Иначе говоря, должно выполняться:

\[\log(5 - |2x|) \le \cos^{2}(3x - 1) \]

Множество решений этого неравенства содержится в промежутке \((-5/2, 5/2)\), потому что вне этого промежутка логарифм уже не определён. Наконец, объединим все ограничения, взяв их пересечение, поскольку функция определена только тогда, когда одновременно выполняются все условия. Логарифм задаёт промежуток

\[-\frac{5}{2} < x < \frac{5}{2} \]

и внутри этого промежутка нужно дополнительно отобрать только те значения \(x\), для которых

\[\cos^{2}(3x - 1) - \log(5 - |2x|) \ge 0 \]

В заключение, область определения функции состоит из всех действительных значений \(x\), таких что:  
\[x \in \left(-\frac{5}{2},\, \frac{5}{2}\right) \]
