# Арксинус и арккосинус


## Арксинус

Арксинус — функция, обратная синусу. Для числа \(x \in [-1, 1]\) (то есть из множества значений, которые может принимать синус) \(\arcsin(x)\) определяется как угол \(\theta\) из промежутка \([-\pi/2, \pi/2]\), синус которого равен \(x\). Вообще, обратная функция отменяет действие исходной: если функция \(f\) переводит значение \(x\) в значение \(y\), то обратная к ней \(f^{-1}\) возвращает \(y\) в \(x\). Синус берёт угол и возвращает действительное число из \([-1, 1]\), а арксинус делает обратное, возвращая угол, синус которого равен заданному значению. Это обратное соотношение выражается тождеством:

\[
\sin(\arcsin(x)) = x \quad \forall \\, x \in [-1, 1]
\]

Формально определение арксинуса таково:

\[
\arcsin(x) = \theta \quad \iff \quad \sin(\theta) = x \quad \text{и} \quad \theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]
\]

Ограничение \(\theta\) промежутком \(\left[-\pi/2, \pi/2 \right]\) необходимо, потому что синус не инъективен на всей области определения. Без этого ограничения обратная функция не была бы корректно определена.

## Пример

Вычислим \(\arcsin\\!\left(\frac{1}{2}\right)\). Нам нужен угол \(\theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), для которого \(\sin(\theta) = \frac{1}{2}\). Из стандартных значений синуса известно, что:

\[
\sin\\!\left(\frac{\pi}{6}\right) = \frac{1}{2}
\]

Так как \(\frac{\pi}{6}\) принадлежит промежутку \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), оно удовлетворяет всем условиям определения. Заключаем, что:
\[\arcsin\\!\left(\frac{1}{2}\right) = \frac{\pi}{6}\]

## Основные значения арксинуса

В следующей таблице собраны стандартные значения \(\arcsin(x)\) для наиболее часто встречающихся аргументов:

\[
\begin{align}
x &= -1          &\quad& \arcsin(-1) = -\pi/2 \\\\[6pt]
x &= -\sqrt{3}/2 &\quad& \arcsin(-\sqrt{3}/2) = -\pi/3 \\\\[6pt]
x &= -1/2        &\quad& \arcsin(-1/2) = -\pi/6 \\\\[6pt]
x &= 0           &\quad& \arcsin(0) = 0 \\\\[6pt]
x &= 1/2         &\quad& \arcsin(1/2) = \pi/6 \\\\[6pt]
x &= \sqrt{3}/2  &\quad& \arcsin(\sqrt{3}/2) = \pi/3 \\\\[6pt]
x &= 1           &\quad& \arcsin(1) = \pi/2
\end{align}
\]

## Арккосинус

Арккосинус — функция, обратная косинусу. Для числа \(x \in [-1, 1]\) (то есть из множества значений, которые может принимать косинус) \(\arccos(x)\) определяется как угол \(\theta\) из промежутка \([0, \pi]\), косинус которого равен \(x\). Как и для арксинуса, сужение области прибытия до \([0, \pi]\) необходимо, чтобы обратная функция была корректно определена, поскольку косинус не инъективен на всей области определения. Соответствующее тождество таково:

\[
\cos(\arccos(x)) = x \quad \text{для всех } x \in [-1, 1]
\]

Формально определение арккосинуса таково:

\[
\arccos(x) = \theta \quad \text{тогда и только тогда, когда} \quad \cos(\theta) = x \quad \text{и} \quad \theta \in [0, \pi]
\]

## Основные значения арккосинуса

В следующей таблице собраны стандартные значения \(\arccos(x)\) для наиболее часто встречающихся аргументов:

\[
\begin{align}
x &= -1        &\quad& \arccos(-1) = \pi \\\\[6pt]
x &= -\sqrt{3}/2 &\quad& \arccos(-\sqrt{3}/2) = 5\pi/6 \\\\[6pt]
x &= -1/2      &\quad& \arccos(-1/2) = 2\pi/3 \\\\[6pt]
x &= 0         &\quad& \arccos(0) = \pi/2 \\\\[6pt]
x &= 1/2       &\quad& \arccos(1/2) = \pi/3 \\\\[6pt]
x &= \sqrt{3}/2  &\quad& \arccos(\sqrt{3}/2) = \pi/6 \\\\[6pt]
x &= 1         &\quad& \arccos(1) = 0
\end{align}
\]

## Свойства арксинуса и арккосинуса

Арксинус и арккосинус связаны следующим тождеством, которое верно для каждого \(x \in [-1, 1]\):

\[
\arcsin(x) + \arccos(x) = \frac{\pi}{2}
\]

Это тождество отражает дополнительность двух функций: поскольку синус и косинус углов, дополняющих друг друга до прямого, равны, угол, синус которого равен \(x\), и угол, косинус которого равен \(x\), в сумме всегда дают \(\pi/2\).


Второе свойство, на которое стоит обратить внимание, касается композиции функции с обратной к ней. В одну сторону всё просто: применение арксинуса после синуса или арккосинуса после косинуса возвращает исходное значение при условии, что аргумент лежит в нужном промежутке. Формально:

\[
\sin(\arcsin(x)) = x \quad \forall x \in [-1, 1]
\]

\[
\cos(\arccos(x)) = x \quad \forall x \in [-1, 1]
\]

Обратная композиция, однако, в общем случае не выполняется. Для произвольного угла \(\theta\) имеем:

\[
\arcsin(\sin(\theta)) = \theta \quad \iff  \quad \theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]
\]

\[
\arccos(\cos(\theta)) = \theta \quad \iff \quad \theta \in [0, \pi]
\]

> За пределами этих промежутков арксинус и арккосинус возвращают единственного представителя \(\theta\) в своих множествах значений, а не само \(\theta\). Эта асимметрия — прямое следствие ограничений области определения, наложенных для того, чтобы обратные функции были корректно определены, и именно она отличает настоящую обратную функцию от простой левой или правой обратной.

## Функции арксинус и арккосинус

Функция арксинус \(f(x) = \arcsin(x)\) сопоставляет каждому значению \(x \in [-1, 1]\) угол \(\theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), синус которого равен \(x\). Её график — непрерывная строго возрастающая кривая.

* Область определения: \(x \in [-1, 1]\)
* Множество значений: \(y \in [-\pi/2, \pi/2]\)
* Периодичность: функция арксинус не периодична.
* Чётность: функция нечётна, она удовлетворяет \(\arcsin(-x) = -\arcsin(x)\).


Функция арккосинус \(f(x) = \arccos(x)\) сопоставляет каждому значению \(x \in [-1, 1]\) угол \(\theta \in [0, \pi]\), косинус которого равен \(x\). Её график — непрерывная строго убывающая кривая.

* Область определения: \(x \in [-1, 1]\)
* Множество значений: \(y \in [0, \pi]\)
* Периодичность: функция арккосинус не периодична.
* Чётность: функция ни нечётна, ни чётна, но удовлетворяет тождеству \(\arccos(-x) = \pi - \arccos(x)\).
