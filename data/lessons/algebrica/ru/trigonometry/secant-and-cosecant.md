# Секанс и косеканс


## Секанс

Рассмотрим единичную окружность с центром в начале координат \(\text{O} = (0,0)\) и радиусом 1. Пусть \(\theta\) — угол в стандартном положении, а \(\text{P}\) — точка на окружности, в которой её пересекает конечная сторона угла \(\theta\). Проведём касательную к окружности в точке \(\text{P}\) и пусть \(\text{S}\) — точка, в которой эта касательная пересекает ось \(x\). Секанс угла \(\theta\) определяется как длина отрезка \(\overline{OS}\) со знаком, то есть абсцисса \(x_S\) точки \(\text{S}\):

\[
\sec(\theta) = \overline{OS} = x_S
\]

Чтобы выразить эту длину через привычные тригонометрические величины, рассмотрим прямоугольный треугольник, образованный точками \(\text{O}\), \(\text{P}\) и основанием перпендикуляра из \(\text{P}\) на ось \(x\). Так как \(\text{OP} = 1\), горизонтальная составляющая точки \(\text{P}\) равна \(\cos(\theta)\), а касательная в \(\text{P}\) перпендикулярна радиусу \(\overline{OP}\), из подобия треугольников можно получить, что:

\[
\sec(\theta) = \frac{1}{\cos(\theta)}
\]

Так как секанс обратен косинусу, он определён только при тех углах, при которых косинус не обращается в нуль. Косинус равен нулю при всех нечётных кратных \(\pi/2\), поэтому из области определения секанса исключаются именно эти значения:

\[
\sec(\theta) = \frac{1}{\cos(\theta)}
\qquad \forall\\, \theta \neq \frac{\pi}{2} + k\pi, \quad k \in \mathbb{Z}
\]

Из геометрического построения видно, что секанс измеряет, во сколько раз нужно удлинить единичный радиус, чтобы достичь точки \(\text{S}\), в которой касательная в \(\text{P}\) пересекает ось \(x\). Это истолкование делает очевидным, почему \(|\sec(\theta)| \geq 1\) всюду, где функция определена: точка пересечения \(\text{S}\) обязательно лежит от начала координат на расстоянии не меньше радиуса самой единичной окружности.

## Основные значения секанса

Ниже приведены некоторые общеизвестные значения \(\sec(\theta)\) для выбранных углов, полезные в различных приложениях тригонометрии:

\[
\begin{align}
\theta &= 0^\circ = 0\\,\text{рад}      && \sec(\theta) = 1 \\\\[6pt]
\theta &= 30^\circ = \pi/6\\,\text{рад} && \sec(\theta) = \tfrac{2\sqrt{3}}{3} \\\\[6pt]
\theta &= 45^\circ = \pi/4\\,\text{рад} && \sec(\theta) = \sqrt{2} \\\\[6pt]
\theta &= 60^\circ = \pi/3\\,\text{рад} && \sec(\theta) = 2 \\\\[6pt]
\theta &= 90^\circ = \pi/2\\,\text{рад} && \sec(\theta) \text{ не определён}
\end{align}
\]

## Тригонометрические тождества для секанса

+ \[ \text{1. } \quad \sec x = \frac{1}{\cos x} \]

+ \[ \text{2. } \quad 1 + \tan^{2} x = \sec^{2} x \]

+ \[ \text{3. } \quad \sec(-x) = \sec x \]

+ \[ \text{4. } \quad \sec x \\,\tan x = \frac{\sin x}{\cos^{2} x} \]

+ \[ \text{5. } \quad \sec^{2} x - \tan^{2} x = 1 \]

> Эти формулы собирают самые полезные тождества с секансом, включая определение через обратную величину, пифагорово тождество, соотношение симметрии и распространённые алгебраические преобразования. Более полный обзор — в полном собрании тригонометрических тождеств.

## Косеканс

Рассмотрим снова ту же конструкцию: касательная, проведённая в \(\text{P}\) к единичной окружности, пересекает ось \(y\) в точке \(\text{Q}\). Косеканс угла \(\theta\) определяется как длина отрезка \(\overline{OQ}\) со знаком, то есть ордината \(y_Q\) точки \(\text{Q}\):

\[
\csc(\theta) = \overline{OQ} = y_Q
\]

Если рассуждать так же, как для секанса, и применить подобие треугольников к этой конфигурации, получим следующее выражение через синус:

\[
\csc(\theta) = \frac{1}{\sin(\theta)}
\]

Так как косеканс обратен синусу, он определён только при тех углах, при которых синус не обращается в нуль. Синус равен нулю при всех целых кратных \(\pi\), поэтому из области определения косеканса исключаются именно эти значения:

\[
\csc(\theta) = \frac{1}{\sin(\theta)} \qquad \forall\\, \theta \neq k\pi, \quad k \in \mathbb{Z}
\]

Аналогично секансу, косеканс измеряет, во сколько раз нужно удлинить единичный радиус, чтобы достичь точки \(\text{Q}\), в которой касательная в \(\text{P}\) пересекает ось \(y\). Это истолкование делает очевидным, почему \(|\csc(\theta)| \geq 1\) всюду, где функция определена: точка пересечения \(\text{Q}\) обязательно лежит от начала координат на расстоянии не меньше радиуса самой единичной окружности.

## Геометрическая интерпретация

Оба определения вытекают из единого геометрического объекта: касательная, проведённая в \(\text{P}\), одновременно определяет точку \(\text{S}\) на оси \(x\) и точку \(\text{Q}\) на оси \(y\), давая секанс и косеканс из одного построения.

Это делает прозрачным и асимметричное поведение двух функций. Когда конечная сторона \(\theta\) приближается к горизонтальному положению, касательная в \(\text{P}\) становится почти параллельной оси \(x\), уводя \(\text{S}\) на бесконечность и делая секанс неограниченным, тогда как \(\text{Q}\) остаётся вполне определённой. Ситуация меняется на обратную, когда конечная сторона приближается к вертикальному положению.

\[
\begin{align}
\theta &= 0^\circ = 0\\,\text{рад}      && \csc(\theta) \text{ не определён} \\\\[6pt]
\theta &= 30^\circ = \pi/6\\,\text{рад} && \csc(\theta) = 2 \\\\[6pt]
\theta &= 45^\circ = \pi/4\\,\text{рад} && \csc(\theta) = \sqrt{2} \\\\[6pt]

\theta &= 90^\circ = \pi/2\\,\text{рад} && \csc(\theta) = 1
\end{align}
\]

## Функции секанс и косеканс

Функция секанса \(f(x) = \sec(x)\) сопоставляет каждому углу \(x\), выраженному в радианах, значение \(1/\cos(x)\). Её график — периодическая кривая с периодом \(2\pi\), имеющая вертикальные асимптоты в точках, где обращается в нуль косинус, то есть при \(x = \pi/2 + k\pi\) для \(k \in \mathbb{Z}\). Область определения \(\sec(x)\) состоит из всех действительных чисел, кроме этих точек, а множество значений — \((-\infty, -1] \cup [1, +\infty)\).

+ Область определения: \( \{ x \in \mathbb{R} : \cos(x) \neq 0 \} = \{ x \in \mathbb{R} : x \neq \pi/2 + k\pi \text{ для всех } k \in \mathbb{Z} \} \)
+ Множество значений: \( y \in (-\infty, -1] \cup [1, \infty) \)
+ Периодичность: периодичен по \( x \) с периодом \( 2\pi \)
+ Чётность: чётен, \( \sec(-x) = \sec(x) \)


Функция косеканса \(f(x) = \csc(x)\) сопоставляет каждому углу \(x\), выраженному в радианах, значение \(1/\sin(x)\). Её график — периодическая кривая с периодом \(2\pi\), имеющая вертикальные асимптоты в точках, где обращается в нуль синус, то есть при \(x = k\pi\) для \(k \in \mathbb{Z}\). Область определения \(\csc(x)\) состоит из всех действительных чисел, кроме этих точек, а множество значений — \((-\infty, -1] \cup [1, +\infty)\).

+ Область определения: \( \{ x \in \mathbb{R} : \sin(x) \neq 0 \} = \{ x \in \mathbb{R} : x \neq k\pi \text{ для всех } k \in \mathbb{Z} \} \)
+ Множество значений: \( y \in (-\infty, -1] \cup [1, \infty) \)
+ Периодичность: периодичен по \( x \) с периодом \( 2\pi \)
+ Чётность: нечётен, \( \csc(-x) = -\csc(x) \)

## Тригонометрические тождества для косеканса

+ \[ \text{1. } \quad \csc x = \frac{1}{\sin x} \]

+ \[ \text{2. } \quad 1 + \cot^{2} x = \csc^{2} x \]

+ \[ \text{3. } \quad \csc(-x) = -\\,\csc x \]

+ \[ \text{4. } \quad \csc x \\,\cot x = \frac{\cos x}{\sin^{2} x} \]

+ \[ \text{5. } \quad \csc^{2} x - \cot^{2} x = 1 \]

> Эти формулы собирают самые полезные тождества с косекансом, включая определение через обратную величину, пифагорово тождество, соотношение симметрии и распространённые алгебраические преобразования. Более полный обзор — в полном собрании тригонометрических тождеств.
