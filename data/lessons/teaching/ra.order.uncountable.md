# The Uncountability of the Reals

**Uncountable:** a set that cannot be listed as a sequence; the reals are uncountable, so no enumeration can contain every real number.

## Cantor's diagonal argument

Suppose, for contradiction, that the real numbers could be listed. Write each listed number as an infinite decimal and look at the diagonal: the first digit of the first number, the second digit of the second, and so on. Build a new decimal whose nth digit differs from the nth diagonal digit, choosing digits other than nought and nine so the number has a unique expansion. The new number differs from the nth listed number in its nth digit, for every n, so it is missing from the list. No listing can be complete.

## Consequences

Uncountability immediately separates the reals from the rationals and the integers, both of which are countable. Every set that contains an interval of reals is uncountable, because a copy of the interval sits inside it. The transcendental numbers are uncountable, since the algebraic numbers are countable and removing a countable set from an uncountable one leaves an uncountable remainder. So almost every real number is transcendental, even though individual transcendence is hard to prove.

## A contrast with measure

Cardinality and length measure are different ideas, and the reals show it. Any countable set has measure zero, because its points can be covered by intervals of arbitrarily small total length. Yet the interval from nought to one has length one while containing uncountably many more points than any countable set. A set can be small in cardinality and large in measure, or the reverse; the diagonal argument is about counting, not about length.
