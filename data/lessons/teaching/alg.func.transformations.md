# Transformations of Graphs

**Transformation:** a shift, stretch or reflection that turns the graph of one function into the graph of a related function; additions outside the function move it vertically, additions inside move it horizontally.

## Shifts and reflections

Adding a constant to the output moves the whole graph up by that amount, and subtracting moves it down. Negating the output reflects the graph across the horizontal axis, turning every height into its opposite. These changes act on the values the function returns, so they are the easy ones to read: what the graph produces is changed directly, and the shape is otherwise untouched.

## Stretches and compressions

Multiplying the output by a constant stretches the graph vertically when the constant exceeds one and compresses it when the constant is between zero and one. Inside the function the effect on the graph is inverted: doubling the input compresses the graph horizontally by a factor of two, because each output now arrives twice as soon. Students predict inside changes wrongly for exactly this reason, so it is worth stating plainly: inside transformations do the opposite of what they appear to do.

## Order matters

When several transformations are applied at once, the order in which they are read changes the result. A horizontal shift followed by a horizontal stretch is not the same as the stretch followed by the shift, because the shift is itself scaled by the stretch. The reliable method is to identify the parent function, list the transformations from the outside in, and apply them to the coordinates of a few known points rather than to the formula alone.
