# Supremum and Infimum

**Supremum:** the least upper bound of a set, the smallest number that no element of the set exceeds; the infimum is the greatest lower bound, defined by the matching dual condition.

## The least upper bound

An upper bound of a set is any number that every element of the set is at most. A set with an upper bound is bounded above, and among its upper bounds there may be a smallest one. That smallest upper bound is the supremum, also called the least upper bound. The infimum or greatest lower bound is the mirror image with the inequalities reversed. Neither need belong to the set, and this is exactly what separates them from the maximum and the minimum.

## Worked: a half-open interval

The half-open interval of all numbers x with nought less than x and x at most one is bounded above by one. No number smaller than one is an upper bound, because elements of the interval come arbitrarily close to one from below. So the supremum is one, and because one belongs to the interval it is also the maximum. The infimum is nought, but nought does not belong to the interval, so the set has no minimum. The supremum and the maximum differ precisely when the least upper bound is left out.

## Supremum versus maximum

A maximum is an element of the set that is at least every other element, so it must be in the set. The supremum may lie outside. For the open interval of numbers strictly between nought and one the supremum is still one, but the set has no maximum because one is excluded. A set can have a supremum and no maximum, but it can never have a maximum without the maximum being the supremum. When the set is unbounded above it has no real upper bound at all, which the extended line later absorbs with one symbol.
