# Domain and Range of an Inverse Function

**Inverse function:** the function that undoes another one, sending each output back to the input that produced it; it exists only when distinct inputs give distinct outputs.

## Swapping domain and range

An inverse function reverses the direction of the original: every value in the range of the original becomes an input of the inverse, and every value in the domain of the original becomes an output. The domain of the inverse is therefore the range of the original, and the range of the inverse is the domain of the original. Reading the restriction this way is why a function with range limited to a small interval has an inverse with a small domain.

## One-to-one and how to fix it

An inverse can only exist when the original is one-to-one, so that each output came from exactly one input. A function that fails this test on its natural domain can often be repaired by restricting the domain until it passes, which is what the square-root branch of a parabola does. The restriction is not a technicality: it is the choice of which input to send each output back to.

## Reading a graph

On a graph the inverse is the mirror image across the diagonal line where the coordinates are equal. A horizontal line that cuts the original twice would make the inverse assign two different inputs to one output, so a function is one-to-one exactly when no horizontal line cuts it more than once. The domain and range swap is visible in the picture as the exchange of the two axes.
