# Graphs of Exponential Functions

**Exponential function:** a function of the form a times b to the power x with b positive, growing or decaying by a constant factor over each unit step.

## Shape of the curve

An exponential function with a base greater than one rises ever more steeply as the input grows and flattens toward zero as the input falls, so the horizontal axis is an asymptote on the left and there is no ceiling on the right. It passes through the point where the input is zero at a height equal to the leading coefficient, because any positive base raised to the zero power is one. Every value is positive, so the graph never touches or crosses the horizontal axis.

## The constant factor

The defining feature of an exponential is that equal steps in the input multiply the output by an equal factor. Doubling the base makes the curve steeper, while a base between zero and one turns the rise into a fall and gives decay rather than growth. Evaluating the function is a short exercise in repeated multiplication: raise the base to the exponent and multiply by the coefficient, which is why a table of values is easy to build and the curve easy to sketch.

## Why it grows faster than any power

An exponential eventually overtakes any polynomial, however high its degree, because the repeated multiplication compounds while the power grows only through a fixed number of factors. This is why compound interest, population growth and radioactive decay are modelled exponentially: the change over a step is proportional to the amount present, so the factor repeats. The same fact makes the exponential the natural home of the number whose rate of growth equals its value.
