# Evaluating a Piecewise Function

**Piecewise function:** a function defined by different formulas on different parts of its domain, with the branch chosen by which part the input lies in.

## Choosing the branch

A piecewise function gives several formulas and a rule that says which formula applies where. To evaluate it at a point you first decide which part of the domain the input belongs to, then use the formula for that part and nothing else. The boundary points need care: a strict inequality sends the boundary to the other branch, and a non-strict one keeps it. Reading the conditions in order and stopping at the first true one is the safe habit.

## Evaluating a two-piece rule

For a rule that uses one linear expression below zero and another at zero and above, the input decides the branch and the arithmetic is then ordinary. A negative input goes to the first expression; a zero or positive input goes to the second. The value at the boundary belongs to the branch whose inequality includes it, which is why the convention a textbook chooses must be read rather than assumed.

## Where piecewise functions appear

Piecewise definitions describe anything that changes behaviour at a threshold: a tax bracket, a shipping rate that jumps after a weight, a cell phone plan with a monthly allowance, or a temperature in Fahrenheit below freezing. They also make the absolute value a piecewise function, because the sign of its input decides which of two expressions is used. The idea is the same in each case: the formula is local, and the domain tells you where.
