# Доказательство по индукции

**Математическая индукция:** метод доказательства, который устанавливает утверждение для всех натуральных чисел с помощью базы и шага от каждого числа к следующему.

## Две части

Доказательство по индукции состоит из базы, которая показывает, что утверждение верно для первого числа, и шага индукции, который показывает: если утверждение верно для некоторого числа, то оно верно и для следующего. Вместе они образуют непрерывную цепочку: база запускает её, а шаг передаёт дальше, так что охвачено каждое число, начиная с базы. Нужны обе части, и ни одна из них сама по себе ничего не доказывает.

## Построение шага

Шаг индукции начинается с предположения, которое называют индукционным, что утверждение верно для некоторого n. Затем нужно доказать утверждение для n плюс один, используя это предположение, обычно записывая случай n плюс один в форме, содержащей случай n, и заменяя его предполагаемым значением. Держать предположение перед глазами, преобразуя более крупный случай, — вот навык, которому учит этот метод.

## За пределами простой формы

Варианты ослабляют две части, не меняя идеи. Сильная индукция предполагает утверждение для всех чисел вплоть до n, а не только для n, и это нужно, когда следующий случай зависит от нескольких предыдущих. Если базу взять позже, можно доказать утверждение начиная с некоторого числа, а не с единицы, и это именно то, что нужно утверждению, ложному в начале.
