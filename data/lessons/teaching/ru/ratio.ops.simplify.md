## 5.6 Отношения и отношения величин

### Цели обучения

К концу этого раздела вы научитесь:

- записывать отношение в виде дроби
- записывать отношение величин в виде дроби
- находить величины на единицу
- находить цену за единицу
- переводить фразы в выражения с дробями

### Запись отношения в виде дроби

Когда вы подаёте заявку на ипотеку, кредитный специалист сравнивает ваш общий долг с вашим общим доходом, чтобы решить, подходите ли вы для получения кредита. Это сравнение называется отношением долга к доходу. Отношение сравнивает две величины, измеренные в одной и той же единице. Если мы сравниваем $a$ и $b$, отношение записывается как ${a\ \text{к}\ b,}\ {\frac{a}{b},\ \text{или}\ \textit{a}\text{:}\textit{b}\text{.}}$

### Отношения

Отношение сравнивает два числа или две величины, измеренные в одной и той же единице. Отношение $a$ к $b$ записывается ${a\ \text{к}\ b,}\ {\frac{a}{b},\ \text{или}\ \textit{a}\text{:}\textit{b}\text{.}}$

В этом разделе мы будем пользоваться записью в виде дроби. Когда отношение записано в виде дроби, дробь нужно сократить. Если это неправильная дробь, мы не превращаем её в смешанное число. Поскольку отношение сравнивает две величины, мы оставим отношение в виде $\frac{4}{1}$, а не упростим его до 4, чтобы были видны две части отношения.

### Пример 5.58

Запишите каждое отношение в виде дроби: а) $15\ \text{к}\ 27$ б) $45\ \text{к}\ 18.$

#### Решение

|  |  |
|----|----|
| а) |  |
|  | $\text{15 к 27}$ |
| Запишите в виде дроби, поставив первое число в числитель, а второе в знаменатель. | $\frac{15}{27}$ |
| Сократите дробь. | $\frac{5}{9}$ |

|  |  |
|----|----|
| б) |  |
|  | $\text{45 к 18}$ |
| Запишите в виде дроби, поставив первое число в числитель, а второе в знаменатель. | $\frac{45}{18}$ |
| Сократите. | $\frac{5}{2}$ |

Отношение в (б) мы оставляем в виде неправильной дроби.

#### Отношения с десятичными дробями

Нам часто приходится работать с отношениями десятичных дробей, особенно когда отношения связаны с деньгами. В таких случаях можно избавиться от десятичных дробей, воспользовавшись свойством равных дробей, чтобы преобразовать отношение в дробь с натуральными числами в числителе и знаменателе.

Например, рассмотрим отношение $0.8\ \text{к}\ 0.05.$ Его можно записать в виде дроби с десятичными дробями, а затем умножить числитель и знаменатель на 100, чтобы избавиться от десятичных дробей.

Видите ли вы короткий путь к равной дроби? Заметьте, что $0.8 = \frac{8}{10}$ и $0.05 = \frac{5}{100}.$ Наименьший общий знаменатель дробей $\frac{8}{10}$ и $\frac{5}{100}$ равен 100. Умножив числитель и знаменатель $\frac{0.8}{0.05}$ на 100, мы «передвинули» десятичную точку на два знака вправо и получили равную дробь без десятичных знаков. Теперь, когда мы понимаем математику, стоящую за этим процессом, мы можем находить дробь без десятичных знаков так:

|                              |                  |
|------------------------------|------------------|
|                              |                  |
| «Передвиньте» десятичную точку на 2 знака. | $\frac{80}{5}$ |
| Сократите.                    | $\frac{16}{1}$ |

Не обязательно выписывать каждый шаг, когда вы умножаете числитель и знаменатель на степени десяти. Пока вы передвигаете обе десятичные точки на одно и то же число знаков, отношение остаётся прежним.

#### Применение отношений

Одно из практических применений отношений, затрагивающее многих людей, — измерение холестерина в крови. Отношение общего холестерина к холестерину ЛПВП — один из способов, которыми врачи оценивают общее состояние здоровья человека. Отношение меньше 5 к 1 считается хорошим.

### Пример 5.61

Общий холестерин Гектора равен 249 мг/дл, а его холестерин ЛПВП — 39 мг/дл. а) Найдите отношение его общего холестерина к холестерину ЛПВП. б) Предположив, что отношение меньше 5 к 1 считается хорошим, что вы посоветовали бы Гектору?

#### Решение

а) Сначала запишем слова, которые выражают отношение. Нам нужно узнать отношение общего холестерина Гектора к его холестерину ЛПВП.

|  |  |
|----|----|
| Запишите в виде дроби. | $\frac{\text{общий холестерин}}{\text{холестерин ЛПВП}}$ |
| Подставьте значения. | $\frac{249}{39}$ |
| Сократите. | $\frac{83}{13}$ |

б) В порядке ли отношение холестерина Гектора? Если разделить 83 на 13, получим приблизительно 6.4, поэтому $\frac{83}{13} \approx \frac{6.4}{1}.$ Отношение холестерина Гектора высокое! Гектору следует либо снизить общий холестерин, либо повысить холестерин ЛПВП.

#### Отношение двух величин в разных единицах

Чтобы найти отношение двух измерений, нужно убедиться, что величины измерены в одной и той же единице. Если измерения выражены в разных единицах, их сначала нужно перевести в одни и те же единицы.

Мы знаем, что для сокращения дроби мы делим числитель и знаменатель на общие множители. Точно так же в отношении измерений мы сокращаем общую единицу.

### Пример 5.62

Нормы закона об американцах с ограниченными возможностями (ADA) для пандусов инвалидных колясок требуют, чтобы изменение по вертикали составляло не более 1 дюйма на каждый 1 фут изменения по горизонтали. Каково отношение изменения по вертикали к изменению по горизонтали?

#### Решение

В отношении измерения должны быть в одних и тех же единицах. Мы можем перевести футы в дюймы или дюймы в футы. Обычно проще переводить в меньшую единицу, так как при этом в задачу не добавляется больше дробей.

Запишите слова, выражающие отношение.

|  |  |
|----|----|
|  | Отношение изменения по вертикали к изменению по горизонтали |
| Запишите отношение в виде дроби. | $\frac{\text{изменение по вертикали}}{\text{изменение по горизонтали}}$ |
| Подставьте заданные значения. | $\frac{\text{1 дюйм}}{\text{1 фут}}$ |
| Переведите 1 фут в дюймы. | $\frac{\text{1 дюйм}}{\text{12 дюймов}}$ |
| Сократите, разделив на общие множители и единицы. | $\frac{1}{12}$ |

Итак, отношение изменения по вертикали к изменению по горизонтали равно 1 к 12. Это означает, что пандус должен подниматься на 1 дюйм на каждые 12 дюймов изменения по горизонтали, чтобы соответствовать нормам.

### Запись отношения величин в виде дроби

Часто нам нужно сравнить два разных вида измерений, например мили и галлоны. Для такого сравнения мы используем отношение величин. Примеры отношений величин: 120 миль за 2 часа, 160 слов за 4 минуты и $\text{\$5}$ за 64 унции.

### Отношение величин

Отношение величин сравнивает две величины в разных единицах. Отношение величин обычно записывается в виде дроби.

Когда мы записываем дробь как отношение величин, мы ставим первое заданное количество вместе с его единицами в числитель, а второе количество вместе с его единицами в знаменатель. При сокращении отношений величин единицы остаются в числителе и знаменателе.

### Пример 5.63

Боб проехал на своей машине 525 миль за 9 часов. Запишите это отношение величин в виде дроби.

#### Решение

|  |  |
|----|----|
|  | $\text{525 миль за 9 часов}$ |
| Запишите в виде дроби, поставив 525 миль в числитель, а 9 часов в знаменатель. | $\frac{\text{525 миль}}{\text{9 часов}}$ |
|  | $\frac{\text{175 миль}}{\text{3 часа}}$ |

Итак, 525 миль за 9 часов равно $\frac{\text{175 миль}}{\text{3 часа}}.$

### Нахождение величин на единицу

В предыдущем примере мы вычислили, что Боб ехал с отношением $\frac{\text{175 миль}}{\text{3 часа}}.$ Это означает, что каждые три часа Боб проезжает 175 миль. Это верно, но не слишком полезно. Обычно мы хотим, чтобы отношение показывало число миль за один час. Отношение величин, у которого в знаменателе 1 единица, называют величиной на единицу.

### Величина на единицу

Величина на единицу — это отношение величин со знаменателем 1 единица.

Величины на единицу очень часто встречаются в нашей жизни. Например, когда мы говорим, что едем со скоростью 68 миль в час, мы имеем в виду, что проезжаем 68 миль за 1 час. Мы запишем это отношение величин как 68 миль/час (читается 68 миль в час). Общепринятое сокращение для этого — 68 миль/ч. Обратите внимание: когда перед единицей не записано число, предполагается, что это 1.

Итак, 68 миль/час на самом деле означает $\text{68 миль/1 час.}$

Два отношения величин, которыми мы часто пользуемся за рулём, можно записать в разных формах, как показано:

| Пример | Отношение величин | Запись | Сокращение | Чтение |
|----|----|----|----|----|
| 68 миль за 1 час | $\frac{\text{68 миль}}{\text{1 час}}$ | 68 миль/час | 68 миль/ч | $\text{68 миль в час}$ |
| 36 миль на 1 галлон | $\frac{\text{36 миль}}{\text{1 галлон}}$ | 36 миль/галлон | 36 миль/гал | $\text{36 миль на галлон}$ |

Другой пример величины на единицу, который вы, возможно, уже знаете, — почасовая оплата. Обычно она выражается суммой денег, заработанной за один час работы. Например, если вам платят $\text{\$12.50}$ за каждый час работы, можно записать, что ваша почасовая оплата (на единицу) равна $\text{\$12.50/час}$ (читается $\text{\$12.50}$ в час.)

Чтобы перевести отношение величин в величину на единицу, мы делим числитель на знаменатель. Так в знаменателе получается 1.

### Пример 5.64

Анита получила $\text{\$384}$ на прошлой неделе за работу в течение $\text{32 часов}.$ Какова почасовая оплата Аниты?

#### Решение

|  |  |
|----|----|
| Начните с отношения долларов к часам. Затем разделите. | $\text{\$384 за прошлую неделю за 32 часа}$ |
| Запишите в виде отношения величин. | $\frac{\$ 384}{\text{32 часа}}$ |
| Разделите числитель на знаменатель. | $\frac{\$ 12}{\text{1 час}}$ |
| Перепишите в виде отношения величин. | $\$ 12/\text{час}$ |

Почасовая оплата Аниты — $\text{\$12}$ в час.

### Нахождение цены за единицу

Иногда мы покупаем обычные товары для дома «оптом», когда несколько штук упакованы вместе и продаются за одну цену. Чтобы сравнить цены упаковок разного размера, нужно найти цену за единицу. Чтобы найти цену за единицу, разделите общую цену на число штук. Цена за единицу — это величина на единицу для одного предмета.

### Цена за единицу

Цена за единицу — это величина на единицу, показывающая цену одного предмета.

### Пример 5.66

Продуктовый магазин берёт $\text{\$3.99}$ за ящик из 24 бутылок воды. Какова цена за единицу?

#### Решение

Что нас просят найти? Нас просят найти цену за единицу, то есть цену за бутылку.

|  |  |
|----|----|
| Запишите в виде отношения величин. | $\frac{\$ 3.99}{\text{24 бутылки}}$ |
| Разделите, чтобы найти цену за единицу. | $\frac{\$ 0.16625}{\text{1 бутылка}}$ |
| Округлите результат до ближайшего пенни. | $\frac{\$ 0.17}{\text{1 бутылка}}$ |

Цена за единицу приблизительно равна $\text{\$0.17}$ за бутылку. Каждая бутылка стоит около $\text{\$0.17}.$

### Попробуйте сами 5.132

Цены за единицу очень полезны, если вы сравниваете цены перед покупкой. *Более выгодная покупка* — товар с меньшей ценой за единицу. В большинстве продуктовых магазинов цена за единицу каждого товара указана на полках.

### Пример 5.67

Пол выбирает стиральный порошок. В продуктовом магазине жидкое средство стоит $\text{\$14.99}$ на 64 стирки, а порошок той же марки — $\text{\$15.99}$ на 80 стирок.

#### Решение

Чтобы сравнить цены, сначала найдём цену за единицу для каждого вида средства.  

|  |  |  |
|----|----|----|
|  | Жидкое | Порошок |
| Запишите в виде отношения величин. | $\frac{\text{\$14.99}}{\text{64 стирки}}$ | $\frac{\text{\$15.99}}{\text{80 стирок}}$ |
| Найдите цену за единицу. | $\frac{\text{\$0.234…}}{\text{1 стирка}}$ | $\frac{\text{\$0.199…}}{\text{1 стирка}}$ |
| Округлите до ближайшего цента. | \$\begin{array}{l}
\text{\$0.23/стирка} \\
\text{(23 цента за стирку.)}
\end{array}$ | $\begin{array}{l}
\text{\$0.20/стирка} \\
\text{(20 центов за стирку)}
\end{array}\$ |

Теперь сравним цены за единицу. Цена за единицу жидкого средства — около $\text{\$0.23}$ за стирку, а цена за единицу порошка — около $\text{\$0.20}$ за стирку. Порошок — более выгодная покупка.

### Перевод фраз в выражения с дробями

Заметили ли вы, что в примерах этого раздела использовались сравнительные слова *отношение ... к, к, за, в, на* и *из*? Когда вы переводите фразы, содержащие эти слова, нужно подумать либо об отношении, либо об отношении величин. Если единицы измеряют одну и ту же величину (длину, время и так далее), у вас отношение. Если единицы разные, у вас отношение величин. В обоих случаях вы записываете дробь.
