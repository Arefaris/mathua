## 6.1 Что такое процент

### Цели обучения

К концу этого раздела вы научитесь:

- использовать определение процента
- переводить проценты в обыкновенные и десятичные дроби
- переводить десятичные и обыкновенные дроби в проценты

### Использование определения процента

Сколько центов в одном долларе? В долларе 100 центов. Сколько лет в одном веке? В веке 100 лет. Не подсказывает ли это, что означает слово «процент»? В английском языке это два слова, «per cent», и означает оно «на сто». Процент — это отношение, знаменатель которого равен 100. Мы используем знак процента $\text{\%,}$ чтобы записывать проценты.

### Процент

Процент — это отношение, знаменатель которого равен 100.

По данным Американской ассоциации общественных колледжей $(2015)\text{,}$ около $\text{57\%}$ студентов общественных колледжей — женщины. Это значит, что из каждых 100 студентов общественных колледжей 57 — женщины, как показано на рисунке 6.2. Из 100 квадратов сетки 57 закрашены, и мы записываем это как отношение $\frac{57}{100}.$

![Из каждых 100 студентов общественных колледжей 57 — женщины.](/diagrams/prealgebra/6.2.png)

*Рисунок 6.2 Из каждых 100 студентов общественных колледжей 57 — женщины.*

Аналогично, $\text{25\%}$ — это отношение ${\frac{25}{100},}\text{3\%}$ — это отношение $\frac{3}{100}$ и $\text{100\%}$ — это отношение $\frac{100}{100}.$ Словами: «сто процентов» означает, что целое, то есть $\text{100\%}$, равно $\frac{100}{100},$ а так как $\frac{100}{100} = 1,$ мы видим, что $\text{100\%}$ означает 1 целое.

### Пример 6.1

По данным Института государственной политики Калифорнии $(2010)\text{,}\ \text{44\%}$ родителей школьников государственных школ хотели бы, чтобы их младший ребёнок получил степень магистра или выше. Запишите этот процент в виде отношения.

#### Решение

|  |  |
|----|----|
| Величина, которую мы хотим перевести, — 44%. | $44\%$ |
| Запишите процент в виде отношения. Помните, что *процент* означает «на 100». | $\frac{44}{100}$ |

### Перевод процентов в дроби и десятичные дроби

Так как проценты — это отношения, их легко записать в виде дробей. Помните, что процент означает «на 100», поэтому знаменатель дроби равен 100.

### Как сделать

#### Переведите процент в дробь.

1.  Шаг 1. Запишите процент в виде отношения со знаменателем 100.
2.  Шаг 2. Если возможно, упростите дробь.

### Пример 6.3

Переведите каждый процент в дробь:

1.  (a)$\text{36\%}$
2.  (b)$\text{125\%}$

#### Решение

|                                        |                    |
|----------------------------------------|--------------------|
| (a)                                      |                    |
|                                        | $36\%$           |
| Запишите в виде отношения со знаменателем 100. | $\frac{36}{100}$ |
| Упростите.                              | $\frac{9}{25}$   |

|                                        |                     |
|----------------------------------------|---------------------|
| (b)                                      |                     |
|                                        | $125\%$           |
| Запишите в виде отношения со знаменателем 100. | $\frac{125}{100}$ |
| Упростите.                              | $\frac{5}{4}$     |

### Пример 6.4

Переведите каждый процент в дробь:

1.  (a)$\text{24.5\%}$
2.  (b)$33\frac{1}{3}\%$

#### Решение

|  |  |
|----|----|
| (a) |  |
|  | $24.5\%$ |
| Запишите в виде отношения со знаменателем 100. | $\frac{24.5}{100}$ |
| Избавьтесь от десятичной дроби, умножив числитель и знаменатель на 10. | $\frac{24.5{(10)}}{100{(10)}}$ |
| Умножьте. | $\frac{245}{1000}$ |
| Перепишите, выделив общие множители. | $\frac{5 \cdot 49}{5 \cdot 200}$ |
| Упростите. | $\frac{49}{200}$ |

|  |  |
|----|----|
| (b) |  |
|  | $33\frac{1}{3}\%$ |
| Запишите в виде отношения со знаменателем 100. | $\frac{33\frac{1}{3}}{100}$ |
| Запишите числитель в виде неправильной дроби. | $\frac{\ \ \ \frac{100}{3}\ \ \ \ }{100}$ |
| Перепишите как деление дробей, заменив 100 на $\frac{100}{1}$. | $\frac{100}{3} \div \frac{100}{1}$ |
| Умножьте на обратное число. | $\frac{100}{3} \cdot \frac{1}{100}$ |
| Упростите. | $\frac{1}{3}$ |

В разделе «Десятичные дроби» мы учились переводить обыкновенные дроби в десятичные. Чтобы перевести процент в десятичную дробь, сначала переведём его в обыкновенную дробь, а затем превратим её в десятичную.

### Как сделать

#### Переведите процент в десятичную дробь.

1.  Шаг 1. Запишите процент в виде отношения со знаменателем 100.
2.  Шаг 2. Переведите дробь в десятичную, разделив числитель на знаменатель.

### Пример 6.5

Переведите каждый процент в десятичную дробь:

2.  (b)$\text{78\%}$

#### Решение

Так как мы хотим перейти к десятичной дроби, мы оставим дроби со знаменателем 100 и не будем сокращать общие множители.

|  |  |
|----|----|
| (a) |  |
|  | $6\%$ |
| Запишите в виде отношения со знаменателем 100. | $\frac{6}{100}$ |
| Превратите дробь в десятичную, разделив числитель на знаменатель. | 0.06 |

|  |  |
|----|----|
| (b) |  |
|  | $78\%$ |
| Запишите в виде отношения со знаменателем 100. | $\frac{78}{100}$ |
| Превратите дробь в десятичную, разделив числитель на знаменатель. | 0.78 |

### Перевод десятичных и обыкновенных дробей в проценты

Чтобы перевести десятичную дробь в проценты, помните, что процент означает «на сто». Если превратить десятичную дробь в дробь со знаменателем 100, эту дробь легко записать в виде процента.

### Как сделать

#### Переведите десятичную дробь в проценты.

1.  Шаг 1. Запишите десятичную дробь в виде обыкновенной.
2.  Шаг 2. Если знаменатель дроби не равен 100, перепишите её в виде равной дроби со знаменателем 100.
3.  Шаг 3. Запишите это отношение в виде процента.

### Пример 6.9

Переведите каждую десятичную дробь в проценты: (a)0.05 (b)0.83

#### Решение

|                                              |                   |
|----------------------------------------------|-------------------|
| (a)                                            |                   |
|                                              | 0.05          |
| Запишите в виде обыкновенной дроби. Знаменатель равен 100. | $\frac{5}{100}$ |
| Запишите это отношение в виде процента.               | $5\%$           |

|                                |                    |
|--------------------------------|--------------------|
| (b)                              |                    |
|                                | 0.83           |
| Знаменатель равен 100.        | $\frac{83}{100}$ |
| Запишите это отношение в виде процента. | $83\%$           |

Иногда при переводе дроби в десятичную деление продолжается на много десятичных знаков, и частное приходится округлять. До какого разряда округлять, зависит от ситуации. Если десятичная дробь связана с деньгами, мы округляем до сотых. В большинстве остальных случаев в этом курсе мы будем округлять число до тысячных, поэтому процент будет округлён до десятых.

### Попробуйте сами 6.24

Переведите дробь в проценты: $\frac{4}{7}$

Когда мы впервые рассматривали обыкновенные и десятичные дроби, мы видели, что некоторые дроби переводятся в периодическую десятичную дробь. Когда мы переводили дробь $\frac{4}{3}$ в десятичную, мы записали ответ в виде $1.\overline{3}.$ Мы будем использовать эту же запись, а также запись в виде дроби, когда будем переводить дроби в проценты в следующем примере.

### Пример 6.13

В статье в медицинском журнале утверждалось, что примерно $\frac{1}{3}$ взрослых американцев страдают ожирением. Переведите дробь $\frac{1}{3}$ в проценты.

#### Решение

|                               |                     |
|-------------------------------|---------------------|
|                               | $\frac{1}{3}$     |
| Превратите в десятичную дробь.          |                     |
| Запишите в виде периодической десятичной дроби. | $0.333\ldots$     |
| Запишите в виде процента.           | $33\frac{1}{3}\%$ |

Этот процент можно записать и так: $33.\overset{\_}{3}\%$.
