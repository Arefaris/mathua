### Моделирование сложения дробей

Сколько квотеров (американских монет в 25 центов) изображено? Один квотер плюс 2 квотера равно 3 квотерам.

Помните: квотеры — это на самом деле доли доллара. Слово quarter по-английски означает «четверть», то есть одну четвёртую. Поэтому рисунок с монетами показывает, что

$$
\begin{matrix}
\frac{1}{4} & & \frac{2}{4} & & \frac{3}{4} \\
\text{один квотер} & + & \text{два квотера} & = & \text{три квотера}
\end{matrix}
$$

Смоделируем тот же пример с помощью кругов для дробей: $\frac{1}{4} + \frac{2}{4}.$

|                                       |     |     |
|---------------------------------------|-----|-----|
| Начнём с одной части $\frac{1}{4}$. |     |     |
| Добавим ещё две части $\frac{1}{4}$.   |     |     |
| Получилось $\frac{3}{4}$.        |     |     |

Итак, мы снова видим, что

$$
\frac{1}{4} + \frac{2}{4} = \frac{3}{4}
$$

### Сложение дробей с общим знаменателем

Пример 4.52 показывает, что для сложения частей одного размера — то есть дробей с одинаковым знаменателем — достаточно сложить количество частей.

### Сложение дробей

Если $a,b,\text{и}\ c$ — числа, причём $c \neq 0,$ то

$$
\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}
$$

Чтобы сложить дроби с общим знаменателем, сложите числители и запишите сумму над общим знаменателем.

### Пример 4.53

Найдите сумму: $\frac{3}{5} + \frac{1}{5}.$

#### Решение

|  |  |
|----|----|
|  | $\frac{3}{5} + \frac{1}{5}$ |
| Сложите числители и запишите сумму над общим знаменателем. | $\frac{3 + 1}{5}$ |
| Упростите. | $\frac{4}{5}$ |

### Пример 4.55

Найдите сумму: $- \frac{9}{d} + \frac{3}{d}.$

#### Решение

Начнём с того, что перепишем первую дробь, поставив знак «минус» в числитель.

$- \frac{a}{b} = \frac{- a}{b}$

|  |  |
|----|----|
|  | $- \frac{9}{d} + \frac{3}{d}$ |
| Перепишите первую дробь, поставив знак «минус» в числитель. | $\frac{-9}{d} + \frac{3}{d}$ |
| Сложите числители и запишите сумму над общим знаменателем. | $\frac{-9 + 3}{d}$ |
| Упростите числитель. | $\frac{-6}{d}$ |
| Перепишите, вынеся знак «минус» перед дробью. | $- \frac{6}{d}$ |

### Моделирование вычитания дробей

Вычитание дробей с общими знаменателями очень похоже на их сложение. Представьте пиццу, разрезанную на 12 кусков. Допустим, пять кусков съели за ужином. Это значит, что после ужина в коробке осталось семь кусков (или $\frac{7}{12}$ пиццы). Если Леонардо съест 2 из оставшихся кусков (или $\frac{2}{12}$ пиццы), сколько останется? Останется 5 кусков (или $\frac{5}{12}$ пиццы).

$$
\frac{7}{12} - \frac{2}{12} = \frac{5}{12}
$$

Смоделируем тот же пример с помощью кругов для дробей: $\frac{7}{12} - \frac{2}{12}.$

Начнём с семи частей $\frac{1}{12}$. Уберём две части $\frac{1}{12}$. Сколько двенадцатых осталось?

Снова получилось пять двенадцатых, $\frac{5}{12}.$

### Вычитание дробей с общим знаменателем

Мы вычитаем дроби с общим знаменателем почти так же, как складываем дроби с общим знаменателем.

### Вычитание дробей

Если $a,b,\text{и}\ c$ — числа, причём $c \neq 0,$ то

$$
\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}
$$

Чтобы вычесть дроби с общим знаменателем, мы вычитаем числители и записываем разность над общим знаменателем.

### Пример 4.59

Найдите разность: $\frac{23}{24} - \frac{14}{24}.$

#### Решение

|  |  |
|----|----|
|  | $\frac{23}{24} - \frac{14}{24}$ |
| Вычтите числители и запишите разность над общим знаменателем. | $\frac{23 - 14}{24}$ |
| Упростите числитель. | $\frac{9}{24}$ |
| Упростите дробь, сократив общие множители. | $\frac{3}{8}$ |
