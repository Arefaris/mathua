# Виды треугольников

**Треугольник** — это замкнутая фигура с тремя прямыми сторонами и тремя углами. Треугольники можно разделить на виды двумя независимыми способами: по сторонам и по углам.

## Классификация по сторонам

| Название | Стороны |
| --- | --- |
| Разносторонний | все три стороны разной длины |
| Равнобедренный | ровно две равные стороны |
| Равносторонний | все три стороны равны |

Штрихи на рисунке показывают, какие стороны равны.

## Классификация по углам

| Название | Углы |
| --- | --- |
| Остроугольный треугольник | все три угла меньше $90^\circ$ |
| Прямоугольный треугольник | ровно один угол равен $90^\circ$ |
| Тупоугольный треугольник | ровно один угол больше $90^\circ$ |

В треугольнике не может быть двух прямых или двух тупых углов, потому что сумма трёх углов всегда равна $180^\circ$. Каждый треугольник получает ровно одно название из каждой таблицы, поэтому «равнобедренный прямоугольный треугольник» описывает и свойство сторон, и свойство углов.

В прямоугольном треугольнике сторона, лежащая напротив прямого угла (самая длинная сторона), называется **гипотенузой**, а две другие стороны — **катетами**.

## Примеры

**Пример**

У треугольника стороны длиной 5, 5 и 8, а угол между двумя равными сторонами равен $40^\circ$. Определите вид треугольника.

*Решение*

По сторонам: две стороны равны, значит, он равнобедренный.

По углам: $40^\circ < 90^\circ$, а так как сумма углов равна $180^\circ$, ни один из двух других не может достичь $90^\circ$. Все три угла острые, значит, треугольник остроугольный.

Классификация: остроугольный равнобедренный треугольник.

**Пример**

Может ли треугольник со сторонами 2, 2, 2 быть прямоугольным?

*Решение*

Нет. Стороны 2, 2, 2 делают его равносторонним, поэтому все три угла равны. Если бы один угол был равен $90^\circ$, то все три были бы равны $90^\circ$, и сумма составила бы $270^\circ$ — это невозможно. Равносторонний треугольник всегда остроугольный.

## Итоги

- По сторонам: разносторонний (нет равных), равнобедренный (две равные), равносторонний (все равны).
- По углам: остроугольный (все меньше $90^\circ$), прямоугольный (один равен $90^\circ$), тупоугольный (один больше $90^\circ$).
- Каждый треугольник получает по одному названию из каждой классификации.
