## 4.4 Додавання й віднімання дробів зі спільними знаменниками

### Цілі навчання

Після вивчення цього розділу ви зможете:

- Моделювати додавання дробів
- Додавати дроби зі спільним знаменником
- Моделювати віднімання дробів
- Віднімати дроби зі спільним знаменником

### Модель додавання дробів

Скільки квотерів зображено? Один квотер плюс 2 квотери дорівнюють 3 квотерам.

Пам’ятайте, що квотери — це насправді частини долара. Квотер — це просто інша назва чверті. Отже, малюнок із монетами показує, що

$$
\begin{matrix}
\frac{1}{4} & & \frac{2}{4} & & \frac{3}{4} \\
\text{один квотер} & + & \text{два квотери} & = & \text{три квотери}
\end{matrix}
$$

Скористаймося кругами для дробів, щоб змоделювати той самий приклад, $\frac{1}{4} + \frac{2}{4}.$

|                                       |     |     |
|---------------------------------------|-----|-----|
| Почніть з однієї частини $\frac{1}{4}$. |     |     |
| Додайте ще дві частини $\frac{1}{4}$. |     |     |
| Результат — $\frac{3}{4}$.        |     |     |

Отже, ми знову бачимо, що

$$
\frac{1}{4} + \frac{2}{4} = \frac{3}{4}
$$

### Додавання дробів зі спільним знаменником

Приклад 4.52 показує, що для додавання частин однакового розміру, тобто коли дроби мають однаковий знаменник, ми просто додаємо кількість частин.

### Додавання дробів

Якщо $a,b,\text{і}\ c$ — числа, причому $c \neq 0,$ то

$$
\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}
$$

Щоб додати дроби зі спільним знаменником, додайте чисельники й запишіть суму над спільним знаменником.

### Приклад 4.53

Знайдіть суму: $\frac{3}{5} + \frac{1}{5}.$

#### Розв’язання

|  |  |
|----|----|
|  | $\frac{3}{5} + \frac{1}{5}$ |
| Додайте чисельники й запишіть суму над спільним знаменником. | $\frac{3 + 1}{5}$ |
| Спростіть. | $\frac{4}{5}$ |

### Приклад 4.55

#### Розв’язання

Почнемо з того, що перепишемо перший дріб зі знаком мінус у чисельнику.

$- \frac{a}{b} = \frac{- a}{b}$

|  |  |
|----|----|
|  | $- \frac{9}{d} + \frac{3}{d}$ |
| Перепишіть перший дріб, перенісши мінус у чисельник. | $\frac{-9}{d} + \frac{3}{d}$ |

| Спростіть чисельник. | $\frac{-6}{d}$ |

### Модель віднімання дробів

Віднімання двох дробів зі спільними знаменниками багато в чому схоже на додавання дробів. Уявіть піцу, розрізану на 12 шматків. Припустімо, п’ять шматків з’їли на вечерю. Це означає, що після вечері в коробці лишилося сім шматків (або $\frac{7}{12}$ піци). Якщо Леонардо з’їсть 2 із цих шматків (або $\frac{2}{12}$ піци), скільки лишиться? Лишиться 5 шматків (або $\frac{5}{12}$ піци).

$$
\frac{7}{12} - \frac{2}{12} = \frac{5}{12}
$$

Скористаймося кругами для дробів, щоб змоделювати той самий приклад, $\frac{7}{12} - \frac{2}{12}.$

Почніть із семи частин $\frac{1}{12}$. Приберіть дві частини $\frac{1}{12}$. Скільки дванадцятих лишилося?

Знову маємо п’ять дванадцятих, $\frac{5}{12}.$

### Віднімання дробів зі спільним знаменником

Дроби зі спільним знаменником ми віднімаємо майже так само, як і додаємо дроби зі спільним знаменником.

### Віднімання дробів

Якщо $a,b,\text{і}\ c$ — числа, причому $c \neq 0,$ то

$$
\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}
$$

Щоб відняти дроби зі спільним знаменником, віднімаємо чисельники й записуємо різницю над спільним знаменником.

### Приклад 4.59

Знайдіть різницю: $\frac{23}{24} - \frac{14}{24}.$

#### Розв’язання

|  |  |
|----|----|
|  | $\frac{23}{24} - \frac{14}{24}$ |
| Відніміть чисельники й запишіть різницю над спільним знаменником. | $\frac{23 - 14}{24}$ |
| Спростіть чисельник. | $\frac{9}{24}$ |
| Скоротіть дріб, прибравши спільні множники. | $\frac{3}{8}$ |
