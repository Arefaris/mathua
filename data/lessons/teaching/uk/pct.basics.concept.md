## 6.1 Розуміння відсотка

### Цілі навчання

Після вивчення цього розділу ви зможете:

- Користуватися означенням відсотка
- Перетворювати відсотки на звичайні й десяткові дроби
- Перетворювати десяткові й звичайні дроби на відсотки

### Означення відсотка

Скільки центів в одному доларі? У доларі 100 центів. Скільки років у столітті? У столітті 100 років. Чи підказує це вам, що означає слово «відсоток»? В англійській це два слова, «per cent», і воно означає «на сто». Відсоток — це відношення зі знаменником 100. Щоб записати відсоток, використовуємо знак $\text{\%,}$

### Відсоток

Відсоток — це відношення зі знаменником 100.

За даними Американської асоціації громадських коледжів $(2015)\text{,}$ близько $\text{57\%}$ студентів громадських коледжів — жінки. Це означає, що з кожних 100 студентів громадських коледжів 57 — жінки, як показано на малюнку 6.2. Зі 100 клітинок сітки зафарбовано 57, що ми записуємо як відношення $\frac{57}{100}.$

![Серед кожних 100 студентів громадського коледжу 57 — жінки.](/diagrams/prealgebra/6.2.png)

*Малюнок 6.2 Серед кожних 100 студентів громадського коледжу 57 — жінки.*

Так само $\text{25\%}$ означає відношення ${\frac{25}{100},}\text{3\%}$ — відношення $\frac{3}{100}$, а $\text{100\%}$ — відношення $\frac{100}{100}.$ Словами, «сто відсотків» означає, що ціле $\text{100\%}$ — це $\frac{100}{100},$ а оскільки $\frac{100}{100} = 1,$ ми бачимо, що $\text{100\%}$ — це 1 ціле.

За даними Інституту державної політики Каліфорнії $(2010)\text{,}\ \text{44\%}$ батьків учнів державних шкіл хотіли б, щоб їхня наймолодша дитина здобула ступінь магістра або вищий. Запишіть цей відсоток як відношення.

#### Розв’язання

|  |  |
|----|----|
| Величина, яку ми хочемо перетворити, — 44%. | $44\%$ |
| Запишіть відсоток як відношення. Пам’ятайте, що *відсоток* означає «на 100». | $\frac{44}{100}$ |

### Перетворення відсотків на звичайні й десяткові дроби

Оскільки відсотки — це відношення, їх легко виразити дробами. Пам’ятайте, що відсоток означає «на 100», тож знаменник дробу дорівнює 100.

### Приклад 6.4

Перетворіть кожен відсоток на звичайний дріб:

1.  а)$\text{24.5\%}$
2.  б)$33\frac{1}{3}\%$

#### Розв’язання

|  |  |
|----|----|
| а) |  |
|  | $24.5\%$ |
| Запишіть як відношення зі знаменником 100. | $\frac{24.5}{100}$ |
| Щоб прибрати десятковий дріб, помножте чисельник і знаменник на 10. | $\frac{24.5{(10)}}{100{(10)}}$ |
| Помножте. | $\frac{245}{1000}$ |
| Перепишіть так, щоб було видно спільні множники. | $\frac{5 \cdot 49}{5 \cdot 200}$ |
| Скоротіть. | $\frac{49}{200}$ |

|  |  |
|----|----|
| б) |  |
|  | $33\frac{1}{3}\%$ |
| Запишіть як відношення зі знаменником 100. | $\frac{33\frac{1}{3}}{100}$ |
| Запишіть чисельник як неправильний дріб. | $\frac{\ \ \ \frac{100}{3}\ \ \ \ }{100}$ |
| Перепишіть як ділення дробів, замінивши 100 на $\frac{100}{1}$. | $\frac{100}{3} \div \frac{100}{1}$ |
| Помножте на обернене число. | $\frac{100}{3} \cdot \frac{1}{100}$ |
| Скоротіть. | $\frac{1}{3}$ |

Таблиця 6.1

Чи бачите ви закономірність?

Щоб перетворити відсоток на десятковий дріб, пересуваємо десяткову крапку на два розряди ліворуч і прибираємо знак $\%$. (Іноді десяткової крапки у відсотку немає, але як ціле число 6 можна уявити як 6.0, так і $\text{6\%}$ можна уявити як $\text{6.0\%}.$) Зверніть увагу: коли десяткову крапку пересуваємо ліворуч, перед числом може знадобитися дописати нулі.

### Перетворення десяткових і звичайних дробів на відсотки

Щоб перетворити десятковий дріб на відсоток, пам’ятайте, що відсоток означає «на сто». Якщо перетворити десятковий дріб на звичайний зі знаменником 100, цей дріб легко записати у вигляді відсотка.

### Як зробити

#### Перетворення десяткового дробу на відсотки

1.  Крок 1. Запишіть десятковий дріб як звичайний дріб.
2.  Крок 2. Якщо знаменник дробу не дорівнює 100, перепишіть його як рівний дріб зі знаменником 100.
3.  Крок 3. Запишіть це відношення у вигляді відсотка.

*Малюнок 6.5*

У розділі «Десяткові дроби» ми навчилися перетворювати звичайні дроби на десяткові. Тепер ми ще й знаємо, як перетворити десяткові дроби на відсотки. Отже, щоб перетворити звичайний дріб на відсоток, спершу перетворимо його на десятковий, а потім цей десятковий дріб — на відсоток.

### Як зробити

#### Перетворення звичайного дробу на відсотки

1.  Крок 1. Перетворіть дріб на десятковий.
2.  Крок 2. Перетворіть десятковий дріб на відсоток.

### Приклад 6.11

Перетворіть кожен звичайний дріб або мішане число на відсоток: (а)$\frac{3}{4}$ (б)$\frac{11}{8}$ (в)$2\frac{1}{5}$

#### Розв’язання

Щоб перетворити дріб на десятковий, поділіть чисельник на знаменник.

|                                                      |                 |
|------------------------------------------------------|-----------------|
| а)                                                    |                 |
| Перетворіть на десятковий дріб.                                 | $\frac{3}{4}$ |
| Запишіть у вигляді відсотка, пересунувши десяткову крапку на два розряди. |                 |
|                                                      | $75\%$        |

|                                                      |                  |
|------------------------------------------------------|------------------|
| б)                                                    |                  |
| Перетворіть на десятковий дріб.                                 | $\frac{11}{8}$ |
| Запишіть у вигляді відсотка, пересунувши десяткову крапку на два розряди. |                  |
|                                                      | $137.5\%$      |

|                                |                  |
|--------------------------------|------------------|
| в)                              |                  |
| Запишіть як неправильний дріб. | $2\frac{1}{5}$ |
| Перетворіть на десятковий дріб.           | $\frac{11}{5}$ |
| Запишіть у вигляді відсотка.            |                  |
|                                | $220\%$        |

Зверніть увагу: нулі довелося дописати в кінці числа, коли ми пересували десяткову крапку на два розряди праворуч.

### Спробуйте самі 6.21

Перетворіть кожен звичайний дріб або мішане число на відсоток: (а) $\frac{5}{8}$ (б) $\frac{11}{4}$ (в) $3\frac{2}{5}$

### Спробуйте самі 6.22

Перетворіть кожен звичайний дріб або мішане число на відсоток: (а)$\frac{7}{8}$ (б)$\frac{9}{4}$ (в)$1\frac{3}{5}$

Іноді, коли ми перетворюємо дріб на десятковий, ділення триває до багатьох десяткових знаків, і частку доводиться округлювати. До скількох десяткових знаків округлювати, залежить від ситуації. Якщо десятковий дріб стосується грошей, округлюємо до сотих. У більшості інших випадків у цьому курсі ми округлюватимемо число до тисячних, тож відсоток буде округлено до десятих.

### Приклад 6.12

Перетворіть $\frac{5}{7}$ на відсоток.

#### Розв’язання

Щоб перетворити дріб на десятковий, ділимо чисельник на знаменник.

|                                                         |                 |
|---------------------------------------------------------|-----------------|
|                                                         | $\frac{5}{7}$ |
| Перетворіть на десятковий дріб, округливши до тисячних. | 0.714       |
| Запишіть у вигляді відсотка.                                     | $71.4\%$      |

### Спробуйте самі 6.23

Перетворіть дріб на відсоток: $\frac{3}{7}$

### Спробуйте самі 6.24

Перетворіть дріб на відсоток: $\frac{4}{7}$

Коли ми вперше розглядали дроби й десяткові дроби, то бачили, що звичайні дроби перетворюються на періодичні десяткові. Коли ми перетворили дріб $\frac{4}{3}$ на десятковий, то записали відповідь як $1.\overline{3}.$ Цей самий запис, а також запис дробом ми використаємо, коли в наступному прикладі перетворюватимемо дроби на відсотки.

### Приклад 6.13

У статті медичного журналу стверджувалося, що приблизно $\frac{1}{3}$ дорослих американців мають ожиріння. Перетворіть дріб $\frac{1}{3}$ на відсоток.

#### Розв’язання

|                               |                     |
|-------------------------------|---------------------|
|                               | $\frac{1}{3}$     |
| Перетворіть на десятковий дріб.          |                     |
| Запишіть як періодичний десятковий дріб. | $0.333\ldots$     |
| Запишіть у вигляді відсотка.           | $33\frac{1}{3}\%$ |

Цей відсоток можна записати також як $33.\overset{\_}{3}\%$.
