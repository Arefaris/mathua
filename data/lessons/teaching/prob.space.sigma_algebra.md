# Sigma-Algebras and Events

**Sigma-algebra:** A collection $\mathcal{F}$ of subsets of $\Omega$ is a sigma-algebra when it contains $\Omega$, is closed under complementation, and is closed under countable unions. Its members are called events, and a probability is defined on them.

## Closed under the set operations

Once $\Omega$ and complements are present, the empty set is an event. Closure under countable unions plus complements gives closure under countable intersections by De Morgan's law, and closure under differences follows. A sigma-algebra is therefore closed under every ordinary set operation performed countably many times. The two generating operations are complements and countable unions; everything else is derived.

## Worked: the smallest and largest

The collection containing only $\Omega$ and the empty set is always a sigma-algebra, and it is the smallest one. The power set of $\Omega$ is always a sigma-algebra too, and it is the largest. For a finite sample space the power set is the usual choice, because every subset is an outcome pattern a model might want to measure.

## Why measurability matters

On an uncountable sample space, such as the real line, the power set is too large for a well-behaved probability to be defined on every subset. The Borel sigma-algebra, generated by the intervals, is the standard compromise: it contains every set a computation names, and it carries the uniform measure. A set outside the sigma-algebra is simply not an event, which is why measurability is a precondition for assigning a probability.
