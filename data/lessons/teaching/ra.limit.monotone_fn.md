# Monotone Functions

**Monotone function:** an increasing or decreasing function on an interval; its discontinuities, if any, are jumps, and there are at most countably many of them.

## One-sided limits exist

A monotone function on an interval has both one-sided limits at every interior point, and they exist as finite numbers or as extended values. An increasing function has a left limit equal to the supremum of the values on the left and a right limit equal to the infimum of the values on the right, and the left limit never exceeds the value, which never exceeds the right limit. This is why a monotone function can fail to be continuous only by jumping over a gap, never by oscillating or by escaping without order.

## Countably many jumps

Each jump of a monotone function straddles a gap in the values, and the gap contains a rational number. Assigning to each jump a distinct rational number pairs the jumps with a subset of the rationals, so there can be only countably many of them. The jumps may still be dense, as they are for a monotone function that is constant on each rational and jumps at every rational, so countably many is a real restriction but not a strong one. Uncountably many discontinuities are impossible for a monotone function.

## Integrability and the left limit

Because its discontinuities are jumps, a monotone function on a closed bounded interval is Riemann integrable: the set of discontinuities has measure zero. Its left limit at a point, when the function increases up to that point, is the supremum of the values on the interval to the left, which need not equal the value at the point. And a monotone function maps a closed bounded interval onto an interval whose endpoints are the one-sided values, which is the monotone version of the intermediate value property.
