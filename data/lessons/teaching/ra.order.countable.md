# Countable Sets

**Countable:** a set is countable when it is finite or can be listed as a sequence, so that every element appears at some position and no element is left out.

## Listing a set

A set is countable when it is finite or can be put into a one-to-one correspondence with the natural numbers. The list is the whole content of countability: each element is assigned a position, and the assignment can be read backwards to recover the element. The integers are countable by listing zero, then one, then minus one, then two, then minus two, weaving the two directions together. A single explicit listing is enough to prove a set countable.

## Closure properties

Countable sets behave well under the usual constructions. Every subset of a countable set is countable, and the product of two countable sets is countable by walking the grid of pairs along its diagonals. A countable union of countable sets is countable by the same diagonal sweep, and this extends to any finite number of factors. These closure properties are the practical tools: they let a complicated set be shown countable by expressing it as a countable union of simple pieces.

## The algebraic numbers

An algebraic number is a root of a polynomial with integer coefficients. To show the algebraic numbers are countable, group the polynomials by degree and by the size of their coefficients. For each fixed degree and coefficient bound there are finitely many polynomials, and each has finitely many roots, so each group is finite. The groups are indexed by pairs of natural numbers, so the whole collection is a countable union of finite sets and hence countable. The transcendental numbers are what remains of the reals.
