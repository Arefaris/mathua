# Solving Logarithmic Models

**Logarithmic model:** an equation in which the unknown sits inside a logarithm; it is solved by rewriting the logarithm as the exponent that produces the given value.

## Rewriting the equation

An equation that says the logarithm of an unknown to a given base equals a given number can be rewritten in exponential form: the base raised to that number equals the unknown. This is the definition of the logarithm read backwards, and it turns an equation about a logarithm into a single power. The rewrite is valid for every positive base other than one, and the unknown comes out already isolated.

## Checking the domain

Only positive inputs have logarithms, so any solution of a logarithmic equation must be positive, and a candidate that is zero or negative is rejected even if the algebra produced it. When logarithms appear on both sides, combining them can introduce restrictions that the original equation did not show, so the domain is checked against the original form rather than the rewritten one. This is the same discipline that catches extraneous roots in radical equations.

## Applications

Logarithmic models describe the time for a decaying quantity to reach a target, the acidity measured on a scale of powers of ten, and the intensity of sound measured in ratios. Solving them always reduces to rewriting the logarithm as an exponent and dividing by the rate or the coefficient. The value found is a real quantity, so the units come from the model rather than from the logarithm, which is dimensionless.
