# Estimating sums and differences

An estimate is a quick answer that is close enough to judge size. Rounding first keeps the arithmetic in your head.

## Round first

Choose the place that matters. For three-digit numbers, rounding to the nearest hundred is usually enough. Find the hundreds digit, look at the tens digit, and round up when the tens digit is 5 or more.

For example, 487 rounds to 500 because the tens digit is 8. 213 rounds to 200 because the tens digit is 1.

## Add or subtract the estimates

Use the same operation as the original problem. For \(487 + 213\), add the rounded values:

\[
500 + 200 = 700.
\]

For a difference, subtract the rounded values in the same order. If the problem is \(695 - 213\), the estimate is \(700 - 200 = 500\).

## Judge the result

The estimate is not the exact answer. It tells you whether an exact answer is plausible. If a calculation of \(487 + 213\) produces 70, the estimate of 700 shows that a place value was lost. If it produces 7000, the estimate shows that an extra place was added.

Rounding both numbers in the same direction can push an estimate a little high or low. That is expected. The purpose is a fast check, not the exact sum.
