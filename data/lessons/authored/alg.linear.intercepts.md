# Intercepts of a line

An intercept is a point where the line meets an axis. It is found by setting the other variable to zero, which turns a two-variable equation into one equation in one unknown.

## Set the other variable to zero

For the \(x\)-intercept, set \(y=0\). Every term containing \(y\) disappears, and what remains is an equation in \(x\). For the \(y\)-intercept, set \(x=0\) and solve for \(y\).

The two procedures are independent. Doing both is not extra work; it is the definition of the two intercepts.

## Solve each one-variable equation

A line in standard form \(Ax+By=C\) becomes \(Ax=C\) for the \(x\)-intercept and \(By=C\) for the \(y\)-intercept. Divide by the remaining coefficient, keeping its sign.

If the coefficient is negative, the intercept is negative. A negative intercept is ordinary: it means the crossing happens on the negative part of the axis, not that the answer is impossible.

## Read the pair in order

The question fixes the order, usually \((x\text{-intercept}, y\text{-intercept})\). Enter the two numbers in that order, separated by a comma. A swapped pair describes the same two points but answers a different question.

Check by substituting each intercept into the original equation. The point \((a,0)\) must satisfy it, and so must \((0,b)\). If one fails, the division or the sign went wrong.
