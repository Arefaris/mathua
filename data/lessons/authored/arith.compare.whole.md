# Comparing and ordering whole numbers

Place value decides which of two whole numbers is larger. Compare the digits from the left, one place at a time.

## Compare by place value

Line up the numbers by place. The number with more digits is larger when the extra digit is not zero. For numbers with the same number of digits, compare the thousands digit first, then the hundreds digit, then the tens digit, then the ones digit. Stop at the first place where the digits differ.

For example, 4582 and 4528 both have four digits. The thousands digits are equal, and the hundreds digits are equal. The tens digits are 8 and 2, so 4582 is larger.

## Use the symbols

The symbol \(>\) means "is greater than", and \(<\) means "is less than". The wider end faces the larger number. So \(4582 > 4528\), and \(4528 < 4582\).

When two numbers name the same value, use \(=\). Place value makes that comparison exact. 4070 and 4070 are equal even if one is written with a leading zero in a table.

## Order a list

To order three or more numbers, compare them in pairs and place the smallest first. A reliable method is to scan for the smallest number, write it down, then scan the rest for the next smallest. Repeat until every number is used.

For 4582, 4528 and 4852, the smallest is 4528, then 4582, then 4852. The ordered list is 4528, 4582, 4852. Check the result by reading the list back. Each number must be no larger than the one after it.
