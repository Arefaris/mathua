# Percent change

Percent change compares the amount of change with the original value. It answers a different question from "what is the new value?", because the same change is a different percentage depending on where it started.

## Find the amount of change

Subtract the smaller value from the larger. For an increase, the change is new minus old. For a decrease, the change is old minus new. Keep the change positive; the direction is a separate fact.

For a change from 80 to 100, the amount of change is \(100 - 80 = 20\).

## Divide by the original value

Percent change always uses the original value as the denominator:

\[
\text{percent change} = \frac{\text{change}}{\text{original}} \times 100.
\]

For the change from 80 to 100, \(\frac{20}{80} \times 100 = 25\%\). Dividing by the new value instead would answer a different question and give \(20\%\), which is not the percent change from 80.

## Name the direction

If the new value is larger, the change is a percent increase. If the new value is smaller, it is a percent decrease. The percent itself stays positive.

A change from 100 to 80 is a \(20\%\) decrease, because \(\frac{20}{100} \times 100 = 20\). Notice that 80 to 100 is a \(25\%\) increase while 100 to 80 is a \(20\%\) decrease. The two changes have the same size, but they do not have the same percentage, because the original value is different.
