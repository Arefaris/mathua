# Вычитание дроби из натурального числа

## Запись натурального числа в виде дроби

Натуральное число — это дробь в маскировке: если записать его со знаменателем вычитаемой дроби, задача превращается в вычитание двух дробей. Для дроби со знаменателем четыре натуральное число один превращается в четыре четверти.

Любое натуральное число можно записать над любым знаменателем, и нужно выбирать тот вариант, который совпадает с дробью из условия.

## С общим знаменателем

Когда оба числа записаны дробями, знаменатели совпадают, и числители вычитаются в одну строку. Числитель натурального числа равен знаменателю, умноженному на это число, — отсюда и берётся больший числитель.

Результат обычно получается сократимым, поэтому последний шаг — сокращение.

## Проверка ответа

Ответ должен быть положительным и чуть меньше натурального числа, поскольку из него вычли правильную дробь. Ответ, больший натурального числа, означает, что целое было переведено с неверным числителем.

Приведение к общему знаменателю и оценка величины — две проверки, которые ловят почти любую ошибку в этом действии.
