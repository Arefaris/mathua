# Кубические корни

Кубический корень обращает возведение в куб. Кубический корень числа — это значение, куб которого равен этому числу.

## Действие, обратное возведению в куб

Возвести число в куб значит умножить его само на себя три раза: \(4^3 = 64\). Значит, кубический корень из 64 равен 4. Записывается это так:

\[
\sqrt[3]{64} = 4.
\]

Маленькая цифра 3 у знака корня — показатель корня. Она означает «кубический корень», а не «квадратный корень». Квадратный корень из 64 — это значение, квадрат которого равен 64, то есть 8.

## Точные кубы

Точные кубы — это результаты возведения в куб целых неотрицательных чисел: 1, 8, 27, 64, 125, 216 и так далее. Если их знать, кубические корни находятся быстро. Например, \(5^3 = 125\), поэтому \(\sqrt[3]{125} = 5\).

Кубический корень из точного куба получается точно. Кубический корень из числа, лежащего между точными кубами, не является целым числом. Он лежит между двумя соседними целыми числами.

## Отрицательные подкоренные числа

У отрицательного числа может быть действительный кубический корень, потому что куб отрицательного числа отрицателен:

\[
(-3)^3 = -27, \quad \sqrt[3]{-27} = -3.
\]

Это отличается от квадратного корня, у которого для отрицательного подкоренного числа нет действительного значения. Отрицательный результат возможен благодаря нечётному показателю корня.

Проверьте кубический корень, возведя ответ в куб. Если куб равен подкоренному числу, то корень найден верно.
