# Градусы Цельсия и Фаренгейта

Шкалы Цельсия и Фаренгейта — две температурные шкалы с разными нулевыми точками и разной ценой деления. Температуру можно перевести из одной шкалы в другую по формуле.

## Используйте формулу перевода

Чтобы перевести градусы Цельсия в градусы Фаренгейта:

\[
F = \frac{9C}{5} + 32.
\]

Чтобы перевести градусы Фаренгейта в градусы Цельсия:

\[
C = \frac{5(F - 32)}{9}.
\]

Эти две формулы обратны друг другу, поэтому если перевести температуру, а затем перевести обратно, получится исходное значение.

## Подставьте перед вычислением

Для \(20^\circ\text{C}\)

\[
F = \frac{9(20)}{5} + 32 = 36 + 32 = 68.
\]

Значит, \(20^\circ\text{C} = 68^\circ\text{F}\). Для \(68^\circ\text{F}\)

\[
C = \frac{5(68 - 32)}{9} = \frac{5(36)}{9} = 20.
\]

Сохраняйте скобки вокруг вычитания в формуле перевода из градусов Фаренгейта в градусы Цельсия.

## Проверьте контрольные точки

Вода замерзает при \(0^\circ\text{C} = 32^\circ\text{F}\) и кипит при \(100^\circ\text{C} = 212^\circ\text{F}\). Результат вне диапазона исходных значений всё равно может быть верным, потому что у шкал разные нулевые точки. Используйте известную контрольную точку, чтобы проверить, в ту ли сторону сдвинулся результат перевода.
