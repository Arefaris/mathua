# Percent error

Percent error measures how far a measurement is from an accepted value, as a percentage of that accepted value. It is a size, so a measurement that is too high and one that is too low can have the same percent error.

## Find the absolute difference

Subtract the measured value and the accepted value, then take the absolute value. The absolute value removes the sign, because the question asks how far apart the values are, not which one is larger.

If the measurement is 55 and the accepted value is 50, the difference is \(|55 - 50| = 5\). A measurement of 45 has the same difference, because \(|45 - 50| = 5\).

## Divide by the accepted value

The accepted value is the reference, so it is the denominator:

\[
\text{percent error} = \frac{|\text{measured} - \text{accepted}|}{\text{accepted}} \times 100.
\]

For the measurement 55 and the accepted value 50, \(\frac{5}{50} \times 100 = 10\%\). The accepted value, not the measured value, sets the scale.

## Interpret the result

A percent error of \(10\%\) means the measurement misses the accepted value by one tenth of that value. Percent error is not percent change. Percent change compares two values without choosing a reference, while percent error always measures against the accepted value and uses an absolute difference.
