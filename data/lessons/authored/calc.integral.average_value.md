# The average value of a function

## Dividing by the width

The average value of a continuous function on an interval is its integral divided by the interval's width:

\[
f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx.
\]

For a linear function on an interval starting at zero, that is the value at the interval's midpoint, which is a useful check on the formula.

## What average means here

The integral is the area under the curve, and dividing by the width turns area into a height: the average value is the height of the rectangle that has the same base and the same area as the region under the curve. Nothing about the function's shape survives, only its average.

That reading explains why the average of a linear function is its midpoint value and why the average of a constant is the constant itself.

## Using it

The theorem that makes the average value useful is that a continuous function actually takes it somewhere on the interval. So an average speed is a speed that was attained, and an average temperature is a temperature that occurred.

That is the mean value theorem for integrals, and it is why an average value is a fact about the function rather than only about its integral.
