# Cube roots

A cube root reverses cubing. The cube root of a number is the value whose cube gives that number.

## The inverse of cubing

Cubing means multiplying a number by itself three times: \(4^3 = 64\). The cube root of 64 is therefore 4, written

\[
\sqrt[3]{64} = 4.
\]

The small 3 in the radical is the index. It says "cube root", not "square root". A square root would ask for a value whose square is 64, which is 8.

## Perfect cubes

The perfect cubes are the results of cubing whole numbers: 1, 8, 27, 64, 125, 216, and so on. Recognizing them makes cube roots fast. For example, \(5^3 = 125\), so \(\sqrt[3]{125} = 5\).

A cube root of a perfect cube is exact. A cube root of a number between perfect cubes is not a whole number. It lies between the two neighboring whole numbers.

## Negative radicands

A negative number can have a real cube root, because a negative number cubed is negative:

\[
(-3)^3 = -27, \quad \sqrt[3]{-27} = -3.
\]

This is different from a square root, which has no real value for a negative radicand. The odd index is what allows the negative result.

Check a cube root by cubing the answer. If the cube returns the radicand, the root is correct.
