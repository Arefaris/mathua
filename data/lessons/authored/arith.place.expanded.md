# Expanded form

Every digit in a whole number names a value, not just a symbol. Expanded form writes those values as a sum.

## Break the number into place values

Read a four-digit number from left to right as thousands, hundreds, tens and ones. In 4305, the 4 is worth 4000, the 3 is worth 300, the 0 is worth 0, and the 5 is worth 5.

A zero digit contributes nothing to the sum. Skip it rather than writing "+ 0". The expanded form contains only the nonzero place values.

## Write the sum

Write each nonzero place value in descending order and join them with plus signs:

\[
4305 = 4000 + 300 + 5.
\]

The order matters for reading the number back. Largest first keeps the thousands value in front, just as the standard form does.

## Check the total

Add the parts to recover the original number. For 4305, \(4000 + 300 + 5 = 4305\). If the total differs, a place value was assigned to the wrong column.

The same method works for any whole number. For 7026, the nonzero parts are 7000, 20 and 6, so \(7026 = 7000 + 20 + 6\). For 5007, they are 5000 and 7.
