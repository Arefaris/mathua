# Rational exponents

A rational exponent combines a power and a root. The denominator of the exponent is the root, and the numerator is the power, so \(a^{m/n}\) means the \(n\)-th root of \(a\), raised to the \(m\)-th power.

## A root and a power

The definition is

\[
a^{m/n}=\left(\sqrt[n]{a}\right)^m=\sqrt[n]{a^m}.
\]

Both orders give the same value when the root exists. Taking the root first usually keeps the numbers smaller, which is why it is the preferred order in arithmetic.

The base must be non-negative when the root is even. A negative base with an even denominator has no real value, and that case is outside this concept.

## Evaluate the root first

Write the base as a perfect power. If \(a=k^n\), then

\[
a^{m/n}=\left(k^n\right)^{m/n}=k^m.
\]

For example, \(8=2^3\), so \(8^{2/3}=(2^3)^{2/3}=2^2=4\). Recognizing the perfect power is the whole computation; the exponent rule only moves the factors.

## Negative exponents take a reciprocal

A negative exponent means

\[
a^{-m/n}=\frac{1}{a^{m/n}}.
\]

Evaluate the positive power first, then take the reciprocal. The sign of the exponent does not affect the root or the power, only the final flip.

The result can be an integer or a fraction. A fraction is entered in the form \(1/4\), not as a decimal approximation, because the value is exact.
