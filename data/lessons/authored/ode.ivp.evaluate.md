# Solving an initial value problem

## One constant per integration

Integrating a first-order equation introduces one constant, and the general solution carries it. The initial condition is what fixes it: substituting the given point into the general solution leaves one equation in one unknown.

So an initial value problem is an integration followed by a substitution, and the order of those two steps matters.

## Using the initial condition

The condition is usually given at zero, which makes the substitution immediate, but any point works the same way. Solving for the constant is the step to show, because it is where the answer stops being a family.

A solution with a constant still in it has not answered the question the initial value asked.

## Evaluating at a point

Once the constant is known the solution is a function, and a question can ask for its value anywhere. Evaluating is then arithmetic, and it is worth doing last, after the constant is fixed, rather than substituting both points into the general form.

The check is the initial condition itself: the finished solution must give the given value at the given point.
