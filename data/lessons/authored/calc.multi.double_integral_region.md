# Double integrals over a general region

## Describing the region

A double integral over a region that is not a rectangle is computed by letting one variable's limits depend on the other. A region of type I is one where \(a \le x \le b\) and, for each \(x\), \(g_1(x) \le y \le g_2(x)\).

The inner integral's limits are then functions rather than numbers, and they are evaluated in the variable the outer integral has already fixed.

## Setting the limits

For the triangle \(0 \le y \le x \le 4\), integrating in \(y\) first runs from 0 to \(x\), and then \(x\) runs from 0 to 4. With the integrand 1 the value is the area, \(16/2 = 8\).

Writing the region down as inequalities before integrating is the step that prevents a wrong answer, because a limit of integration that is a constant where it should be a function is the usual mistake.

## Choosing an order that fits

A region can usually be described either way, and one description often gives simpler limits. A triangle bounded by the axes and a line is easy in both, but a region bounded by a parabola and a line is usually easier in the variable whose limits are constant.

The order does not change the value, by Fubini's theorem, but it changes how much work the inner integral is.
