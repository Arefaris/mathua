# ADR-025: The report lives on the hub

*2026-10-01*

ADR-024 moved the report to `/progress` to honour ADR-001/023's "compact hub". In use that was wrong: a learner opening their own page got a task queue and an alerts column and had to go elsewhere to answer "how am I doing", and the hub stopped being the thing it is named for. The five sections came back to `/profile`, ordered `Activity` → `By domain` → `How you're doing` → `Struggles` → recently unlocked, below the identity/Next/alerts block. `Activity` leads deliberately: the heatmap is the "I showed up" signal and is what many learners open the page for. Restored by hand rather than by reverting the move, so the two things already decided against stayed out — the cohort first-pass-by-week chart (belongs on `/docs/efficacy`) and the daily-goal row that restated `ProfileStats`. `PositionBlock` came with it: it was the one part of the redesign that was new rather than moved, and it reads the same `head` the Next task does, so *where am I* and *what's next* cannot disagree. `/progress` is deleted; the sidebar entry became `History → /history`, which finishes the naming fix ADR-024 began. Kept from ADR-024 because they stand alone from the move: the `lib/progress.ts` extraction, `Engine.GetProgress` applying decay on read, `prereqMet` accepting `DECAYING`, and the `/history` rename. The lesson: ADR-023's "compact summary" was about not duplicating the Next head, not about hiding a learner's own numbers from them.
