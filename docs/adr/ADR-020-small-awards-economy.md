# ADR-020: Small-awards economy

*2026-09-29*

XP rescales from flat 10/5/15/20 to effort-derived 1–5 bases (`EffortBase` from threshold seconds × difficulty; review halves, quiz premium +1); quiz gate 150→50, daily default 30→10, rush −5→−1, existing goals rescaled /3 via versioned v3 backfill (both stores). Cadence preserved (~5 lessons per quiz, ~a lesson a day). Bases are an effort-derived approximation, never exact time accounting. Deferred: retry multiplier, lesson accuracy bonus, continuous time-ratio rush.
