# ADR-047: Study is closed as a learner workflow, and its content became a reference panel inside `/learn`

*2026-10-08*

**ADR-021's split — Learn teaches, Study explains — was half a design.** It drew the boundary between two pages and then left both pages open, so "Study explains" was also "Study is a second place to approach the same mathematics": a browsable library of whole lessons with its own search, domain index and lesson pagination, linked from the desktop header, the mobile tab bar, the profile sidebar, the footer, the landing page, the docs menu and the creator's note, and reachable from the graph, the diagnostic results, the quiz's remedial list, the attempt history and two **Reference** buttons *inside* `/learn` itself. Only demonstrated answers move a concept, so a surface that explains without asking is a route around the only thing that counts — and the product had decided against that in ADR-045 and then left the door open. **The material is kept and the route is closed**, which is the whole distinction: `components/ConceptReference.tsx` renders the worked-example blocks, the per-block report menus, the prerequisite list and the article fallback for **one concept**, inside `/learn`, collapsed, with **no link out of it at all**. There is no domain list, no lesson list, no search box, no sibling-concept chips and no route to another concept, because the difference between reference material and a second learning path is behavioral rather than cosmetic. The last figure renderer — the one that resolves a `/diagrams/…` reference out of markdown — survives only on the article fallback path, and `e2e/lessonFigures.spec.ts` had to move to reach it rather than be deleted, because a guard that is not run protects nothing. **Four modules died with the surface and one of them had a test**, which is the argument for the orphan check rather than against it: `lib/topoRank.ts` (Kahn's order, so a *listing* followed prerequisites — the whole reason it existed), `lib/conceptTarget.ts` (URL-state sync for in-lesson chips), `SearchBar` (search over lessons; concept search survives on the graph) and `MasteryBadge` (the status dot, replaced by the status **words** ADR-021 kept). **Two recommendations now named a route that does not exist**, and both were wrong before the closure as well as after: `scheduler.Recommend`'s "everything available is already learned — the reference library is open" sent a learner with **nothing due** to go and read, which is the one activity that cannot help them, and `getNext`'s client-side fallback said the same thing in its own words. Both now send `/graph` and `RecommendPaused` sends `/settings`, where the pause and its end both live — chosen over `/review` because reviews are hidden while paused, so naming it would contradict the pause the learner just set. `TestRecommend_NothingAvailableFallsBackToOrientation` asserts the destination and that it is not `/study`, because a recommendation pointing at a forwarder sends someone to a redirect on the way to nothing. **The graph's node action became a function of the concept's state**: still being learned goes to the teaching loop, already demonstrated — **including DECAYING** — goes to `/review`, because `/learn?concept=` opens with the worked example unconditionally and re-teaching a concept the learner has proved they can do is the tutorial purgatory ADR-037 removed from the scheduler's own path. **Two bounds kept, as ADR-044 had already got right:** prerequisites stay visible, and the readiness banner's learn/check split is untouched — the panel lists the complete set as words with no links, so nothing is dropped and nothing is duplicated. **No "I studied this" was added, and the panel says so at its foot**, because prose sitting next to the questions is exactly where such a control would be expected if one ever arrived. `/study` and `/concept` forward to `/learn`, carrying `?concept=` and dropping `?domain=`, `?lesson=` and the `?from=` that only ever existed to come back from Study; static export cannot use `next.config` redirects, so they are client stubs like `/session`, pinned by `test/deprecatedRoutes.test.tsx`. **The guard is the deliverable.** `test/learningPath.test.ts` scans every authored learner surface and fails on any `/study` destination, any "Study" control, a `/study` in the sitemap, a link out of the reference panel, or a graph node that can re-teach a mastered concept — each stated as a property of the source, because the failure mode is a link being **added** and a snapshot would have to be regenerated to notice. It strips comments first, so the reasoning above can live in the code without tripping it; a guard needing a carve-out per explanatory comment is a guard that has already stopped working. **Three findings came from running the thing, and each is a class someone else would re-create.** (1) `buildExampleBlocks` called `stripMathDelimiters(kp.label)` on a shard with no `label`, and that function calls `.replace` on what it is given — so one malformed knowledge point took down the **whole `/learn` page** with a render error, and it was a loose e2e fixture (`{ key, title, sections }`) rather than real corpus data that exposed it. External payloads are now defaulted at the parse boundary, which is where the repo's own lint rule already said to put them. (2) The reference panel starts below the fold, and `KatexContent` renders figures with `loading="lazy"`, so a lazy figure that has not been fetched reports `0×0` — **the same reading as a broken one**. The figure spec now scrolls and awaits each image, and says why: a measurement that cannot tell "not loaded" from "did not draw" is not a measurement. (3) The panel's `h3` is the first heading on `/learn`, which broke a mobile spec that locates a heading to tap; the locator now filters `:visible`. **`/study` was the last route in `INDEXABLE_ROUTES` that was query-driven, and it is 462 kB of bundle that is now a 460 B forwarder.** Verification: 614 web unit tests, 221 Playwright tests across three viewports, both Go packages, `tsc`, ESLint and `oxlint` — the last at 82 warnings, unchanged from before, which is asserted by diffing rather than by a threshold nobody would notice.
