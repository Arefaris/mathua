# ADR-043: A learner is told where they are against what they can reach, not against the catalogue

*2026-10-06*

`PositionBlock` said "**N of 657** concepts mastered" while the bar four pixels below computed `mastered / unlocked` — on a fresh account a **100% full bar next to a 0% headline**, both true about different sets, presented as one scale. One denominator now, and it is named: "of 3 you can reach". "Still locked" is removed: it was the one figure here a learner can neither act on nor change today, and it *grows* as they learn, so it reads as decline. ADR-024/025's deliberate refusal of a percentage-of-657 was half-implemented — the comment said so, the headline did not. **Second half: the frontier's button is gone, its label is not.** ADR-025 had this block read the same head as the Next task so the two could not disagree; that coupling is still worth having, so the label stays and the CTA does not, because `NextUpSummary` renders it twenty lines below and two buttons for one task is not emphasis. The test asserts the block contains no link to the head's own destination while the review-debt link — a different fact — stays. **Then the stale numbers, all of them the same shape: a number copied somewhere the thing it describes can change.** The landing page advertised a **150** XP mastery check for as long as ADR-020 had gated it at **50** — the one number `build-graph.mjs` cannot derive from the corpus, which is exactly why it drifted. It now travels as `quizGateXP` in `graph.meta.json` and `internal/xp`'s `TestLandingQuizGateMatchesEngine` compares the artifact against the constant. Adding it surfaced the mechanism: **`app/home/data.ts` redeclared the `GraphMeta` interface instead of importing it**, so a second schema described the same artifact and a new field type-checked as a *missing property* rather than as a change to the page — a duplicate type is quiet in a way a duplicate value is not. The **level ladder stopped at "256–284"** over a 657-concept catalogue: nine hand-written ranges ending mid-corpus, now computed from `conceptCount`, which is ADR-013's rule applied to a number it had missed. And `/profile`'s quiz bar **divided by a literal `50`** while gating visibility on `scores.xp_total >= 50`, a fallback for `quiz_due` — a flag the server does send — so copy, bar and condition could each describe a different gate; `Scores` carries `quiz_gate_xp` now, and the block renders only when it arrives rather than substituting a literal, because a bar measured against a gate the engine does not use is a claim about how close a learner is. `Take Test` → `Start the quiz`: the badge beside it has said "Quiz due" throughout, and CONTEXT reserves *test* for the diagnostic. Landing and `/study` told learners "the scheduler reads the graph" — right in `/system-design`, where `SM-2 Scheduler` names a component, wrong in a paragraph about what a learner will see.
