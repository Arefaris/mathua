# ADR-040: The client renders the authoritative score instead of computing its own

*2026-10-05*

completes the deferred half of ADR-039, and the finding that made it necessary is a measurement artefact worth keeping. ADR-039 ended by naming `lib/progression.ts:masteryEstimate` as a second model and promising unification "as its own piece of work". Tracing it first showed there was nothing to unify. `LearnStepper` read `est.decision` from exactly one place — `est.decision === 'advance' || next >= REQUIRED_IN_A_ROW` — and `decision === 'advance'` **requires** the last two attempts correct (`streak2`), which is the same fact as `next >= REQUIRED_IN_A_ROW`, so the first operand could never be the deciding half. An exhaustive sweep over all 510 histories of length 1–8 confirmed it: 111 advance decisions, **zero deciding alone**. `intervene` and `continue` were therefore unreachable rather than merely unused, `masteryEstimate` had no other production importer, and its only surviving output was `band`, rendered as text in two places. A model with no authority is the worst kind to leave in place, because it reads like authority and cannot be reconciled with the real thing. **What the second model got wrong**, had it mattered: it weighted difficulty per attempt against the server's mean of correct attempts (same multiset, different pairing → 0.500 vs 0.562); it counted *every* attempt in the window for variety against the server's documented correct-attempts-only population (0.71 vs 0.66, and on miss/correct/miss the band differed outright — `developing` against `unseen` for the same three answers); and it applied a flat 60s time cliff where the server uses the concept's own `avg_time_seconds`, disagreeing on **262 of 437** concept-thresholds because 162 of 657 concepts sit at 120s. **The fix removes logic rather than adding it.** `applyGradedAttempt` now returns the `mastery.Evidence` it decided from, and `AnswerResult` carries `evidence_score` plus `evidence_band`; `mastery.EvidenceBand` lives in `internal/mastery` beside `MasteryThreshold` and `MasteryEvidenceFloor`, so the client's thresholds are gone and it renders a string. `LearnStepper` deleted its formula and its dead operand; `history` survives only as a header tally, with no judgement derived from it. **Two defects lived in the label, not the state, and are the reason the band was worth moving rather than keeping.** It offered `well retained` off a score with **no spacing term at all** — a retention claim drawn from evidence that knows nothing about retention, in the same file that had just been used to separate attainment from retention. And having no evidence floor of its own, it read **`strong` after a single correct answer**, because a lone attempt carries the most recency weight there is: `MasteryEvidenceFloor` exists to prevent precisely that, and the label was letting it through the back door. `EvidenceBand` therefore floors on `MasteryEvidenceFloor` and the vocabulary is `starting`/`building`/`consistent`/`strong`, none of which promises the future. **Guards, because a model with no authority is easy to re-add by someone who believes it has some:** `test/masteryAuthority.test.ts` asserts `lib/progression.ts` computes no score, that no client module contains the distinctive constants of the removed model, that the Learn header renders the server's word and derives no judgement, and that there is exactly one `const advance` in the file and it is the plain 2-in-a-row rule. It strips comments before asserting code shape, because several of the new comments deliberately quote the code they replaced. `TestEvidenceBandClaimsNothingBeyondTheEvidence` and `TestAnswerResponseCarriesAuthoritativeEvidence` cover the server side, including that an ungraded answer (ADR-006) reports no evidence. **Not touched, and deliberately:** `nextStreak`/`isAdvanced`/`initialState`/`applyResult` are dead production code with no caller outside their own test, and `StreakState.advanced` looks like a progression model — but 2-in-a-row is ADR-017's *lesson* rule (`improve.md:39`), a genuinely different concept from mastery, so removing it is a separate call. **Deferred, and now smaller:** with the client copy gone there is exactly one evidence model in Mathua. Still open, and adjacent: `LearnStepper`'s `totalCorrect/totalAnswered` is reset on every knowledge-point advance, so the completion card reports only the *last* section's tally while the band beside it is per-concept — a scope mismatch that predates this work and is worth its own pass.
